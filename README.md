# dsh-academic-ppt

**面向正式学术汇报的 DSH 插件：主动查证文献、取得论文图，用图表和研究插图组织论证，交付可继续编辑的 PowerPoint。**

适用于论文精读、文献综述、研究进展、开题、学位答辩和项目汇报。围绕研究问题，把证据、方法、解释和适用条件组织为有阅读层级的页面，并保持整稿的叙事与章节定位。

**v0.8.1** · 支持 DSH Desktop / Web · 论文图与研究插图 · 可编辑 PPTX · 36 款辅助信息卡

[下载插件](https://github.com/YuZhou0311/dsh-academic-ppt/releases/latest) · [安装与升级](docs/INSTALL.md) · [完整卡片图册](skills/dsh-academic-ppt/references/card-library/index.html) · [发布说明](docs/RELEASE_NOTES.md)

## 用图像表达研究

先核对论文身份与全文，取得并查看原始结果图、方法图和必要的研究插图，再按这些材料安排每页的比较、解释与条件。只给主题或 DOI 时，Agent 应主动使用宿主提供的检索与下载能力；用户未上传原图不意味着可以跳过取图。

论文原图作为独立图片保留，标题、图旁解释、标注、数据图和布局继续可编辑。原始曲线、误差、空间图与必要对照不会因为“原生可编辑”而被替换成文字摘要。卡片用于解释、条件和局部比较。

新建学术工程会检查来源查证与图源盘点，追踪选中的原图是否真正进入正文。未取得图、只登记未上页、用图标或文字框代替原图，都会明确暴露；真实没有适用原图的材料可记录具体依据并采用有来源的替代表达。

## 为学术内容设计

| 能力 | 怎样用于你的汇报 |
| --- | --- |
| **论文图与研究插图** | 主动查证、下载或从 PDF 取得原图，查看图注与图版，保留图号、来源及采用记录；按图组织说明与比较。 |
| **整稿叙事与导航** | 建立贯穿问题与章节问题，安排目录、分节、正文定位和过渡；结尾回应研究问题并说明下一步。 |
| **完整逐页设计** | 先确定可见内容、证据来源、语义关系和阅读顺序，再安排标题、图表与区域；同页可组织多组相关信息。 |
| **灵活分栏与分块** | 自由组合主证据、比较区、方法说明、条件旁注和综合判断，支持不同宽高与层级的多区域布局。 |
| **36 款原生信息卡** | 按研究任务查询和选型，保留完整正文、单位、条件与来源；需要不同关系时可用原生形状重新组织。 |
| **正式学术配色** | 提供深蓝、墨绿、靛蓝、酒红和石墨色系，根据资料、图表和阅读场景调整颜色职责。封面通过题名与真实元信息建立层级。 |
| **用户模板参考** | 开始新汇报时确认一次是否提供模板；支持分析上传的 PPTX，并查看代表页，学习比例、层级与分组方式。 |
| **按内容生成设计参考** | 宿主提供可用生图工具时，优先以本次汇报的真实内容生成卡片参考；查看后重建为可编辑对象。没有可用接口时继续使用原生卡片库。 |
| **可追溯的修改与检查** | 保存查证依据、图源、论点、逐页设计与讲稿；检查原图实际使用、连续文字页、缩略图、文字负担与大空区，支持局部修改和修订恢复。 |

### 参考之后，继续设计

模板和卡片库提供组织方法。Agent 仍需根据当前材料决定哪些信息需要合并、分组、对照或形成流程，并相应调整配色与构图。只有明确要求沿用模板版式时才进入忠实模板模式；普通参考任务保留自主设计。

学术颜色服务于结构和数据含义。已有科学图中的变量色应保持可解释，新增强调色用于标题、关键比较与章节定位；参考图的颜色可以调整，用户明确指定的固定色则应保留。

### 六类卡片，覆盖常见研究任务

| 家族 | 可以表达的内容 |
| --- | --- |
| 问题与背景 | 研究问题、语境、概念定义、背景观察、编号议题 |
| 方法与流程 | 输入输出、操作步骤、公式释义、实验协议、算法过程 |
| 证据与解释 | 结论与依据、来源定位、证据追踪、配对比较、观察与解释 |
| 指标与读数 | 单项读数、双指标、基线参照、目标与观测、指标台账 |
| 条件与限制 | 适用边界、工作假设、覆盖范围、风险与应对、条件核对 |
| 阶段与决策 | 阶段路线、里程碑、条件分支、完成与待办、下一步行动 |

## 开始使用

1. 从[发布页](https://github.com/YuZhou0311/dsh-academic-ppt/releases/latest)取得插件安装包。
2. 按[安装说明](docs/INSTALL.md)安装到正在使用的 DSH Desktop 或 Web 环境，并启用插件。
3. 在新会话中加载 `dsh-academic-ppt` 技能，提供材料、听众、时长和页数要求；有参考模板时一并上传。

可以直接这样提出任务：

> 请使用 dsh-academic-ppt，根据工作区里的论文和数据制作一份 15 分钟的研究进展汇报。
> 先主动核对文献和全文，取得并查看关键论文图，再梳理研究问题、证据与不足。
> 用实际结果图、方法示意和必要的研究插图组织正文，图旁解释比较、条件和边界。
> 正文需要充分的信息量，可以分栏、分块或组合多种表达；保留比较条件、单位和结论边界。
> 配色正式、克制，卡片按实际内容调整。若参考模板，请学习其信息层级与设计方法。
> 最后交付可编辑 PPTX、讲稿和可恢复工程，并检查实际渲染的每一页。

没有模板也可以开始。插件会沿用学术设计流程；模板偏好已经说明后，不再重复询问。旧版 `.ppt` 文件需先转换为 `.pptx` 后再解析。

## 从资料到交付

| 阶段 | 主要工作 |
| --- | --- |
| 查证与取图 | 检索并核对题名、DOI与版本，取得全文、原图和图注，记录真实获取状态及图号；未取得时保留具体缺口。 |
| 组织论证 | 确定中心问题、章节任务、逐页承接和时间分配。 |
| 设计页面 | 先安排实际原图、准确数据图及研究示意，再写图旁解释和必要卡片；学习参考、比较困难页面的真实候选。 |
| 构建与复核 | 核查选图是否实际入稿，再生成并查看每页 PPTX；修复缺图、图过小、文字负担、空卡片与大空区。 |
| 继续修改 | 根据反馈修改指定对象或整页，保留版本、讲稿、证据与工程记录。 |

每次构建生成独立的导出目录，包含可编辑 PPTX、HTML/SVG 预览、讲稿、证据清单和检查结果。安装可选渲染引擎后，可生成实际 PPTX 的页面图与 PDF；中文字体按[安装说明](docs/INSTALL.md)配置。工程保留可恢复记录，便于后续改稿。

页面设计和可选生图调用由 DSH 当前会话的模型执行，插件提供设计流程、工具、原生渲染与检查。研究解释和最终画面仍需结合资料复核；具体宿主版本与实测范围见[DSH 兼容说明](docs/DSH_COMPATIBILITY.md)。
