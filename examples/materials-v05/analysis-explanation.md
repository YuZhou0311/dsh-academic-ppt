# 金属构件疲劳寿命比较：分析说明与答问依据

对应汇报：10 页，讲稿时间预算 600 秒，最终审阅工程 revision 13。资料为教学模拟数据；本文件中的数值不代表真实材料、工艺、机构或项目的实验结果。

## 1. 结论及其适用范围

现有记录支持继续验证改性工艺，但不足以确认工艺收益。B 批是唯一同时包含两工艺、且应力相同的单元；其改性减常规均值差为 **2.56 万次**，探索性双侧 95% Welch 区间为 **[−1.37, 6.49] 万次**。正向点估计是后续验证线索，区间和设计缺口使方向、实际幅度及因果归因均未完成。[1][2][3]

合并所有记录得到的 **41.5%** 是不同条件构成下的受限均值相对差。它不能替代 B 内比较，更不能作为工艺收益。C 批两件 runout 允许估计 50 万次观察窗内的受限平均寿命，不能提供完整失效寿命的尾部。[1][2][3]

所有结论均保留三个边界：资料是合成的；工艺随机分配缺少记录；可比工艺条件仅有一个批次。新批随机对照、机制表征和跨批验证均为提议，尚未开展。[1]

## 3. 先定义所估计的寿命

设实际失效寿命为 T，预定共同观察上限为 τ = 500,000 次。对于本文件记录，可以完整得到：

\[
Y=\min(T,\tau),\qquad \operatorname{RMST}(\tau)=E[Y]=\int_0^\tau S(t)\,dt.
\]

46 个 failed 是已观察到的失效时间；2 个 runout 是达到共同停止点时仍未失效。两个 runout 分别为 C-mod-02 和 C-mod-08，CSV 第 39、45 行，均为 500,000 次。没有记录更早删失。[1][2]

因为本数据中所有删失都发生在共同 τ，`cycles_observed` 正好等于 Y，取其均值是有效的受限均值描述。错误不在于“平均了 500,000”，而在于把该平均解释成完整失效寿命 E[T]，或忽视混合条件后将其归因于工艺。报告没有把 runout 记为失效、删除或替换成推测寿命。

B 两组在 τ 之前全部失效，因此其本次样本平均失效时间与受限观察均值数值相同。选择 RMST 作为后续共同评价口径，可以使出现 runout 的新数据仍对应同一观察窗；若未来存在 τ 之前失访，则不能再不加处理地取观察时间均值，需要预先规定删失分析及假设。

## 4. B 批的主要探索性比较

设常规组均值为 \(\bar Y_c\)，改性组均值为 \(\bar Y_m\)，差值方向固定为改性减常规。

\[
\widehat\Delta_B=\bar Y_m-\bar Y_c
=329305.0833-303682.8333=25622.25\text{ 次}.
\]

两组各 12 件，样本标准差分别为 30,977.2812 与 56,622.7126 次。采用不要求两组方差相等的 Welch 近似：

\[
SE=\sqrt{\frac{s_m^2}{12}+\frac{s_c^2}{12}}=18631.7908,
\]

\[
\nu=\frac{(s_m^2/12+s_c^2/12)^2}{(s_m^2/12)^2/11+(s_c^2/12)^2/11}
=17.0432.
\]

\[
CI_{95\%}=\widehat\Delta_B\pm t_{0.975,\nu}SE
=[-13679.7991,\ 64924.2991]\text{ 次}.
\]

相对点差使用 B 常规样本均值作分母：25,622.25 / 303,682.8333 = **8.4372%**。报告展示的区间仍在绝对差尺度，未把它冒充成比例效应置信区间。双侧检验 p = 0.1869 仅保留在计算文件中；主画面以效应大小和区间为主。[2][3]

这是探索性、小样本、模型下的均值区间。它依赖组内独立与均值抽样近似，未覆盖分配记录缺口、顺序与样品差异造成的系统偏差。它既不是工艺因果效应的保证，也不是一个“95% 概率工艺有效”的后验概率。当前区间同时兼容负差、零差和较大的正差，不能将未显著解释为无效或等效。

## 5. 为什么混合差达到 41.5%

把 A/B 常规合并、B/C 改性合并，两组各 24 件：

\[
\bar Y_{\text{常规混合}}=269974.3750,\quad
\bar Y_{\text{改性混合}}=382064.7083.
\]

混合差为 112,090.3333 次，相对常规混合均值为 **41.5189%**。由于四单元样本量相等，可得到精确代数恒等式：

\[
\Delta_{\text{混合}}=
(\bar Y_{Bm}-\bar Y_{Bc})
+\tfrac12(\bar Y_{Bc}-\bar Y_{Ac})
+\tfrac12(\bar Y_{Cm}-\bar Y_{Bm}).
\]

| 描述项 | 次 | 报告显示 / 万次 |
|---|---:|---:|
| B 内工艺样本差 | 25,622.2500 | 2.56 |
| 常规构成项 ½(B−A) | 33,708.4583 | 3.37 |
| 改性构成项 ½(C−B) | 52,759.6250 | 5.28 |
| 合计：混合差 | 112,090.3333 | 11.21 |

这说明混合估计使用了不同的条件构成；它不把后两项识别为“批次贡献”或“应力贡献”。C 相对 B 同时改变批次和应力，而且 C 缺少常规对照。另一个有用描述是：在同为常规、200 MPa 的 A 与 B 中，B 样本均值较 A 高 **28.5343%**，分母为 A 常规均值。这提示条件构成值得控制，但仍不是纯批次的因果效应。[1][2][3]

## 6. C 批删失曲线与 RMST

C 有 10 次失效，生存曲线只在这 10 个事件时下降；两件在 50 万次共同停止，曲线在停止点仍保持 2/12 = 1/6。报告曲线止于 τ，不在删失处落到 0，也没有向 50 万次以后延伸。

按 Kaplan–Meier 分段常数曲线积分得到 434,824.3333 次，即 **43.48 万次**，与 12 件 Y 值的样本均值精确相等。程序保存了每次事件时间、在险数量及生存比例，可以逐段复核面积。[2][3]

50 万次后的两个实际失效时间未被记录，因此 E[T] 的尾部不由现有数据识别。C 只有 180 MPa 改性组，无法在该应力下估计工艺对照差；其较长循环记录也不能单独证明应力作用或改性机制。

## 7. 归因、建模和机制能推进到哪里

现有设计不是完整的批次 × 工艺 × 应力交叉设计。应力与 C 批完全绑定，可写成 `stress = 200 − 20·I(batch=C)`，所以不能同时从现有记录独立识别不受约束的批次效应与应力效应。数据只有两个应力水平且与批次/工艺结构绑定，不足以建立可推广的应力—寿命规律。[1][2]

这不意味着任何回归都不能运行。含批次项和共同工艺系数的加性模型可以主要借 B 的对照估计工艺关联；但把该系数外推到 A、C 或其他应力，需要额外假定工艺效果不随条件改变。现有缺格无法检验这些交互与可迁移性假设。模型计算不能生成缺失的对照记录，也不能替代随机分配证据。

材料机制同样须分层表述。输入没有具体工艺参数、断口显微图、组织信息或残余应力测量，因此不能画出已成立的“工艺—组织—性能”机制链。后续可以先明确改性操作与参数，再根据具体候选机制选择表征，并检验其与失效终点的关系；这是一条验证路径，不是现有结果。[1]

## 8. 下一批试件的可执行提议

原方案允许申请一批同应力新试件，但尚未开展。建议以同一新批、200 MPa、两工艺随机 1:1 分配为优先设计，并对试验顺序随机安排。分配前固定入组条件和工艺参数，记录加工、测试顺序及设备环境条件，尽可能盲化终点判读。固定观察窗为 50 万次；主要评价为改性减常规的 RMST 差。[1，研究进度；本报告提议]

在新数据形成前，应具体写清：什么是疲劳失效，什么是行政 runout，设备中断/提前失访如何处理，哪些排除发生在分配前，如何保留分配后的记录，主分析的差值方向、观察窗和区间方法。若出现更早失访，应采用预定且有依据的删失处理；不能用 50 万次替填，不能按失效处理，也不能事后静默删掉。

随机试验可以加强这一新批次内的归因，单批试验仍不能估计跨批重复性。即使成功，也仅覆盖当前定义的工艺、200 MPa 与 50 万次观察窗；向批次总体或其他应力推广需要独立重复和补充设计。

## 9. 完整的判定规则和反例

令新试验预定估计量为 Δ = 改性 RMST − 常规 RMST，双侧 95% 区间为 [L,U]。δ = 30,000 次仅为报告中便于讨论的设计值；原资料没有工程重要性阈值，它尚未验证或批准。应在新数据揭盲前依据应用需求、成本和误判代价确定 δ。

先核查随机分配、统一终点和预定分析的评价前提是否成立。若前提失败，先处理偏差或缺失并限定支持范围；不能直接把确认性判据套在不满足前提的结果上。

| 区间条件（前提成立后） | 判断 | 后续含义 |
|---|---|---|
| L > δ | 支持超过实际阈值的正向收益 | 进入独立批次重复 |
| U < −δ | 支持超过实际阈值的反向损害 | 停止推广，排查工艺与条件 |
| −δ ≤ L ≤ U ≤ δ | 支持预先定义的实际近似 | 结合成本讨论工艺取舍 |
| 其余，且 L > 0 | 方向为正，是否超过实际阈值未定 | 提高精度或修正假说 |
| 其余，且 U < 0 | 方向为负，反向实际幅度未定 | 保留负向证据，评估风险 |
| 其余，且包含 0 | 方向及实际幅度未定 | 补充信息，不宣布无效或等效 |

这是采用预先约定双侧 95% 区间的保守判定方案；“实际近似”取决于 δ 和区间整体包含关系，不等于未拒绝零差，也不冒充未经设计的正式等效检验。

以下全部是假想区间，单位万次，不是新实验结果：

| 假想 95% 区间 | δ=3 万时的判定 |
|---|---|
| [4,7] | 超过阈值的正向收益 |
| [−7,−4] | 超过阈值的反向损害 |
| [−2,2] | 全部位于实际近似带 |
| [1,5] | 正方向成立，但是否超过 3 万未定 |
| [−5,−1] | 负方向成立，但是否低于 −3 万未定 |
| [−5,4] | 含 0 且越出近似带，方向和实际幅度均未定 |
| [3,4] | 触及阈值，不满足严格 L>δ；正方向、实际收益门槛未定 |
| [−4,−3] | 触及负阈值，不满足严格 U<−δ；负方向、实际损害门槛未定 |

`analyze.py` 中的 `current_B_under_proposed_rule` 只展示当前数值区间在这组讨论阈值中的位置。它不是对 B 进行确认性规则授予：B 的随机工艺分配前提缺少记录，δ 也是面向未来的讨论值。当前 B 既不能确认收益，也不能宣称实际近似，这一结论由区间与设计边界共同支持。

## 10. 样本量情景的用途和限制

用 B 两组样本方差的平均值作先导方差，σ = 45,638.38 次。针对等组、独立两组、双侧 α=0.05、目标功效 80%，以 30,000 次作为相对零差的备择差，正态近似：

\[
n\approx \frac{2\sigma^2(z_{0.975}+z_{0.8})^2}{30000^2}.
\]

| 假设标准差 | 近似每组数（向上取整） |
|---|---:|
| 45,638.38 次（B 先导量级） | 37 |
| 57,047.98 次（×1.25） | 57 |
| 68,457.57 次（×1.50） | 82 |

这组数字仅说明资源量级对变异假设敏感，没有作为已批准试验方案或主画面承诺。它们忽略小样本 t 修正、新批变异、未来删失/失访和预定区间方法的细节，需要重新设计。

尤其需要区分：上述公式针对“检测相对 0 的差异”，不能保证区间下限 L>δ。若真正成功标准是 L>δ，必须另选高于 δ 的目标备择效应 Δ₁，并围绕裕量 Δ₁−δ 计算；不应在 Δ₁=δ 时承诺有 80% 概率越过该阈值。δ、Δ₁、误判代价和可能删失比例都须先约定，再确定最终样本量。
