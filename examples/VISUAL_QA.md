## 本轮修复如何改善阅读

中文导出的相对行距曾与字体自然高度叠乘，紧凑面板因此比预览拥挤。正文和原生表格单元格改用明确的点行距后，场景估计与实际行距更接近。

独立六页演练还发现了接近列宽的中英混排表格反例。修复保留文字宽度余量，预先计算折行、行高和图注位置；没有通过缩小全表文字掩盖问题。实际反例中表格末行与图注之间保留 6.864 pt。

书目页原先把所有授权连接成一个长段，原生输出出现横向溢出。现按每个 Fig./面板/许可证独立分行，完整保留来源，消除对右栏的侵入。

S06 的长题签曾超出窄槽位；最终写作“Fig. 4 局部”，研究对象在页面标题与图注中完整保留。

直接解包最终 PPTX，取得 **390 个原生 shape、5 个独立 picture、3 个原生 table、1 个原生 chart，以及 14 份 notes**。文字、方法图、表格、解释和图注可以继续编辑；计数图带有原生图表结构。

## 实际边界

论文发布的 PNG 分辨率会限制细小轴字的投影效果。完整长图用于定位，关键面板放大并配原生文字解释；必要时应打开原始图文件或正式图页继续核对。没有通过生成模型“修复”科学读数。

字体家族存在不等于特殊字符都有字形。独立演练保留了下标 `ₜ` 的缺字反例；正式强化学习模板使用 `s_t/a_t/r_t`，对其他公式仍需实际查看。合法的裁切坐标也不能证明坐标轴和对照均被保留，这依赖实际读图检查。

本轮没有进行 Microsoft PowerPoint 或 WPS GUI 的交互编辑验证。原生结构由 XML 和回归测试确认，实际画面由 LibreOffice kit 验证。HTML 是单独的预览输出，不充当 PPTX 验收凭据。

离线 `npm run demo` 保留 `imageInput: unknown`，不会自动继承这份视觉审查。使用者应核查实际 DSH 模型与宿主能力，再执行自己的审查。

更多机器可读数据见 [validation-v0.2.0.json](../docs/validation-v0.2.0.json)，独立演练范围见 [forward-review-v0.2.0.md](../docs/forward-review-v0.2.0.md)。
