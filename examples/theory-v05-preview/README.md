# 理论 C1：最终代码重建的局部预览

本目录提供已独立接受的理论 C1 答卷的 **3 张实际页面预览**：原稿第 1、4、8 页。C1 的独立接受来自原试用的单独评审；本目录所用图片取自随后在最终 v0.5.0 代码上完成的相同内容兼容性重建，**不是一次新盲测生产或新的独立接受**。

原汇报题名：**保形预测：有限样本保证从何而来**。

原文来源为 Anastasios N. Angelopoulos 与 Stephen Bates 的 [A Gentle Introduction to Conformal Prediction and Distribution-Free Uncertainty Quantification — arXiv:2107.07511v6](https://arxiv.org/abs/2107.07511v6)。这里保留论文链接，不附原论文 PDF。

## 作者绘图源码

[author_figures.py](author_figures.py) 与原作者文件及最终代码重建附带文件逐字节相同。完整源码已检查：不含内嵌图片字节、base64、序列化 SVG 或原论文图像载荷。它包含多个作者自制教学图的计算代码，以及从另行提供的原论文 PDF 裁出天气图的步骤；后者只有路径和裁切指令，没有天气图像本身。

代码没有为了这个局部目录而改写，也没有在本次预览整理中执行。其原流程需要 `inputs/paper.pdf`、`inputs/fonts/NotoSansCJKsc-Regular.otf`、`inputs/fonts/NotoSansCJKsc-Bold.otf` 及相应 Python 依赖，这些均未随局部预览附带。因此此目录是来源可检查的局部预览，不是完整可运行绘图环境。
