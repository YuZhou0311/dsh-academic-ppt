# 内容树教学输入，不是科研成品

从 contract(authoring) 查询当前完整契约。shared-comparison.json 与 method-feedback.json 可在空教学工程编译；其数值和方法是构造示意。paired-panels.json 故意使用待替换资产 ID：必须先 record 当前真实原图，再填入实际 ID，不会自动寻找或编造图片。

只迁移关系：共享行、反馈、图文对应。研究对象、标题、条件、全部读数和来源必须由当前材料决定。更改对象数量、图像比例、必要文字长度时重新分配权重，不整体缩放旧页面。

这是输入示例；源资产、科学核验、用户意见和实际看图记录不能由示例代填。主流程仍是 init → record 真实证据 → plan(compose-page) → build(draft) → render → read_image → 修订 → 真实反馈。
