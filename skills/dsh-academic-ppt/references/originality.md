# 每稿独立设计与跨报告检查

## 把不同内容变成不同画面

每份研究先确定其核心证据、数据尺度、方法拓扑、不可删条件与来源图特点，再形成design.direction。原图、表格和科学关系决定主载体与构图，不能先确定一组页型后只替换文案。

独立设计可以体现在封面重心、读图路径、局部组件、图文邻接、主次面积、方法展开方式与页序。统一字体和色义形成完整报告；不靠每页随机换皮。相同原图或相同比较关系可能需要相同表达，不为降低相似度改变数据比例、尺度或含义。

## 核对四种假变化

| 表面变化 | 仍需检查的问题 |
| --- | --- |
| 换配色与图标 | 主体位置、分组和阅读顺序是否仍完全一致 |
| 换标题与词句 | 是否仍是大标题、三条短文、同一组小卡片 |
| 调整几个比例 | 当前证据是否实际获得合适空间，还是只有数值变化 |
| 模板编号为空 | 页面是否仍复刻固定骨架，原生自由绘图也可能重复 |

候选比较必须看真实图，不把设计自述当作效果。封面与困难页各保留两个实际候选，比较哪种更好保留证据与阅读层级，不作抽象“创意”打分。

## 使用portfolio

只比较用户明确提供或当前任务已经生成的工程。先查academic_ppt_portfolio参数，传入实际工程路径；不要凭标题猜路径，也不要搜索其他会话或用户私人报告。

阅读其比较依据、涉及页面和局限，再将实际概览及相关页并列查看。结构相似提醒不能证明抄袭，无提醒不能证明原创性；科学上合理的共同尺度对照仍可保留。需要修改时优先重构与证据不匹配的分组、载体或页序，不为降低数值调整无意义坐标。

## 用真实任务检验技能

需要验证新流程时，让新上下文作者只得到任务、原始材料、参考和技能入口，从空工程制作完整稿。不要把另一作者页面、预先写好的结论或根线程的答案当成输入。可共享经核对的来源文件与出处，不把先前生成的PPT当作新稿的隐性模板。

实际反馈与返工属于协作制作，保存其范围；不能把修订后成功报告为零干预成功率。区分记录重建与新创作，重建相同像素不增加独立模型制作次数。用户宿主模型、账户、PowerPoint/WPS和现场投影只有实际运行才算验证。
