# 每稿独立设计与跨报告检查

## 把不同内容变成不同画面

每份研究先确定核心证据、数据尺度、方法拓扑、不可删条件与来源图特点，再形成design.direction。每页先列必要信息，再设计它们的主次、组合和阅读推进。原图、表格和科学关系决定构图，不能先确定一组页型或组件后只替换文案。

独立设计可以体现在封面重心、读图路径、局部组件、图文邻接、主次面积、方法展开方式与页序。统一字体和色义形成完整报告；不靠每页随机换皮。相同原图或相同比较关系可能需要相同表达，不为降低相似度改变数据比例、尺度或含义。

reference-guided先把参考写成几条抽象原则，再依据本次题名、元信息和证据重新构图。蓝白、细线或居中题名本身并非不可使用；需要避免的是完整搬用参考的比例、标识、装饰组合和页序。封面可以纯文字，通过重心与对齐完成设计，不为展示原创而增加无用途图片。用户明确要求沿用版式时按其范围执行template-faithful，仍不复用旧研究事实和身份。

## 核对四种假变化

| 表面变化 | 仍需检查的问题 |
| --- | --- |
| 换配色、图标或圆角 | 主体位置、分组和阅读顺序是否仍完全一致 |
| 换标题与词句 | 是否仍是大标题、三条短文、同一组小卡片 |
| 调整几个比例 | 当前证据是否实际获得合适空间，还是只有数值变化 |
| 模板编号为空 | 页面是否仍复刻固定骨架，原生自由绘图也可能重复 |

候选比较必须看真实图，不把设计自述当作效果。封面与困难页各保留两个实际候选，困难页保留真实信息量，比较证据、关系和标题层级。再看相邻三页中的承接与骨架复用；短稿按实际页数处理。不作抽象“创意”评分，也不为降低相似度随机拆块。

## 在同一稿中检查构图重复

先把页序表与整稿概览并列看，按实际阅读关系识别页面：配对比较、上下证据链、总览局部、方法与验证、图表联合、综合与收束等。卡片预设名称不同、坐标略变或图左右互换，都不必然形成不同关系。

一幅左图与右侧三卡可以适合某一页，但不应默认承担所有背景、方法、结果与展望。新增图卡后，同样检查是否只是把整稿换成同一种上图下释。发现不同任务长期同构时，回到具体证据：相关子图是否应共同对照，条件能否跨栏共享，解释是否应贴到局部，方法中哪一步需要实际图像；据此重组。

使用[image-cards.md](image-cards.md)的图卡与开放大图、表格、短注释组合，按内容选择。保留同一比较组的共同尺度和结构，不为达到样式数量而改变真实关系。结构统计只定位重复风险；最终结论来自实际页面及其研究任务，不能把“不同ID占比”当审美评分。

## 使用portfolio

只比较用户明确提供或当前任务已经生成的工程。先查academic_ppt_portfolio参数，传入实际工程路径；不要凭标题猜路径，也不要搜索其他会话或用户私人报告。

阅读其比较依据、涉及页面和局限，再将实际概览及相关页并列查看。先判断相似页是否在完成同一比较任务；结构相似提醒不能证明抄袭，无提醒不能证明原创性。需要修改时重构与证据不匹配的分组、载体、局部关系或页序，不为降低数值调整无意义坐标，科学上合理的共同尺度仍保留。

## 用真实任务检验技能

需要验证新流程时，让新上下文作者只得到任务、原始材料、参考和技能入口，从空工程制作完整稿。不要把另一作者页面、预先写好的结论或根线程的答案当成输入。可共享经核对的来源文件与出处，不把先前生成的PPT当作新稿的隐性模板。

实际提问、用户回答与返工属于协作制作，保存其范围；不能把修订后成功报告为零干预成功率。作者应从技能主动获得设计对话流程，不依赖验证者额外提示哪些问题需要问。区分记录重建与新创作，重建相同像素不增加独立制作次数。用户宿主模型、账户、PowerPoint/WPS和现场投影只有实际运行才算验证。
