# 学术组合页：从研究关系到可编辑画面

本接口不生成证据，也不替你推断因果关系。每页先确定要回答的问题、主证据、比较条件和能支持到哪里，再分配空间。完整字段用 `academic_ppt_contract({topic:"slide"})` 查一次。

## 1. 只需两层：行与研究面板

使用 `layout:"academic"`、`section:{number:"02",title:"研究设计"}`。`composition.rows` 是从上到下的行，每行 `panels` 从左到右。weight是可用空间的正数比例，不是重要性评分；工具同时满足真实文字和证据的最小尺寸。默认等权；主证据通常比解释区宽。最多3行、每行4面板、全页8面板。

先按 [visual-decision.md](visual-decision.md) 写本页visualPlan，再分配这些行列；计划记录焦点和阅读顺序，不会自动替你布局。不同科学关系可产生不同结构，用户明确的共同尺度比较也可以保持同构。

每个面板有稳定id与说明其论证职责的title；引用当前页的既有内容：

| 面板字段 | 内容存放位置 | 使用条件 |
| --- | --- | --- |
| `figureIds:["f-a"]` | slide.figureIds以及project.assets | 一幅或两幅真实来源图；保留轴、单位、尺度和必要图例 |
| `plotId:"effect"` | slide.plots | 明确数据的点分布或区间；一页可放不同科学图 |
| `chart:true` | slide.chart | 有意义的类别柱/条图、连续过程折线；不能以折线伪造关系 |
| `table:true` | slide.table | 精确条件、证据对照、指标或文本矩阵 |
| `diagram:true` | slide.nodes/edges/diagram | 流程、分支、汇合、机制、理论与检验关系 |
| `cardIds:["explanation"]` | slide.cards | 紧邻解释，或有具体研究内容的文本/引文面板 |

一个面板只有一种主载体，解释卡可附在主载体下方。每幅图、每张表、每个科学图、每个卡片和整张机制图在本页必须恰好被引用一次；不引用不会自动出现在别处。多项主载体放不同面板。面板不能只填标题。嵌套面板不需要额外box。

`composition.lead` 可放全页共同条件或准确的研究问题。`conclusion:{label,text}` 放最后的有条件判断或下一步决策。不要把所有页都加相同标签：只有共同信息确实存在时才用strip。条件若只属于一幅图，应紧邻该图。旧subtitle/takeaway会完整呈现，相同文字才合并；避免重复提交相同意思。

## 2. 最小结构示例（只有字段，不是研究答案）

下面是**composition子结构**，不是完整slide；f-a和c-a必须已是本次真实图与解释卡的ID。面板题签改成当前研究的具体内容，不复制占位词。

```json
{
  "rows": [{
    "panels": [
      {"id":"evidence", "title":"主证据与条件", "weight":2, "figureIds":["f-a"]},
      {"id":"reading", "title":"证据如何支持判断", "weight":1, "cardIds":["c-a"]}
    ]
  }]
}
```

正文解释卡默认compact，明确的plain/compact也会保留。分组框默认由design.system.panel控制，每个面板可用surface覆盖：inherit / plain / rule / tint / band。plain保留标题和全部内容，只去掉分组家具；rule对应全稿line样式；混合外观仍遵循共同配色与字体。不要给内层解释卡再套学术题签、纸张阴影或模板组件。

panel.align默认为stretch；短旁注可选start，按完整测量的最小高度顶对齐，不再撑满同行。主证据通常保留stretch。start与该面板任何显式card.box或所消费机制节点的node.box冲突，会报告composition-panel-align-box-conflict。需要绝对图框时使用旧figure-focus/figure-split接口，不与composition混用；使用card.box时保留stretch且外框须在本面板正文区内。

这些是局部组件选择，使用场合见 [component-grammar.md](component-grammar.md)。不要把surface枚举当成每页依次套用的新模板。

## 3. 按论证任务组织，不按模板槽凑内容

| 科学任务 | 有意义的页面结构 | 常见错误 |
| --- | --- | --- |
| 界定问题 | 现象或证据主面板 + 已知方法适用范围 + 精确缺口 | 三块泛泛的背景、意义、前景 |
| 比较研究 | 同条件证据并排，方法/样本/终点按行对齐；不齐处显式写明 | 只排几篇论文摘要并在末尾排名 |
| 解释机制 | 概念、变量或实体为节点，实际作用/假设/关联为边；验证紧邻相应关系 | 几个名词框用默认箭头串成因果链 |
| 展示数据 | 主图直接体现核心判断与不确定性，条件和解释位于相邻面板 | 均值提升做大字，跨零区间藏在脚注 |
| 研究方案 | 前置条件 → 并行处理 → 共同测量 → 预定判据；标明未实施 | 把随机、样本量、指标、判据拆成无顺序备忘卡 |
| 理论汇报 | 假设与定义 → 核心构造 → 保证/证明关键环节 → 失败条件 | 用真实论文图装饰，但未解释保证对谁/何种随机性成立 |
| 人文/定性 | 可定位原文或个案并置；概念/编码/解释关系明确，反例可见 | 套用不存在的样本量、实验对照和数值提升 |
| 综合收束 | 已知证据 → 可支持判断 → 缺少的验证/后续动作，逐项对应 | 平级列出优势、挑战、展望 |

“更密”不是“更多字”。有限空间优先用于图形关系、可比较的条件与主证据；具体限定不可删，冗余同义句应删除。较复杂机制用全宽面板，文本说明移入相邻页或讲稿，但决定结论的边界必须在正文可见。

## 4. 可编辑的科学图

`plots`中每项有id、kind、unit、groups、sourceClaimIds，可有caption与reference。

- `distribution`：每组 `{label,values:[显式观测]}`，各组数量可不同。所有点保留，纵向错位只防重叠，不连接独立点，不自动计算均值或删掉离群值。组名旁会按实际values长度标注n，不要在label中重复同一n；如果只画子集，须另行说明子集与总体的区别。
- `interval`：每组 `{label,estimate,lower,upper}`。需要有出处的区间计算，且lower≤estimate≤upper。默认零参考线；其他参考值必须有科学理由。工具只绘制，不能把输入数值自动变成置信区间。
- 同页分布与效应区间放两个`plots`，各由一个panel.plotId引用；共同条件写lead，共同判断写conclusion。两者的单位可能不同，应分别写unit。
- 数据从记录重算时保留脚本、参数和输入版本，claim.metrics记录样本单位、比较基准、分母、聚合和区间定义。只给精确数字而没有口径，不是深度。
- 柱/条图的 `chart.valueDecimals` 可指定标签小数位（0–8），SVG与PPTX使用相同显示精度，原生图表工作簿保留series的完整数值。按测量精度和比较任务选择，不把长浮点尾数当成额外精确性，也不能把需要区分的小量都显示成0；必要时先选择有明确换算的单位。
- 高密散点、回归、空间图、复杂误差模型或生存曲线可用标准绘图库生成证据图，并作为author-created资产登记计算来源；不要强行用当前原生接口模拟不支持的统计图。

每幅科学图一般需要至少约380px宽；高度由组标签、点/区间、轴、单位和图注共同测量。不要把三行长caption放进小半页。关键比较可用两个面板，条件文字精确而简短，详细计算留讲稿与来源。

## 5. 机制图的拓扑先于坐标

`diagram.rows`按阶段/层级列节点ID，例如 `[["input"],["branch-a","branch-b"],["measurement"],["decision"]]`。这只分配节点位置，不创建任何边。用edges逐条明确from/to，可有label和kind：

- flow：有向步骤或有依据的作用关系；并列方法不自动相连。
- feedback：虚线有向回路，说明返回什么、为什么返回。
- association：无向关联，不画因果箭头。

rows需包含所有节点恰好一次，不与node.box混用。可有rowLabels说明阶段或域，但不是每个节点标签的重复。短节点名配必要detail，完整条件可在相邻文本面板说明。换行与节点高度按真实文字计算。跨列映射必须让独立关系能被辨认，不能用重合总线暗示汇合。

## 6. 表格与字体

表格支持columnWeights按列内容分配宽度，以及highlightRows（数据行从0开始）标出当前比较范围。高亮只能帮助定位，不能代替条件文字或把其他记录伪装为同条件对照。

design.system允许受控字号范围，默认正文24px（18pt）、面板标题28px（21pt）、图注18px（13.5pt）。这是一张1280×720的可编辑画布。模板字号超出受控范围时推断会披露适配。不要为了清除错误连续降字号；先去冗余、扩大主载体、调比例或拆解科学任务。

## 7. 先检查记录，再看最终渲染

check中会给出哪个面板缺少载体、遗漏哪个ID、哪段文字需要多高、哪条边穿过节点。集中修这批具体问题，再build/render。不要每改一个词就重新导出。

一份好看的HTML不保证PPTX相同。实际render会提供编号概览和各页PNG。先检查全稿节奏，再看每页的图、单位、结论与源材料对应。有参考时按design.mode检查应保留的字体与层级或用户指定结构；重点看当前证据与解释是否分清主次、关系图是否完整，以及页面是否退化成重复文字区。计数和自动检查不作审美评分。
