# 从研究关系到可编辑画面

先确定页面要回答的问题和必要信息，再设计主构图与局部分组。一个核心问题可包含主辅证据、方法、比较条件、解释和边界；按当前任务取舍，不设固定五块。完整字段查academic_ppt_contract(topic:slide)，不要根据本文片段猜测未列出的字段。

## 流式行列与自由区域

组合页面使用layout:academic。composition.rows按行及面板安排，适合顺序明确的图文关系；composition.regions用每个区域的box安排独立位置，适合上下层次、主辅、跨栏大图、局部解释等自由组合。两者择一，不能同页同时设置，也不与referenceTemplateId混用。多区域不要求并排、等宽或等高，单一完整载体足够时也不硬拆。

先用visualPlan记录主关系、主区域与完整阅读顺序。可选contentLayers为`[{role,panelIds,summary}]`，role取evidence / explanation / conditions / method / synthesis，panelIds引用本页真实面板。一个信息层可对应多个区域，不要求全部角色出现；它是作者声明，不是自动生成内容或原创性证明。readingOrder按当前契约覆盖实际面板一次，上限12不表示应该凑到12个。

主布局之下可继续设计局部关系，例如上部总体比较、下部方法解释，或大图内部的对照组和旁侧条件。独立regions不得重叠；有意义的嵌套用一个区域内的drawing分组表达，不用互相覆盖的独立面板模拟。row/panel的weight只是空间比例，位置与层次都由作者根据关系决定。

| 面板内容 | 来自哪里 | 使用要求 |
| --- | --- | --- |
| figureIds | slide.figureIds及project.assets | 真实原图或有记录的科学图，保留所需轴、单位和图例 |
| plotId | slide.plots | 显式观测分布或有出处的区间 |
| chart | slide.chart | 分类比较或真实连续过程，不以连线暗示不存在的关系 |
| table | slide.table | 精确数据、条件或证据矩阵 |
| diagram | slide.nodes/edges/diagram | 来源支持的流程、分支、反馈或概念关系 |
| drawingIds | slide.drawings | 自主绘制的原生关系、数据标记与局部组件 |
| referenceIds | slide.referenceIds及project.papers | 完整书目，可与相关结论或边界自由组合 |
| cardIds | slide.cards | 当前研究的解释、条件、边界或引文 |

一个区域按契约安排主载体及附属解释；多个相关区域可以共同承担一个证据层，drawing内部也可包含有组织的子组。不要把载体接口当成内容上限，或把每个标签拆成独立区域。每项需要显示的载体须被当前页实际使用；不能填记录后隐去，也不重复消费同一对象充数。精确容量及互斥条件以contract与check为准。

区域保留稳定id和具体title。重复的可见题签可用heading:hidden隐藏，padding在0–24px内按图、表与文字分配，避免嵌套边距挤小主证据。隐藏题签不表示删除重要条件：仍需让听众在相邻位置读到必要语义。

surface控制局部分组，align决定是否收紧；它们不改变科学内容。短旁注可收紧后重新安排余下空间，不能让一条短句占据高空栏。图表自己的边界已经清楚时，外围可以开放；没有明确归属的多组文字可用浅底、题签或细线区分。不同内容不必强行装成等大卡片。

先确定是否需要卡片；图、表、流程和开放旁注可以自行建立结构。确需独立卡片时，默认细描边仍可保留，并按题签/正文关系选择appearance.layout。外层panel已有清楚归属时，可将内层surface设为plain或隐藏重复题签。必要的包含层级保留，无意义套框删除。

composition.lead只放真正共享的条件，conclusion只放值得单独强调的判断。只适用于一幅图的条件就近放置；不要每页机械增加上下色带或重复subtitle/takeaway。

## 自主原生绘图

slide.drawings中的每项有id、内部width/height、元素与可选claimIds。非composition使用时给box；组合页通过drawingIds分配实际区域。内部坐标按区域适配，最终字号和线宽受缩放影响，不能只核对内部fontSize。

元素包括text、rect、ellipse、line和image，均用稳定id。文本可声明title/body/label/note角色；线使用显式points，可有箭头或虚线；图片引用已登记assetId。精确属性查contract。它们用于可编辑关系、分组、表格和明确数据，不能把整页截图冒充原生编辑。

- 文本承担内容，框与底色承担归属；空框和装饰线不当作科学证据。
- drawing的claimIds绑定真实依据，图像来源仍通过资产及paperIds核对。设置颜色、长度或面积前确认其含义，数据图的比例需由可复算数值决定。
- 箭头从实际输出端指向实际输入端。输入、预测、反馈分开端点；标签靠近对应线。折点不是额外科学节点，线的交叉也不默认表示连接。
- 手工绘制数值图时保留单位、尺度与基线；为区间标明它是SD、SE、CI或其他范围。不能用任意线长制造数据。
- 原论文图是独立图片，其内部点和文字不声称可编辑。若重建轴或图例，保存原图及配准依据，见figure-selection。

## 研究任务决定构图

| 任务 | 应在画面建立的关系 | 容易漏掉的内容 |
| --- | --- | --- |
| 方法 | 输入、操作、状态、输出及对应条件 | 反馈更新对象、分支条件、观测与预测区别 |
| 对照 | 共享尺度、不同处理与比较基准 | 分母、信息条件、非独立重复与不可比项 |
| 结果 | 原始分布或趋势、汇总指标、解释与边界 | 不确定性、反向结果、失败条件 |
| 综述 | 来源证据与机制/问题对应 | 不同划分、作物/对象、时间和尺度的差别 |
| 理论 | 假设、构造、关键推导、成立范围 | 随机性对象、条件不满足的后果 |
| 方案 | 真实缺口、公平比较、测量与预定判断 | 尚未实施身份和非成功结果的分支 |

这些关系可以混合在同一页的不同层级中，不是必须复用的六种模板。例如共尺度多图可配同列指标表；方法流程可在关键步骤邻接验证；总体分布可配局部窗口与边界；问题可逐项连接下一步行动。只在这些信息相互支持同一问题时组合，不能为了充满页面拼接无关材料。信息充实依靠证据、比较与解释，不用字数、图片数或分块配额衡量。

## 数值图、表格与公式

原生plots支持distribution与interval。distribution保留显式独立观测，不自动删离群点或连成时序；interval需输入有依据的estimate/lower/upper及定义，工具不会凭空计算置信区间。多图用各自plotId关联。复杂散点、空间图等可用标准绘图库生成有可复算来源的独立科学图资产。

chart的分类、系列、单位与sourceClaimId须准确；valueDecimals只控制显示，不改变完整原值。table按实际内容设置列宽，保留所有必要行、列和对照条件；高亮不构成比较成立的证据。

公式优先使用可正确渲染的原生文本与定位字符；当前能力不能准确保留的公式可作为独立科学资产并保留源。不得把Unicode方框当作成功数学排版。需要本页推理的公式必须有足够阅读空间，详细推导可进讲稿。

## 计高、字号与验收

画布为1280×720px，1px约0.75pt。新稿普通正文/必要标签/辅助注释可从28/24/18px起步，并按材料和投影需求显式声明projection。主要条件不降为note角色，原图像素标签需要另行查看；数字达下限也不保证清晰。

文字放不下先删除同义重复、重新分配区域、减少无用题签或拆任务，不持续缩字。check处理已知几何和内容保全问题后，仍要查看实际PPTX的每页。没有溢出、所有载体被消费或结构不重复，都不能独立证明好设计。
