# 两份用户参考稿：学习整页语法，不复制皮肤

本文是对本次上传文件的设计观察，不是对其科学数据的核验，也不是对全部学术场景的统一规范。原稿含占位文字、占位机构和待核验图文；不得将其当作已核实研究。公共补丁不附原稿、截图、图片或字体。

A：《蓝色-重点项目结题答辩(5).pptx》，20页。
B：《001重点研发计划（太赫兹运用 蓝色）(4).pptx》，19页。

本轮看过A的20页实际渲染概览、B的9页正文实际渲染；重点放大检查A6和B10。原生对象统计只计幻灯片内递归展开的叶对象，不含母版。A6有70个叶对象、没有图片；B7有49个叶对象、没有图片。这说明结构复杂性并不完全来自图片，也不意味着应该追求更多对象。

## A：项目答辩的结构重量

**A3 研究背景。** 深色页眉 → 灰底前提 → 两个证据/问题区域 → 底部需求带。段落、问题、示意图和需求是不同层级；需求带收束的是前面的问题，不只是再写一遍标题。

可迁移：先给研究前提，再将问题与技术响应组织成两组，最后汇合到需求。不可照搬：模板里的患病规模、材料性能、机构与临床结论。

**A6 技术路线。** 同页组织模型建立、两种仿真和实验验证；外框界定总体任务，内部框界定工作包；线宽和色块区分入口、步骤和输出；箭头连接实际对象，而不是每块之间随便画箭头。

可迁移：主流程与验证链分开；分支在相同纵向层级对齐；相关输出汇合到问题；子步骤沿同一基线展开。不可照搬：原稿里的XXX与示例术语，更不能因线条相连就声称有科学因果。

**A10—A12 成果页。** 小标题、研究说明、多个图证和解释组成密集的研究单元。不是“左边一张图、右边三条点”机械重复。图证的面积和位置参与构图。

可迁移：按证据对象分组；相邻图和对应文字同边界；把主要验证图放大；重要结论旁给依据。需改进：部分图片/小字过密，模板图文语义未核验；不能继承后将其当成科学正确。

## B：轻页眉下的分区密度

**B3—B4 背景。** 白底蓝标题和细线形成较轻的外框架；内部使用蓝色题签、浅底板、图像与局部红字。视觉层次来自分区与关系，不依赖所有区域都铺深色。

可迁移：深色只承担题签，浅色承担分组，红色只强调少数关键词；并列图片统一高度，但不拉伸、不裁掉图义。不要把整段都涂红。

**B7 改进路线及局限。** 页面同时放置处理过程和按“样本处理—数据分析—系统优化”组织的解释。真正值得学习的是“一个系统中不同干预位置”的映射，而不是左右两列本身。

可迁移：结构图、问题位置与对应限制贴近；分支与列标题保持一一对应。若没有真实新图，也能用原生节点、关系线和短说明形成完成度。

**B10—B12 方法与证据。** 研究目标带、主图/子图、相邻的技术说明、底部结果共同形成整页；读者先知道看什么，再看证据，最后看意义。

可迁移：原始图证成组、方法说明就近、结论与边界明确区分。B10中的定量指标仅是原稿表述，未取得原论文，不能当作核验结论。右侧Q值关系图与封装定位叙述的关系未获解释，不应擅自补出因果链。

## 与旧样张的具体差距

旧样张常见问题：标题、主图、表格、注释各自漂浮；正文视觉重量小；组内/组间距离未形成稳定级差；同一少量教学数据被分散到多种“风格”里；主要变化是字体、轻导航和布局次序，缺乏被用户认可的整页正样本。

修正方向：先把一页做成完整研究单元，形成导航—命题—证据—解释层级；将相关信息紧凑地组织为组；用色块、线、题签和图像参与关系表达；从一组经用户认可的正文页拓展，不先宣传风格数量。
