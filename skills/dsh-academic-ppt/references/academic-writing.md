# 学术文案：具体、准确、适合讲述

把“去AI味”落实为可观察的修改：删掉空泛主张，补齐比较对象，保留不确定性，让每句话对听众判断研究有用。不要用禁词表、标点规则或同义词替换冒充审稿。

## 先选标题职责

| 页面实际作用 | 合适标题 | 需要防止的问题 |
| --- | --- | --- |
| 提出问题 | “跨站点测试是否改变模型比较？” | 未出结果就写“解决了泛化难题” |
| 交代材料/设置 | “站点、年份与训练测试划分” | 强行把设置页写成宏大结论 |
| 解释方法 | “观测约束进入状态更新的方式” | 只有模型名和箭头，缺输入、变量与验证 |
| 呈现结果 | “本站测试的误差较低，跨站点优势尚不稳定” | 把局部观察推广到所有环境 |
| 讨论限制 | “当前数据不能区分两种解释” | 只写“存在一定局限”而不说影响哪项判断 |
| 推导/定义 | “状态转移假设与观测方程” | 为像演讲金句而删掉数学对象 |

上表为措辞示例，不代表已存在对应实验。实际标题中的事实必须由本次来源支持。

## 改写时补具体信息

| 常见空泛表达 | 修改方向 | 必须回查 |
| --- | --- | --- |
| “AI赋能智慧农业新范式” | 写本研究要预测/识别/控制的对象与现有困难 | 对象、任务和研究范围是否确实存在 |
| “显著提升模型性能” | 写指标、基线、测试条件；无统计依据则写观察到的差异 | “显著”是否指统计检验，效应/不确定性是否有来源 |
| “具有较强泛化能力” | 写在哪些独立地点、年份或群体中检验 | 是否只有随机拆分，是否存在泄漏或同源测试 |
| “构建高效、精准、鲁棒的体系” | 分别说明验证过哪项能力，尚未检验的删去或作为目标 | 速度、准确性、稳健性不能相互代替 |
| “具有重要理论与实践意义” | 写这项结果改变哪种解释或允许哪种有限决策 | 推论有没有越过已验证场景 |
| “未来持续优化完善” | 写下一项检验将区分什么、如何判定 | 是否是可执行方案，是否被误写为已完成 |

有结果才写结果；只有研究方案时使用“拟检验”“计划比较”等准确身份。负结果、失败案例和不足以判断都可以成为有效报告内容。

## 删除重复，不删除证据

依次读页标题、副题、图旁句子、结论带和讲稿。若同一事实出现四次，保留最能服务阅读的位置。图旁文字优先回答“看哪里、比较什么、说明什么、边界是什么”。不用每页都写“核心洞察”“价值启示”“创新突破”。

合并同义句与没有依据的形容词。保留必要背景、技术名词、定义和解释，不把全部正文压成没有主语的短语。列表用于真实并列，条目数量由内容决定；没有第三项就不要凑三，有四项重要条件也不能删成三。

## 中文与中英混排

- 使用该领域自然术语，首次必要时给中英文或缩写定义，同一术语全稿一致。
- 以语义换行。数值与单位、变量与下标、短术语不拆成孤字；不要用空格硬排齐。
- 中文标题可较短，英文结果标题也可是一句完整发现。不以“中文必须对仗、英文必须句子”机械处理。
- 保留规范变量、数学符号和单位，实际查看上标/下标/负号/希腊字母。字体缺字不能通过删除符号解决。
- 讲稿补口头过渡、读图步骤与预期追问，不逐字重复屏幕；关键样本、对照和局限仍须在页面可见。

## 一页最终文案检查

回答：本页在说哪个具体研究对象？哪句话需要来源？哪句话超过来源？删掉哪句话不会损失信息？哪些条件一删就会改变结论？

只有“更有设计感”“去掉AI味”“文字更高级”不是完成标准。把修改落实到具体句子及其与证据的关系。
