# 学术面板与卡片的组合语法

按信息职责设计组件，让主证据、条件、解释与边界形成整体。组件是可重组的局部表达，不是固定整页模板。

## 组件选择

| 组件职责 | 必需信息 | 可以怎样变化 | 不适合的用法 |
| --- | --- | --- | --- |
| 主证据区 | 当前来源图/数据、条件、图注或来源 | 全宽、宽主栏、同尺度并排；常用plain或rule | 在小卡片中缩到看不清标签，或用大数字替代不确定性 |
| 解释旁注 | 对具体证据的解读与成立边界 | 就近放置，可tint + start；按内容收紧 | 与主图等大却只有一句话，重复图标题 |
| 条件条 | 全页共享的实验设置或比较口径 | composition.lead，或setting面板 | 每页固定放背景口号；只适用于一图的条件挪到全页 |
| 对照单元 | 同一比较维度、组别、证据/条件 | 等权面板、原生table、plots中的组 | 为打破重复而给同条件对照不同尺度 |
| 机制区 | 有含义的节点、明确关系与验证身份 | diagram.rows、显式edges、邻接验证面板 | 无序名词串箭头，把假说画成已证实因果 |
| 证据矩阵 | 研究/问题与共同维度的交叉对应 | 原生table，用columnWeights分配宽度 | 把无法比较的研究强行排优劣 |
| 边界或提案区 | 限制对哪个结论有影响，或如何验证 | boundary/hypothesis语义、短侧栏、结论区 | 泛泛“存在局限”“后续研究”；没有来源的确定结论 |
| 综合判断 | 本页证据支持的具体判断与保留条件 | composition.conclusion，或对应综合面板 | 全页重复同一句话，或每页强制加金句 |

## 按语义选择外观

`composition.rows[].panels[].surface`：

- `plain`：保留标题与内容，去掉面板外框、横线和色带。适合有自身坐标框架的主科学图，减少套框。
- `rule`：用细线建立分区。适合开放的证据解释或文本关系，不需要封闭卡片。
- `tint`：浅底题签与边框。适合条件、旁注和边界等需要看出归属的局部区域。
- `band`：主色标题带与边框。适合需要明确辨识的一组研究任务，避免每个层级都用深色大块。
- `inherit`或省略：继承全稿 `design.system.panel`，用于保持用户选定的体系。

同页可混合这些表达，但继续使用共同字体、颜色和对齐。不要为了丰富把所有外观都展示一次。surface只改变分区家具，不会隐藏标题、删正文或产生证据。

`align:"stretch"`（默认）利用同行高度，主图/机制/表格通常适合；`align:"start"`按完整测量的最小高度顶对齐，适合短旁注。start不与该面板内任何显式 `card.box` 或所消费机制节点的 `node.box` 共用，否则返回冲突；需要绝对坐标时保留stretch。start不是自动寻找最佳图尺寸，主证据滥用它可能缩得过小。

## 避免重复的文字层级

面板标题命名整个证据或论证单元，卡片标题命名其中的具体解释。不要把同一句标题写两次。组内文字卡支持plain/compact；它们使用面板的统一空间与字号，避免内层再套题签、阴影和组件。零文字卡片的纯图表或机制页也是完整页面。

目前组合布局最多3行、每行4面板、全页8面板；每面板一种主载体，可附文字解释。每项图、表、图表、机制和卡片只消费一次。这些是执行容量，不是推荐信息数量。超出能力时重组研究任务、拆页，或使用有来源的复杂科学图资产；不要声称可以任意重叠、跨行合并或自由嵌套。

## 层次丰富的判断

看是否能先读到主证据，再找到解释、限定与出处。真实平级对象可以等大；其他内容按职责分配大小。阴影、渐变、图标、徽章和色块不会自动增加学术信息。图表必须有当前数据，强调必须对应已核对的意义。无数据时选择准确概念图或文本对照即可。

若必须分步讲解，在讲稿中设计讲述顺序，或在用户允许的页数内拆成递进页面。当前插件不提供新的动画/转场接口，不在JSON里编造字段或承诺尚未实现的动态效果。
