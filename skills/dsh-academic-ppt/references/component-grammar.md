# 学术面板与卡片的组合语法

按信息职责设计组件，让主证据、条件、解释与边界形成整体。组件是可重组的局部表达，不是固定整页模板。

## 组件选择

| 组件职责 | 必需信息 | 可以怎样变化 | 不适合的用法 |
| --- | --- | --- | --- |
| 主证据区 | 当前来源图/数据、条件、图注或来源 | 全宽、宽主栏、同尺度并排；可开放以突出图的自身结构 | 在小卡片中缩到看不清标签，或用大数字替代不确定性 |
| 解释旁注 | 对具体证据的解读与成立边界 | 就近设计可见卡片，浅底/轮廓配标题与必要图标 | 裸文字散放空栏，或与主图等大却只有一句话 |
| 条件条 | 全页共享的实验设置或比较口径 | composition.lead，或setting面板 | 每页固定放背景口号；只适用于一图的条件挪到全页 |
| 对照单元 | 同一比较维度、组别、证据/条件 | 等权面板、原生table、plots中的组 | 为打破重复而给同条件对照不同尺度 |
| 机制区 | 有含义的节点、明确关系与验证身份 | diagram.rows、显式edges、邻接验证面板 | 无序名词串箭头，把假说画成已证实因果 |
| 证据矩阵 | 研究/问题与共同维度的交叉对应 | 原生table，用columnWeights分配宽度 | 把无法比较的研究强行排优劣 |
| 边界或提案区 | 限制对哪个结论有影响，或如何验证 | boundary/hypothesis语义、短侧栏、结论区 | 泛泛“存在局限”“后续研究”；没有来源的确定结论 |
| 综合判断 | 本页证据支持的具体判断与保留条件 | composition.conclusion，或对应综合面板 | 全页重复同一句话，或每页强制加金句 |

## 区分面板与卡片外观

面板组织一组证据或研究关系，卡片承载其中一个完整解释单元。通常选一层明显容器：开放面板内放有边界的小卡片，或有底色的面板内放开放文字。不能因“避免套框”把所有独立文字组都画成裸字，也不要将每句各包一层框。

`composition.rows[].panels[].surface`：

- `plain`：保留标题与内容，去掉面板外框、横线和色带。适合主科学图或用独立卡片分组的容器；不代表内部卡片也必须无边界。
- `rule`：用细线建立分区。适合开放的证据解释或文本关系，不需要封闭卡片。
- `tint`：浅底题签与边框。适合条件、旁注和边界等需要看出归属的局部区域。
- `band`：主色标题带与边框。适合需要明确辨识的一组研究任务，避免每个层级都用深色大块。
- `inherit`或省略：继承全稿 `design.system.panel`，用于保持用户选定的体系。

同页可混合表达，使用共同字体、颜色和对齐。不要为了丰富把所有外观展示一次。surface只改变分区外观，不会隐藏标题、删正文或产生证据。

`align:"stretch"`（默认）利用同行高度，主图/机制/表格通常适合；`align:"start"`按完整测量的最小高度顶对齐。start不与该面板内任何显式card.box或所消费机制节点的node.box共用，否则返回冲突；需绝对坐标时保留stretch。start只收紧局部，不自动重新分配其下方空区。短旁注收紧后若整页仍空，调整行列结构或扩大真实主证据，不全稿套用start。

## 设计原生小卡片

`design.cardDefaults`定义全稿卡片基线，`card.appearance`逐字段覆盖。新稿主动选择，不依赖旧style恰好产生好看结果；旧项目不设新字段时保留原行为。

| appearance字段 | 支持值 | 用途 |
| --- | --- | --- |
| surface | outline / tint / solid / plain | 轮廓、浅底、强调实底、开放内容 |
| radius | 0–18 | 圆角，统一尺度后可按主次变化 |
| padding | 12–24 | 内容内边距；参与卡片最小尺寸测量 |
| accent | left / top / none | 局部强调边，只在分组或强调有用时使用 |
| elevation | boolean | 轻微层次分离，不用强阴影压过科学图 |

下面只是外观片段，合入包含真实id、kind、title、body和claimIds的卡片；不能用占位正文作为科学内容：

```json
{
  "appearance": {
    "surface": "tint", "radius": 10, "padding": 18,
    "accent": "none", "elevation": false
  },
  "icon": "boundary"
}
```

`card.icon`为可编辑原生线图标，枚举为question、method、evidence、comparison、boundary、hypothesis、satellite、leaf、water、model。选能帮助辨认概念的一个，不把图标作证据或给每张卡强制加图标。图标与padding会占真实空间，放入后检查标题宽度、正文高度和对齐。

开放的主图面板可以与带浅底的读图卡并置；同一侧栏的两种观测条件可以采用轮廓卡；唯一需强调的结论可以实底，旁边的适用边界保持较轻。以上是职责映射，不是三张必须依次使用的模板。不要把每张卡都做成同一种带条矩形。

## 避免重复的文字层级

面板标题命名整个证据或论证单元，卡片标题命名具体解释，不把同一句标题写两次。旧style:plain/compact与新appearance不能混为一谈：style是旧内容排法，appearance决定新外观。外层已明显包住内容时，可用appearance.surface:plain避免多层重复边框；外层开放时，独立解释卡通常需要可见边界。零文字卡片的纯图表或机制页也是完整页面。

目前组合布局最多3行、每行4面板、全页8面板；每面板一种主载体，可附文字解释。每项图、表、图表、机制和卡片只消费一次。这些是执行容量，不是推荐信息数量。超出能力时重组研究任务、拆页，或使用有来源的复杂科学图资产；不要声称可以任意重叠、跨行合并或自由嵌套。

## 层次丰富的判断

看是否能先读到主证据，再找到解释、限定与出处。真实平级对象可等大，其他内容按职责分配大小。卡片边界、图标与主题图片允许参与表达，但不能替代论证或用来刷空间覆盖。短卡片与剩余空区一起设计；框内有大量无用空白时调整内容、尺寸或排列。图表必须有当前数据，强调对应已核对的意义。

若必须分步讲解，在讲稿中设计讲述顺序，或在用户允许的页数内拆成递进页面。当前插件不提供新的动画/转场接口，不在JSON里编造字段或承诺尚未实现的动态效果。
