# 让整场汇报形成论证

先组织研究问题、证据与可支持判断，再安排页数和布局。学术叙事让听众理解每一步为何出现，不要求制造悬念，也不能把不确定证据写成成功故事。

## 一条主线，若干需要回答的问题

用一句话写清整稿如何推进`brief.centralQuestion`，作为`brief.narrative.throughline`。这句话描述研究路径与论证关系；尚无答案时保留问题，不提前编造结果。

将路线分为2–8个`sections`，通常3–5个已经足够。每节写稳定`id`、简短`title`和具体`question`。按材料选择推进方式，不强制各学科套同一页序：

| 报告任务 | 可采用的推进关系 | 关键转折 |
| --- | --- | --- |
| 文献综述 | 同一问题 → 不同研究路径 → 可比证据 → 分歧与缺口 | 为什么这些研究能比较，哪里仍不能合并判断 |
| 论文精读 | 原有困难 → 作者思路 → 验证设计 → 结果与成立范围 | 方法为何解决困难，证据是否排除了替代解释 |
| 研究进展 | 先前目标 → 本期完成的检验 → 新认识 → 下一步验证 | 新证据如何改变原判断或工作安排 |
| 开题与方案 | 有依据的缺口 → 可检验问题 → 设计与评价 → 风险和判定分支 | 什么结果支持方案，什么结果需要改变方向 |
| 答辩与项目汇报 | 核心问题 → 工作间关系 → 各项证据 → 贡献与边界 | 多项工作怎样共同回答问题，而非按完成时间罗列 |

这些是论证方向，不是固定模板。原材料中的失败、反向证据或暂不能判断都应有位置。章节名称可以简短通用，节问题必须让听众知道本报告具体要判断什么。

仅修改单页或单一问题的极短速报时，不为满足2节起点硬拆内容；可省narrative记录，直接用准确页标题、必要定位和讲述过渡呈现路线。用户明确页数与形式优先。

## 从章节到每页

正文页用`slide.sectionId`关联章节。沿用`slide.argument`记录本页问题、作用、贡献和边界，不为叙事再造一份互相矛盾的科学记录。每页至少能回答：本页给了什么证据或必要定义？它改变了听众的哪一个判断？

页标题优先写具体对象、方法关系或有条件发现。一个标题中的主张需要该页证据支持；不能将相关性改为因果，不能从模拟直接跳到田间可用。避免所有标题都只是“背景”“结果”，也不强制定义页或方法页写成结论句。

重要跨节处，把前页如何引出下一问题写入前页`transition`。例如：“这组比较固定了观测条件；下一节检查改变评价尺度后，判断是否仍成立。”只有材料确实支持时才能使用这种表达。不要逐页复制“接下来介绍下一部分”。该字段进入讲稿，不会自动增加画面文字；需要可见提示时，在下一章节页`subtitle`或正文的适当位置写出转入原因。

## 目录、分节与持续定位

较长报告通常需要一个可见路线：例如约8页以上或10分钟左右时，优先在封面后安排`layout:roadmap`。短篇速报可以把路线放在开场说明和页内章节标签中。页数与时间只是设计起点，以实际认知负担和用户要求为准。

在已有`brief.narrative`时，roadmap可直接使用声明过的章节名称和问题。章节页用`layout:section`及`sectionId`定位当前节；正文页也可派生章节标签。渲染器只呈现已声明的结构，不会自动插入章节页、改写论证或创造结论。

只有需要明确换题或建立新比较条件时才增加独立章节页。连续几页属于同一检验时，保留轻量章节标签即可；不要每两页重复一遍完整目录。让章节序号、名称和当前激活项一致，保留够读的问题文字。

已有`agenda.items`可继续使用；若填写`sectionId`或`question`，应与整稿路线一致。优先从同一narrative派生，避免手写多份目录产生错位。自定义composition可自行设计目录，此时不同时设置agenda；仍须实际显示条目及当前定位，不能只在记录中声明。

不要习惯性关闭所有`chrome.showSection`，也不要用品牌字替代研究定位。使用自定义标题区或关闭默认章节显示时，要在本页明确放置同等清楚的节标签。页码帮助定位，完整来源仍按证据要求保留。

## 结尾回应开场

结尾按中心问题作答，把判断与支持它的证据对应，并保留适用条件。对仍缺验证的部分说明下一次检验要区分什么，而不是只写“未来继续完善”。

没有足够证据时，明确回答哪些问题已得到支持、哪些仍不能判断。可以保留简短致谢或讨论邀请，但不能用“谢谢”替代研究收束。复杂综合用composition，保持具体的证据—判断—边界关系。

## 交付前读一遍路线

先只读目录、各页标题、跨节过渡与结尾，再查看整稿概览。确认听众能回答开场问题、当前所在位置、下一节出现的理由以及最后获得了什么认识。

检查章节是否全部得到正文支撑，是否存在孤立段落、重复背景或无交代地返回早先章节。确需回顾时，在标题或过渡中明确说明；重复实验的同尺度比较可以保留一致版式。

工具能检查声明中的章节引用、次序和缺项，不能证明逻辑真的成立。最后仍需结合来源和实际页面判断：故事是否忠于证据，目录是否准确，章节页是否过多，关键转折是否在讲稿与画面中相互配合。
