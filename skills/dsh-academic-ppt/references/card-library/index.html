36种学术信息卡 可选的局部内容组件

从问题、方法、证据、指标、条件和进展中选择合适的表达方式。每张卡片都有独立的内容组织与可编辑原生结构，可与图表、表格和开放文字组合。示例文字与读数只用于展示设计，不是研究结论。

按内容查询 academic_ppt_cards，把选中 ID 写入 card.preset，再填写自己的内容。已有模板时先研究其组织原则；有生图工具时可先按本次内容生成参考，再用原生对象重建。
