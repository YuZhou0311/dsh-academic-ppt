# 把阅读转成学术论证

## 内容主线

先写一个听众可以判断的中心问题，再写暂定回答与尚不确定之处。暂定回答是组织材料的假设，不能提前决定论文“必须支持”什么。每个来源承担一个必要角色：定义问题、说明机制、提供验证、揭示边界或构成反例。满足用户篇数和门槛后不再为增加数量扩检。

给来源建立一次结构化分析，后续通过ID引用，不反复复述全文：

| analysis字段 | 合格内容 | 空泛替代会漏掉什么 |
| --- | --- | --- |
| question | 对象、任务、可判断的问题 | “研究某技术”没有比较对象 |
| gap | 既有方法在哪个条件或环节不足，原文位置 | “精度和效率有待提高”没有机制 |
| mechanism | 输入、操作、输出；改变的环节；为何预期有效 | 罗列模型/技术名称没有解释 |
| design | 数据来源、划分/取样、干预或推导、评价过程 | “开展大量实验”无法判断可信度 |
| unitOfAnalysis | 独立样本/研究单位；重复观测如何处理 | 把图片数、像素数当独立样本 |
| comparators | 真正的基线、替代解释或理论参照；没有对照就注明 | 把最弱方案当唯一基线 |
| validity | 最强支持、关键威胁、不能推出的结论 | 泛泛“仍需研究”没有边界 |
| locators | 实际查过的章节/页/图表/数据行 | 只写“全文”无法复核 |

具体研究可以没有对照实验，例如理论证明、定性访谈或描述性数据集；必须记录其真实论证方法。没有报告某项信息就写“原文未报告，限制是……”，不能为填schema编造。

## 适配学术场景

| 场景 | 主体需要回答 | 优先页面关系 |
| --- | --- | --- |
| 单篇精读 | 难点是什么，方法怎样解决，关键实验排除什么解释 | 问题/机制/实验设计/关键结果/有效性 |
| 文献综述 | 领域按哪几个机制分歧，证据怎样支持或冲突，仍缺什么 | 分类依据/机制比较/证据矩阵/争议与缺口 |
| 研究进展 | 原目标是什么，新增工作提供什么证据，下一步为何必要 | 目标与现状/方法/新增结果/失败诊断/下一步 |
| 开题方案 | 缺口是否真实，假说可否证伪，设计能否归因 | 问题与证据/假说/公平对照/指标与风险 |
| 学位或项目答辩 | 主张了哪些贡献，完成证据是什么，贡献范围多大 | 任务-结果对应/核心方法/验证/贡献与局限 |

不是每次都需要所有页面，不照搬固定页数。原始报告、数据集、方案或学位材料用实际sourceType；没有DOI时填空字符串，journal写实际来源，不伪造期刊。

## 阅读顺序与停止条件

先定位研究问题、总图和结论，再读取方法、关键结果及图注；对准备放入幻灯片的主张查验证设计、附录或source data。保持一份按页提取的文本与来源版本。遇到矛盾回到具体位置，不整篇重新读取。

每个核心来源至少有实质claim被正文使用，且analysis能解释其机制与验证。工具只验证记录完整性，执行者必须核对原文。为了凑“已读”填写章节名和长段套话仍不合格。

用户要求全文而材料只含摘要时，继续尝试合法作者稿/机构库等有限途径；每个来源默认最多两条有希望的获取路线。仍缺失则保存已经取得的证据并说明差额，不解除全文或期刊门槛。需要用户补材料的具体缺口应一次说清。

## 内容与图表覆盖

阅读时建立一份短清单，把关键主张与必要条件对应到原始图、表、公式、方法结构和精确位置。为每项记录拟用载体、页面、需保留的标签与边界；未采用的关键材料说明原因。不要从摘要先写出全套短句，再用原图装饰。

在逐页大纲里先分配该页真正需要的信息，再决定如何组合。一个中心问题可需要主要观察、辅助对照、方法条件、机制解释或边界等多组关联信息；它们可以承担主辅、前后、包含或证据支持关系，不等于每页各放五张卡。没有某种信息就明确缺项或省略，不为做满版面追加事实。

决定结论的信息进入相关主要画面：样本单位、基线、时间与信息窗口、误差或区间含义、反向结果及适用边界。详细推导、参数表和补充检查可进入备注或备份页，但不能把核心条件藏入小字。

结果图保留分布/趋势、必要对照与不确定性；方法保留数据路径、状态更新与验证对象；综合说明证据之间的关系。已有图表能表达的信息不只改写成大数字。没有原始观测时不要重画伪散点；只有汇总值则用准确表格或显式汇总图。

全稿完成后回查清单：信息是否实际显示，组合后是否仍能辨别来源和适用条件，解释是否对应具体观察，缺项是否影响结论。讲稿中存在不等于画面已经表达；字数多、图块多也不等于论证充分。工具的字句检查只是辅助，不能用关键词命中替代完整语义和科学复核。

## 深度来自推导和比较

让推导可被质疑：观察A；由于实验控制了B，支持解释C；但未控制D，因此不能推到E。对照说明因果归因，独立样本和不确定性决定证据强度，适用范围决定迁移边界。

跨论文比较先对齐研究对象、信息条件、任务、数据划分、基线和单位。不同数据集/终点的百分比不能排总榜。可以比较机制与验证覆盖，明确不可比的指标。综述自身的转述不能冒充原创实验。

综合页至少说明两项证据之间的关系：一致支持、表面冲突由设置解释、相互补充或共同缺口。用inference依赖原始claim，并说明另一解释，不能只贴多篇论文摘要。

## 可检验研究方案

将已有证据、具体缺口、可证伪假说、公平对照、评价和外推边界连起来。让比较方法获得相同观测、划分、预测信息、调参机会和计算预算。把信息增益与架构增益区分开。

例：如果改进只在某一分布出现，下一实验可预注册主要终点，保持信息预算相同，设置跨环境留出和去模块对照；相应结果若未达预定方向，假说不获支持。领域具体变量从材料取得，不能沿用此例的数值或假设。

“加入多模态/知识图谱/智能体”只是技术选项。必须解释它改动的机制与验证设计才成为研究方向。

### 判定规则也要接受反例检查

在上页前，用简短草稿走过可能结果：支持假说、支持反向或替代解释、信息不足、评价前提不成立。分支应覆盖当前研究真正允许的结果，不能把全部“非成功”结果合并为“不确定”。例如，对有方向的效应，需要区分明确反向证据与跨越参照值的宽不确定范围；定理条件不满足时，不能自动宣布结论为假；定性材料中反证和缺少材料也不是同一状态。这里检查的是逻辑，不要求所有学科套同一统计判据。

把规则代入一个有利、一个不利和一个模糊结果，检查结论是否符合假说及证据强度。若使用“否则”“证明无效”“不能排除”等词，明确它包含哪些情况。统计阈值与实际重要程度分别说明，后者应有来源或标注为尚待讨论的设计值。没有做过的试验和检验始终是方案，不能写成已获得结果。

这项检查应在批量排版前完成；最终页面、讲稿和计算报告要保留相同的结论分支，不能为了缩短一句话丢掉会改变判断的情形。

## 讲述预算

把时间优先给关键证据与综合判断，同时给中心问题、目录和必要跨节转折留出讲述时间。短报告可以合并导航，不能为了分节数量反复插入空章节页。逐页seconds只是预算，不能宣称已排练。内容多时合并重复背景，保留对结论有影响的条件；补充参数移到讲稿或备份页。用户未要求固定页数时，让页数服从时长和论证负担。
