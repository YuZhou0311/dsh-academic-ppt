# 选题、精读与可检验研究方向

## 1. 用任务约束控制选文

先写 `brief.centralQuestion`：听众在报告结束后应能判断哪个研究问题。再填写听众、时长、篇数、全文条件和用户指定的期刊门槛。用户未要求门槛时不擅自添加，已经要求时不静默降低。

对于“AI 智能体或强化学习用于农业栽培”，检查研究是否真实包含序贯决策、工具执行、反馈更新或策略学习。仅做图像分类、单步预测或使用“智能”名词的文章可以作背景，不能自动占用核心智能体论文名额。

用互补证据组织核心论文：综述提供接口地图，算法实验提供机制与结果，工具系统提供执行和审计，迁移或失败案例提供边界。不要选成五份相似摘要。

## 2. 逐篇记录资格与版本

| 记录 | 具体做法 |
| --- | --- |
| 完整书目 | 核对原文题名、作者、期刊、发表年、DOI 和正式页面；`title` 保持完整 |
| 实际版本 | `version` 写正式版、接受稿或带版本号的预印本；`reading.source` 指向实际材料 |
| 全文状态 | 摘要用 `abstract-only`，元数据用 `metadata-only`；真实阅读全文才用 `full-text` |
| 深读范围 | `reading.sections` 写实际查过章节；`reading.notes` 写补充材料、数据、代码及未取得内容 |
| 期刊门槛 | `impactFactor` 保留数值、指标年、可靠来源和核对日期；不把 CiteScore 或分区冒充 IF |
| 研究类型 | 按实际实验设置选择 `studyType`；混合研究在方法与局限中分别解释结果来源 |
| 贡献与边界 | `methodSummary` 写改变的接口，`limitations` 写具体未验证条件 |

IF 年份与发表年是两个字段。逐篇核查所用年度来源，不能由同一期刊的一条记录自动填满其他年份。期刊指标是筛选条件，不能替代单篇的研究设计、可重复性与主题适配性判断。

如“五篇、IF 10+、全文精读”不能同时满足，先完成已符合部分与候选池，分别列出主题不匹配、指标未核实或全文未取得的差额。需放宽条件时只提出真实缺口，不把缺项改成“已验证”。

## 3. 四轮阅读，每轮留下可核查产物

1. **骨架**：读研究问题、贡献、总图和结论，写出对象、任务及为何需要该方法。
2. **机制**：读算法与接口，解释输入、输出、控制权、环境反馈和时间尺度。RL 另查状态、动作、奖励、约束；LLM 智能体另查规划、工具、数据来源、执行回路与停止条件。
3. **实验**：读划分、图表、图注、基线、消融、独立样本单位、种子、指标与不确定性；将准备上 PPT 的结果逐项登记。
4. **边界**：读失败案例、附录、补充材料和必要代码；比较宣称能力与公开实现，记录版本冲突和未核实内容。

读过正文不代表补充材料或代码也读过。章节清单不是阅读证明，只有真实查阅后才记录完成。逐项结果的规则见同级 `evidence.md`。

## 4. 用中心问题组织页序

给每篇论文一个不可替代的叙事任务，再分配页面。每页主要负责问题、接口、结果解读、失效、机制比较或方案中的一个动作。

每页确定核心句、主证据、必要边界和讲述秒数，分别写入标题/结论、证据与资产 ID、页上文本、`seconds/notes`。不要让“研究背景”“实验结果”成为所有页面唯一信息。

每篇核心论文安排完整题名的 `paper` 页，后续页保留论文 ID，末尾 `references` 页保留完整书目。英文题名不必在讲稿里逐字朗读。

跨论文比较先检查任务、决策接口、信息可得性和验证范围。奖励、产量、人工输出正确率、LLM 评分、审计条目通过率不能放进统一“准确率”排行榜。

## 5. 将研究方向变成可证伪假设

以下六项落在 proposal 证据的 `text/context`、方案卡片和备注中：

1. **已有证据**：原文已支持什么具体结果，引用对应位置。
2. **缺口**：未验证的环境、控制环节、信息条件或失败类型。
3. **假设**：只改变哪个因素，预期改善什么主要终点；什么结果使假设不获支持。
4. **对照**：强基线、移除模块的消融和必要替代机制；核心方法获得相同观测、预测、划分与计算/工具预算。
5. **评价**：主要效果、约束违反、代价、失败；按独立样本单位报告重复和不确定性。
6. **留出**：未见地点、年份、品种或任务；排除未来信息泄漏与调参污染测试集。

示例方案：错误若集中于精确读图，可检验“结构化数据查询绑定数值、单位与样本，能否降低数值错误”。让两组获得相同证据，控制工具预算，分别检查值、单位、样本和证据行。这是待检验建议，不能写成已证实结论。

加入预测数据的模型胜过未得到预测的基线，首先说明额外信息可能有用，不能单独归因为架构。让基线也得到相同信息，或明确本实验研究的正是信息增益。

“多模态融合”“加入知识图谱”“提升鲁棒性”只是技术名词；没有上述字段就继续具体化，不作为最终研究切入点。

## 6. 把时长留给论证

按用户时长分配核心证据与综合方案，章节和参考文献快速经过；复杂方法图保留读图时间。必要边界在页上，补充参数在备注或备份页。

10–15 分钟任务可先编约 13 分钟主稿，并标可省略与扩展段；这是排练起点。用实际朗读校准，不能将字数估算称为排练结果，也不照搬旧案例页数。
