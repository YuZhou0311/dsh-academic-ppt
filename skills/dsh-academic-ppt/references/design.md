# 学术页面的内容承载与视觉设计

## 1. 先确定听众需要判断什么

学术汇报需要让听众理解研究对象、方法和证据之间的关系。页面应能回答一个具体问题，例如“随机化单位是什么”“智能体调用哪些工具”“这个提升使用什么基线”“失败发生在哪一步”。方法与实验页可以使用明确的主题标题；结果页宜写具体发现并保留必要条件。

避免“先确认研究价值”“让证据说话”“把问题变成机会”这类制作者口号。它们没有说明本页包含什么研究信息。“工具链的评分提高至 4.66/5”仍需在页上说明评分类别、评价者与分母，标题不能替代这些内容。

MIT Communication Lab 强调主信息、科学叙事和可解释的图。Penn State 的 assertion–evidence 方法强调论断与视觉证据的关联。二者都不能简化为每页固定三个框。这里采用这些沟通原则，不复制机构模板或品牌素材。[来源 1–2]

## 2. 按内容选择构图

先看 [academic-layouts.md](academic-layouts.md) 的选型方法，再通过 `academic_ppt_reference` 读取具体构图。插件的 48 个原生参考页覆盖 8 类学术任务。`referenceTemplateId` 决定实际对象位置与要求，不能只把它当作标签。

| 需要解释的内容 | 优先构图 | 必须留在页上的信息 |
| --- | --- | --- |
| 论文为什么做、实际做了什么 | 完整题名与关键图、研究范围 | 原文题名、对象、任务、验证身份 |
| 智能体或强化学习如何接入 | 工具路由、闭环、状态动作奖励 | 输入、输出、调用或控制权、约束 |
| 实验怎样产生可比较的数据 | 样本与重复测量、分组、训练测试划分 | 独立单位、处理、样本量、留出条件 |
| 图中什么变化支持结论 | 原图主导、双面板、全图与局部 | 轴、单位、图例、误差、对照与观察 |
| 结果能否归因于某个组件 | 消融、同条件对照、误差分析 | 同一分母、共同预算、差异和不确定性 |
| 局限如何影响研究判断 | 失败过程、测量偏倚、效度审查 | 输入条件、错误步骤、后果与替代解释 |
| 下一步怎样验证 | 假设检验、公平比较、数据计划 | 干预、对照、终点、反证与代价 |

表格用于精确的同维度对应，不能替代原图、流程和机制说明。图表、表格、节点和资产的输入必须在实际场景中出现；遇到未呈现记录应改用支持它的构图或拆页。

## 3. 信息密度需要双向检查

**不足**：标题下只有一两句泛论、数字没有条件、同一句话在三处重复、原图很小而装饰很大、一个短观点占整页。修复时补上必要的方法接口、实验设置、实际图中观察、对照和失败条件，或把相邻薄页合并。不要用大留白代替叙述，也不要添加无关背景来凑密度。

**过高**：页面同时回答多个不相干问题、全部参数平铺、图注占据主图、把讲稿完整塞进正文。修复顺序是去重复、缩短表达、突出同一任务的层次、拆开不同问题、调整图文比例；最后才考虑局部字号。

不存在适用于所有学术汇报的固定“内容占比”“留白率”或每页字数科学标准。本插件的槽位与文字预算是工程约束，需结合原图比例、中文字形、投影条件和讲述速度判断。PLOS 的口头汇报建议也强调受众、内容选择和练习，不能把经验建议改写成普适定律。[来源 3]

会改变结论的仿真身份、实验单位、分母、模型配置、误差区间及未验证范围留在页上。备注容纳定位、补充参数、过渡和追问，不负责藏起科学限定。

## 4. 原图承担证据，原生对象负责解释

开始读图时说明横纵轴、一个点或一条线代表什么、颜色和误差如何定义，然后指出观察及其限制。[来源 1]

复合图先确定支持本页论点的面板，再分配主空间。完整长图可作定位，但局部放大必须足够大，使听众能看清要讨论的关系。优先取得出版方允许的高分辨率图、矢量图或补充放大图；不能用模型“修复”或生成新的科学读数。

当前 `asset.viewport={x,y,w,h}` 使用相对原始图像的 0–1 归一化坐标，原图文件完整保存，PPTX 对图片对象应用裁切视窗。每个视窗使用独立资产 ID，登记同一来源、图号、具体面板与 `cropNote`；不得裁掉会改变解释的对照、坐标、图例或条件。全图与视窗的关系在图注或备注里说明。

原生标签可以重新说明小字、标明观察、给出公式或比较值；原图轴和数据不能被覆盖后冒充原始内容。从正文数值重绘的可编辑图表明确标为重绘，绑定来源证据。原生方法图说明结构关系，不应自称论文原图。

## 5. 模板复用分清整页与局部

调用 `academic_ppt_template` 读取用户实际 PPTX，并查看可取得的预览。记录整页比例、标题区、图注与内容栏，再看题签、边框、分区和层次。保留源文件哈希、源页和组件 ID。

工具把 profile 保存到受控工作区，通过 `academic_ppt_record.templateProfilePaths` 导入 1–4 个返回路径，再选择 `templateComponentId`；不要让模型复制大量几何数据。当前基础导入支持矩形、椭圆、线条及规定组合子集，不导入旧文字。检查 `unsupported`，区分直接提取、按实际观察重建和未支持内容，不能承诺任意复杂 PPTX 无损导入。

用户只要求小卡片时遵循 [revision.md](revision.md)。锁定基线、目标卡片与外框，不把样式任务扩展为重写页面。样式修改保留卡片内容、数值、外框及所有目标外对象和备注；卡内文字坐标可随结构调整。

## 6. 卡片是局部辅助结构

按内容配合使用 `plain`、`ruled`、`compact` 平面文字区与 `academic-panel`、`academic-tab`、`academic-side` 学术细框、题签和侧签。蓝色细框可组织方法与证据，少量暗红适合标记具体差异或错误。留出自然阅读路径，避免仪表盘、产品宣传页或不分语义的连续同款模块。

确有语义需要或用户模板要求时，使用以下结构：

| 样式 | 合适用途 | 应避免 |
| --- | --- | --- |
| `open-frame` | 单一问题或解释区 | 每块文字都套框 |
| `floating-tab` | 短方法名与说明 | 题签高于正文的重要性 |
| `split-label` | 状态/动作、训练/测试等对应 | 长标签挤压解释 |
| `paper-shadow` | 独立证据或引用区 | 重阴影和多层纸片装饰 |
| `title-band` | 少量步骤或结果分区 | 大片纯色标题栏 |
| `stacked-corner` | 来源或层次关系 | 无含义折角和重复叠层 |
| `ledger` | 有单位与条件的读数 | 巨大数字挤掉分母 |
| `dashed-note` | 局限、待验证条件 | 把重要限定降成小字便签 |

无需凑齐样式。固定字体、基线、间距和强调色，让同类信息保持一致；变化应服务内容，而不是单纯轮换颜色。

## 7. 在真实产物上判断质量

检查标题与内容是否一致、信息是否足够、指图顺序是否自然。逐页看全尺寸，连续看缩略图辨认重复，再检查长题名、图例、带单位数字和密集区域。1280×720 场景以 px 表示，渲染器按 1 px=0.75 pt 换算；不能把 24 px 宣称为 24 pt。

HTML 预览与 PPTX 可能存在换行、字体和图片裁切差异。可用时调用 `academic_ppt_render` 检查实际 PPTX。未知视觉能力、不可用渲染器或仅通过结构检查，都不能登记最终视觉通过。任何修订后都应重建新预览，旧截图不用于验收新产物。
