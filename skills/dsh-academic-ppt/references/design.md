# 正式学术页面的构图与文字

## 证据和论证占主要空间

每页先确定主证据和阅读顺序，再确定必要的解释、变量、对照与限定。卡片只是实现元素，不是默认内容单位。按研究关系使用复合证据面板、对齐比较、原生表格、可编辑流程和真实来源图。框、题签和颜色必须表达分组或对照，不能靠装饰填空。

标题直接指出主题、方法或有条件的发现。机制页可以是明确名词短语；结果页可以写证据支持的判断。正文用具体研究语言，去掉“赋能、全面提升、构建体系、具有重要意义”等没有研究信息的句子。

## 封面

cover使用独立构图，不走正文页眉。主标题通常约42pt以上，以可读的自然断行形成中心；长题通过cover.titleLines规划，每行文字必须忠实于slide.title。副题只解释范围，避免再重复标题。

署名、单位、场合、日期只写用户材料已给信息，未知则省略。有design.system时用framed/project/minimal选择，系统字号进入实际封面；无system的旧工程继续formal/minimal。不要自动放第一篇论文题名、13分钟汇报、参考文献脚注或制作说明。正式感来自明确层级、对齐和克制的主色。

## 文字与空间

场景坐标为1280×720 CSS px；导出为13.333×7.5in，1px=0.75pt。不要把px当pt。默认标题约30pt、正文约18–19pt、图注约13.5pt；根据用户模板和放映条件调整。当前渲染器字宽是保守估计，实际中文字体、粗体和英文长词都需最终查看。

内容超框时按顺序处理：删除与图/标题重复的解释；改为更准确短句；调整图文比例或受控区域；拆成两个论证任务。不能截断、隐藏文字、删科学限定或不断缩字号来通过检查。

使用claimIds指向原始证据，把较长的补充推导放notes。会影响听众判断的比较基线、模拟身份、单位与范围留在页上。notes是可讲述的解释，不是照抄页上每个字，也不写“本页用了某工具”。

## 图像、流程、表格

论文原图优先完整contain。图像职责、必要元素和最终标签可读性见figure-selection。密集多面板常需要局部证据+定位图或拆页；不能以裁掉图例换取更大标签。

流程节点表达真实研究机制。箭头需说明数据、时间、计算或因果关系，不能把一组无序名词串成流程；并列策略用并列分区，反馈闭环必须画出真实回路和方向。颜色、文字与结构共同区分方法、设置、观察、边界和假说，不让颜色表示未经证实的好坏。

表格只承载需要精确对应的信息，行列来自当前证据。长文字对比用少量行和完整条件，不做字海。实际数据不足时不用装饰性数值图。图表通过sourceClaimId、表格通过sourceClaimIds绑定来源，绘制前检查比较口径一致。

## 布局选择

新稿优先使用 [composition.md](composition.md) 的学术组合页，不必先查询旧48页型。多个科学图用plots+plotId，机制阶段用diagram.rows，面板结构由论证关系决定。以下规则用于确实适合固定槽位的旧页型。新页眉长标题与旧固定槽位冲突时，转为composition或精简重复标题，不能强压正文。

调用reference前先回答：本页属于哪种研究任务；主图横纵比例与标签限制；需要多少独立解释。最多比较两个有依据候选，选择能保留证据的一个。单纯“排名第一”或“看起来高级”不构成理由。

默认figure-focus适合一图+短解释，comparison适合真实对照，method适合机制关系，results适合证据展示；更精确区域由referenceTemplateId提供。选择后必须满足layout和数量约束。

参考页有panels时按当前材料填写一一对应的panelTitles。题签应说明当前图或比较的身份，不能继承示例的“闭环”“终点”等科学判断。正文来源采用与参考页一致的全局编号；完整书目留在参考页与备注，参考分页连续安排。

无固定参考时，figure-focus / figure-split可用figureBoxes，图框与figureIds一一对应，所有cards必须给box。图区处于x36–1244、y132–658且不能相互覆盖。改自由图框前移除referenceTemplateId，使用edit的removeFields，不写null或伪造schema字段。

## 节奏与密度

连续三页同构只是一项提醒：连续结果对照可能合理。不要为了多样性换皮，也不要把所有论文拆成同样“背景/方法/结果”三张介绍页。章节页只在长报告需要停顿时使用。

缩略图下检查是否有清楚中心；原尺寸下检查听众能否读懂真实证据。如果一页只有泛泛三点且大片空白，应补机制或证据或合并；如果一页拥挤，应拆任务而非全面缩字。机械的卡片数量、留白比例和评分不决定学术质量。
