# 模板、页面与小卡片设计

## 1. 从模板提取关系

调用 `academic_ppt_template` 读取实际 PPTX。同时查看可取得的模板预览：对象清单揭示形状，视觉预览揭示留白、比例、层级与阅读顺序。

分三层记录：整页比例与标题区，主图/图注/内容栏，题签/边框/分区/叠层/投影。保留源文件哈希、源页和组件 ID。工具把 profile 保存到受控工作区，随后用 `academic_ppt_record.templateProfilePaths` 导入 1–4 个返回路径，再通过 `templateComponentId` 应用组件；不让模型复制大段形状几何。

当前受控导入只支持矩形、椭圆、线条及规定组合子集，不导入模板旧文字。检查 `unsupported`，不要假定复杂媒体、SmartArt 或特殊效果可无损复用。区分“直接提取”“按模板关系重建”“未支持”，不能用同色背景充当深度复用。

不能完整导入时，仍可据实际观察的字体层级、图文比例、对齐和组件关系重建可编辑对象。不要未经说明将原模板整页截图设为背景。

## 2. 让页面结构服务证据

| 任务 | `layout` | 组织重点 |
| --- | --- | --- |
| 建立问题与主线 | `cover`、`roadmap` | 中心问题、范围与预期判断 |
| 引入论文 | `paper` | 完整原文题名、作者/期刊/年份/DOI 与研究任务 |
| 解读原图 | `figure-focus` | 大图为主，短说明指向具体证据 |
| 图与解释并置 | `figure-split` | 适配原图比例，保留设置和边界 |
| 对照机制/结果 | `comparison` | 同层面比较，成对呈现基线与改变 |
| 解释接口 | `method` | 节点、方向、输入输出和控制权 |
| 定量发现 | `results` | 数值、单位、分母、条件一起读 |
| 跨论文归纳 | `synthesis` | 接口、证据范围与共同缺口 |
| 实验方案 | `proposal` | 假设、对照、消融、终点与反证 |
| 收束与来源 | `closing`、`references` | 回答中心问题，完整书目 |

先选任务再选版式。不要每篇都机械套“背景—方法—结果—不足”的同款卡片页。表格承载精确映射，不能承包流程、机制、原图证据和失败案例。若所选页型不支持某项图、卡片、图表或流程，改用相应页型或拆页；不能留着未呈现的输入后声称内容完整。

`paper` 页题名原样完整。后续页可用简洁来源行，完整题名仍在备注；参考文献由调用方按可读数量分页，不依赖隐藏自动分页。

## 3. 八种小卡片结构

| `style` | 结构语法 | 优先承载 |
| --- | --- | --- |
| `open-frame` | 开放细框与清楚题签 | 问题、概念、单一切口 |
| `floating-tab` | 浅底区域配浮动小题签 | 方法名称与简短说明 |
| `split-label` | 左短标签、右解释 | 状态、动作、目标、训练/测试 |
| `paper-shadow` | 白纸层与克制投影 | 实验结果和证据 |
| `title-band` | 窄标题带与正文分区 | 方法步骤、结果说明 |
| `stacked-corner` | 角部错位原生轮廓 | 范围、来源与层次 |
| `ledger` | 标签、读数、说明分区 | 分别统计指标和带单位数值 |
| `dashed-note` | 轻虚线便签边界 | 局限、失效与待检验条件 |

不强制八种全部出现。依据 `kind`、内容与长宽比选择；同类信息重复结构有助比较，动机、结果和局限可有不同层次。不能为了变化让同一角色失去一致性。

固定字体、基线、间距和强调色关系；变化落在题签位置、内容分区和框线构造。避免重阴影、大折角与无意义编号占掉正文；证据必须比装饰显眼。

## 4. 密度与几何预算

检查“标题高度 + 段间距 + 正文高度 + 上下留白 ≤ 卡片高度”。左右分区分别预算，浮签、折角与阴影也留在允许范围内。宽矮卡片选轻边框或横向分区，不硬压高题签。

画布使用 px，PowerPoint 文本使用 pt；本渲染器按 1 px = 0.75 pt 换算。配置的 24 px 不是 24 pt。字号要结合实际预览、字体与观看条件判断，不能用单一最低数值保证所有图注可读。

密度不足时补方法接口、设置、基线、图中观察或失败条件。过高时先拆任务、去重复、短表达、分项，再调图文比例或移到备注；不能优先缩小所有文字。

会改变判断的仿真身份、样本单位、分母和最佳配置等限制留在页上。备注容纳补充参数、定位和追问，不用来隐藏证据边界。

## 5. 先验证风险代表页

新建时选覆盖长题名、方法图、结果图和密集卡片的少量页。局部任务先选用户指出位置，再加最矮卡片或最长正文；按风险选择，不机械固定数量或每次等批准。

看全尺寸文字/图注、连续缩略图的节奏/重复和讲述时的指图顺序。修复后重建新预览，禁止以旧截图验收新文件。

材料未齐的样页可用 `mode: draft`，但必须保留草稿身份。完整汇报用 review 构建检查证据门槛，不能以草稿路径绕过用户要求。

SVG/HTML 与 PPTX 共用场景仍可能有字体、换行和渲染差异。可用时调用 `academic_ppt_render` 检查真实 PPTX；仅检查预览时明确范围，不扩大为 PowerPoint/WPS 显示已确认。

## 6. 将“高级感”转成可观察改动

具体诊断题签层级、边框重复、数值分区、图像大小或留白分配，再给局部改动与前后对照。更多颜色、装饰和卡片不自动等于设计更好。

用户只说小卡片时遵循同级 `revision.md`；样式编辑保留卡片内容与外框几何，卡内文字坐标可随结构调整。文字或数据结构确需变化时用明确的内容修改任务，不能混进样式补丁。
