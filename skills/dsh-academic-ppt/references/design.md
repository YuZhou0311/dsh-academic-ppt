# 学术视觉：封面、颜色与阅读层级

## 从本次材料形成设计方向

用`design.direction`记录听众、阅读场景、来源图特点和信息关系，并依据[visual-decision.md](visual-decision.md)中的完整逐页设计稿建页。全稿统一字体职责、颜色含义、线宽与间距；主载体、分组和阅读方向按研究任务变化。答辩兼复读需要让证据、普通解释和必要条件共同可见。

reference-guided只迁移有用原则，例如题名主导、白底深字、元信息分组、对齐和留白。重新设计当前题目与材料的构图，不整体复刻参考的横条比例、校徽位置、装饰箭头或背景纹理。仅有封面参考时，不能把它推成全稿统一的大横幅或图文比例；用户明确要求沿用版式时按指定范围执行template-faithful。

## 选择学术色板，说明颜色职责

从`academic_ppt_contract(topic:design)`返回的`academicPalettes`取得学术色板候选，将选中项的完整`palette`写入`design.palette`，按实际图表、场合和阅读层级调整。深蓝石墨、墨绿暖灰、靛蓝冷灰、酒红中性灰等都可形成正式方向；候选是设计起点，不是学科标识或某机构认证。不要机械执行“农业必绿、AI必蓝紫”，也不要求所有报告只用蓝色。

| 角色 | 用途 | 选择约束 |
| --- | --- | --- |
| 背景与纸面 | 承托图文，保留图表自身结构 | 以白色或近白色为主，不靠渐变和纹理填满空间 |
| 正文与注释 | 稳定阅读层级 | 正文为深色，注释也须可读；关键条件不能变浅灰小字 |
| 主色 | 标题、章节定位、少量强调 | 一套稳定主色即可，不将每个区域涂成宣传色块 |
| 辅助色 | 必要的对比、边界或少量强调 | 用量克制，避免多种高饱和色同时竞争 |
| 边界与浅底 | 表达局部分组 | 灰蓝或中性灰细线、极浅底，不用重阴影制造层次 |
| 数据系列 | 区分真实变量、方法或处理组 | 根据可辨认性与比较任务安排，不等同于页面装饰色 |

用`design.colorRoles`明确有意义的颜色对应。同一变量或处理跨页保持一致，保留原图数据色的原义；关键区别同时使用文字、标记或线型。不要把更红、更大、线更粗默认解释成效应更强。检查最终文字对比和图例辨认，不能仅凭色板名称声称可读。

## 封面默认文字主导

完整研究题目是第一视觉焦点。按已有信息组织报告类型、题名、必要副题、研究范围与报告人、单位、日期，设计题名承托以及各组的主次、邻接和留白；副题只补充范围，不重复主标题或塞入长摘要。用语义断行、字重、间距及有职责的原生线、题签或局部边界建立关系；简洁不等于删除所有层级，也不要求加图或装饰。

默认不放封面图片。只有图像能明确识别本研究对象、装置、场景或核心方法时才加入，并检查来源与用途。泛农业航拍、芯片、地球、AI脑图不能只因关键词相关就填入封面；留白不是寻找装饰图的理由。纯文字封面可以完整成立，不需要象征性大图标证明“有设计”。

先比较两个实质不同的封面候选，检查题名承托、主副题和元信息分组如何形成不同的主次与阅读关系。同一组文字仅从左对齐切到居中不足以成为另一候选；若同时重构了信息主次或组间关系，依据实际画面判断。两者都可以无图，不预设封面模板、比例或元素数量；只换颜色或小幅移动同一组框不算另一个方案。

使用当前受支持的`cover`变体，需自主安排时使用`variant:custom`及角色`boxes`。`cover.titleLines`保留完整题名。`presenter`、`affiliation`、`occasion`和`date`未知时省略，不借用参考身份，不保留没有内容的占位框。

`cover.assetId`属于语境视觉，只能引用对应用途的已登记资产。科学证据原图以证据身份登记并保留出处；真实场景、实验样本与生成插画不能相互冒充。`drawings`可支持原生封面设计，但不得制造没有来源的科学主张。

## 页标题与可见章节

先区分三种职责，再决定需要哪些层级：章节定位说明全稿位置；页级题名说明本页对象、方法关系或有条件发现；局部题签命名证据组、条件或步骤。方法和定义页可用精确名词短语，结果页使用证据支持的判断。没有必要的层级可省，同一句话不要重复出现在章节、标题和面板三处。整稿路线见[storytelling.md](storytelling.md)。

标题的设计包括承托形式、位置、对齐、字重、语义断行和重点的选择，不只是字号。可用有职责的章节题签、窄色带、规则线或开放标题，不从参考复制固定比例。色带可以帮助定位，但不能机械装饰每一块。使标题占用的空间与其职责相称，为主证据和普通解释留下可读面积。完整论文题名在书目保留，正文标题无需照搬题名。

用`slide.heading`安排标题区域、语义断行和必要强调，留足真实行高。自定义heading默认不继承chrome，以兼容旧稿；要显式保留当前章节/身份与band或rule，设置`heading.inheritChrome:true`，同时自行安排不冲突的标题box。继承不自动移动对象或缩字，检查冲突后调整真实区域。

`chrome`帮助听众辨认章节、页码和来源。删去无用品牌字、重复题签或装饰横线时，保留研究定位。选择不继承时自行安排必要章节标签；隐藏页脚后仍在图注等位置保留必要出处，完整引用和讲稿不删除。

## 卡片有清楚边界，分组有内容理由

先判断内容是否需要卡片。对照图组、方法图、时间线、指标表或局部注释可直接形成结构，不全部包入卡片。需要独立条件、解释或边界卡时，按[card-design.md](card-design.md)查询36款原生设计，选择能表达当前内容关系的`card.preset`；它们分别处理题签、逐项条件、指标读数、对照、步骤与限定。旧`appearance.layout`仍可选择stacked、banded或side-label，与surface分开设计。同组保持一致，不随机轮换组件。

既有卡片默认细描边、小圆角、适量内边距、`accent:none`、`elevation:false`；默认不是整页构图指令，也不是新卡片设计的唯一风格。浮签、双线、折角、侧栏、编号锚点、标题带和读数分隔可按任务使用，先改变内容的层级与阅读关系，再决定边界形态。描边应在实际投影尺度可见，但不比标题和数据更抢眼。题签带用于标识归属，不能变成所有文字上方的粗宣传条；具体组件见[component-grammar.md](component-grammar.md)。

宿主生图可用时，先按本次汇报内容生成少量卡片设计参考并实际查看，提炼可用关系，再用原生文本、线框、数值和受支持的图形重建。生图参考不是最终信息卡、科学证据或可编辑性的证明；没有接口或调用失败就用原生目录继续。不要为采用参考轮廓删掉长条件，不要把36款变成必须使用的数量指标。

外层已有明确分组时，内层可显式使用`surface:plain`；图旁注释靠邻接和对齐已经清楚时也可开放。新增边界须表达真实归属或包含关系，删除无意义套框，不要求每段文字描边，更不把图、表、公式全部装进等大的卡片。具体组件见[component-grammar.md](component-grammar.md)。

## 按文字职责保留中间层

先建立本稿的字体职责表，再排版；记录位置是设计工作文件，映射到当前contract支持的system、heading、card与drawing字段，不提交自造字体角色枚举。

| 职责 | 设计处理 | 在最终画面核对 |
| --- | --- | --- |
| 章节定位 | 简短、稳定，可用题签、序号或页内定位 | 足够辨认，不与页题争夺重心 |
| 页级题名 | 完整语义断行、明显字重与必要承托 | 与本页对象/判断相符，不挤占正文 |
| 局部题签 | 按真实组别或阶段命名，与同级对齐 | 与页题和正文有区别，不重复命名同一组 |
| 普通正文与解释 | 连续句或真实并列项，保留方法限定与证据解释 | 在主视图可读，有足够行宽与行距 |
| 数据读数、轴与图内标签 | 对齐数据和比较尺度，突出少数真正关键读数 | 单位、负号、变量和误差含义清楚 |
| 来源与辅助注释 | 轻于正文，按引用职责安排 | 仍可读；不能承接主要条件或结论 |

有依据的结果区可用局部题签指出需要核对的比较或特征，例如校准案例的“修正后残差收窄”；把“每点为一个独立样本”等编码说明贴在图旁作为普通说明。方法和条件区用准确对象名称，无可靠判断时不强写结论。对承担局部论点的相关表列、曲线区段或读数做有限强调，让读者能就近核对依据；不将所有内容同时加粗或着色。

1280×720场景中1px约0.75pt。28/24/18px是既有正文/标签/注释默认值，不是所有新稿的共同目标。制作前依据参考的真实字级、最终观看尺寸和材料选择阅读策略：当前projection契约允许bodyMin为22–40px、labelMin为18–36px、noteMin为14–24px；这些是各职责的检查下限，实际字体还要形成层级。system控制受支持的共同字号，自定义对象在契约允许范围内设计。

例如答辩兼复读可以在代表页上比较24px普通解释、20px图内标签与16px来源的实际阅读，配套的projection在排版前明确为24/20/16；远距离短讲可能需要更大。此例仅说明不同职责可以有中间字级，不能直接套给所有报告，也不能在失败后改低projection清除提示。先调整区域、无用重复和行宽，再判断字号；仍不清楚时重新组织或拆分任务。

绘图文本title/body/label/note按实际内容职责使用。样本、基线、主要条件和边界不得伪标note，原图的像素标签也不套用原生文本的检查结论。中文粗体、长英文、上下标、负号和最终缩放后的字形均需实际渲染查看。

## 按页面职责审查留白

正文用真实图、表、关系和必要解释形成完整论证，重点检查主证据过小、内容挤在上半页、短句占高空栏和解释远离图表。先恢复遗漏信息，再调整主次比例、组内邻接和组间距离；可以上下分层、主辅、嵌套、跨栏或局部穿插，不预设多栏等宽。回收无用边距，必要时合并重复页面或拆分复杂任务。正文`compact`要求仍有效，不能改为`balanced`消除失败。

封面、目录与分节页承担题名、定位和转折，允许有目的的留白。对它们的空间提醒通过实际画面判断，不按正文占幅去补图、堆元信息或拉大空框。保留有用的呼吸空间与分组距离，也核对标题重心是否失衡、导航是否过小。

## 结尾与整稿节奏

结尾对应开场问题，将可支持判断、证据和待验证条件重新收束。可用证据—判断矩阵、清楚的结论与边界或下一检验设计；不默认三列宣传式短文，也不用大字“谢谢”替代回答。复杂综合使用composition，不与原生closing对象混用。

看完整概览和最终PPTX每页。科学上需要共同尺度的比较可以保持结构；不同论证任务要获得适配的载体和阅读路径。科学含义、导航、可读性与视觉秩序清楚后停止装饰性返工。
