# 内容适配、留白和深浅层次

## 空间要有具体作用

| 实际画面 | 判断与处理 |
| --- | --- |
| 封面题名、身份和上下分组之间的留白 | 保留层级；核对题名醒目，不为填空加无关图 |
| 短卡只有两行文字，外框底部大片空腔 | 按当前宽度测量并收紧；重新安排相邻信息，不平均填满卡片高度 |
| 同一实验的等高比较卡，内容长度不同 | 等高可支持比较；先对齐对应字段和共享条件，仍保留空区时说明比较作用 |
| 主图很小，短说明占满大面板 | 扩大主图、收紧解释区，考虑上下、带状或跨栏关系；保留原图比例和标签 |
| 卡片收紧后整页下方仍大空白 | 重新分配图文区域、行权重和解释位置；卡片尺寸正确不代表整页完成 |
| 原图内部的轴、图例、面板间距与科学尺度 | 保护原图；不能把科学图内部留白机械当成浪费，更不能裁掉坐标或对照 |

留白应服务于具体分组、阅读顺序或重点。不要用固定填满比例代替判断，也不要用“极简”掩盖主体过小、卡片过高或阅读断裂。

## 卡片适配顺序

1. 按本页科学关系确定组件职责与实际可用宽度。
2. 使用真实标题、正文、指标、限定与图重排，测量自然高度，保留必要字号和内边距。
3. 文本卡随内容收紧。图槽随目标区域适配，原图达到有效宽度后停止无效增高；图片 contain，不拉伸、不自动裁科学数据。
4. 只有刻意保持比较尺度时设置 card.box 或 mediaHeight。示例尺寸不是成稿固定尺寸，先删除复制来的无依据约束。
5. 再检查整页主次、空区与相邻页节奏。可以合并重复页或重组内容，不能编造证据填空。

preset 控制内部关系，appearance.layout/surface 不覆盖 preset 内部 recipe。要改变内部比例、分区或文字色时选适合配方，或用 drawings 与 composition.regions 重组，不能依赖被忽略的参数声称已改变版式。

## 深中浅的职责

`contract(design).academicPalettes` 的 surfaceOptions 提供可执行方案。默认深色题签建立结构、白色正文承载证据；选色仍由原图、场合和真实用户偏好决定。

| 处理 | 职责与细节 |
| --- | --- |
| 开放白底、无填充边界 | 主证据、跨图比较、未确定范围；靠对齐、实线或虚线表达关系，不给每个字块套框 |
| 中间明度的局部面 | 共享条件、方法阶段、次级组；面色比近白明确，正文保持对比，不抢主图 |
| 深色题签＋白色正文 | 实验模块、同级任务、方法组件；band 仅填题签，嵌套卡不重复加深条 |
| 少量深色重点面 | 核心问题、关键结果、收束判断；用清楚浅字，复杂原图与长表格保留清晰纸面 |

不设每页必须多少深色块的配额。全浅色可能缺乏重点，全深色也会混淆主次。深浅层次应在概览中帮助辨认章节、证据和结论，同时保留多样版式。

颜色一致指意义一致，不要求每页同样填色。原图颜色的变量含义保持不变；不能无依据用颜色暗示方法或结果优劣。区别同时使用文字、线型或标记。

## 在实际渲染上复核

看全稿概览和每页可读尺寸画面，放大密集卡片与图表。对比计算只辅助已知背景上的文字，图片、叠色和混合背景必须实际看图。

spaceCheck 说明最大空区、卡内空间和主体占幅，例如：“右侧方法卡按三行正文收紧，下方安排共享条件；主图标签在整页尺度可读。”colorCheck 说明深中浅职责和实际对比，例如：“深蓝题签对白字清楚，原图白底，灰蓝条件区用深字；数据系列颜色原义保留。”不能复制“留白合理、颜色专业”覆盖全稿。

当前 reviewTargets 逐项写 diagnosticChecks 的 targetId / decision / reason；decision 为 intentional 或 needs-fix。有意保留须解释具体阅读作用；实际缺陷先修复、重建和重渲染，再以当前目标和哈希审查。用户接受也不能覆盖作者已知但未修好的缺陷。
