# 分布先行与主次对比

原十二页版面实验第 4 页。配色方向：酒红 / 暖灰。它是助手编排的构造数据案例，非 DSH 模型端到端实测；用户认可了这批样张的总体方向，不代表本次新报告已经获批。

## 先看画面，再学决策

打开同目录 `preview.png`（实际独立 PPTX 渲染），不要只读这段文字。阅读次序：先读站点异质性，再看汇总区间。

**核心决策：**主体分布与汇总承担不同职责，空间不均分；弱化不改变解释的重复数值。

**适用：**观众需要理解总体结论是否掩盖个体差异。

**不适用：**只有汇总数据时不能制造站点分布，不确定关系不可变成因果箭头。

## 换材料必须重新决定

新数据有离群点或区间冲突时保留它，不能把案例中的判断复制过去；正文增加时重排侧栏而非缩字。

先列本页必须保留的证据、条件、单位和边界，再确定视觉锚点、区域比例、对齐轴与颜色职责。案例的坐标、字号和配色是这份材料的选择，不是默认阈值。至少写出一个本次保留原则和一个因新材料改变的地方；不是强行凑不同。

不能用换色、换标题、微移文字框冒充重新设计。也不能为了使新稿更清爽而删除误差、对照或不利结果。正样本不是固定整页模板。

`input.json` 是 `renderProject` 的直接绘图测试输入，不是已经通过研究/用户批准/交付流程的 `project.json`。没有真实论文 claim，不得拷贝为当前报告的科学记录；生产工程仍用 `academic_ppt_record` 的完整契约登记真实内容。
