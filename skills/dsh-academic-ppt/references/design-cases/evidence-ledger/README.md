# 读数与图形共享行

原十二页版面实验第 7 页。配色方向：赭金 / 炭灰。它是助手编排的构造数据案例，非 DSH 模型端到端实测；用户认可了这批样张的总体方向，不代表本次新报告已经获批。

## 先看画面，再学决策

打开同目录 `preview.png`（实际独立 PPTX 渲染），不要只读这段文字。阅读次序：从对象、读数沿同一行读到共同尺度图。

**核心决策：**精确表与图形融合成共享行比较区，视觉归属来自行基线；不是给表格换皮。

**适用：**既要看趋势，也要逐项复核读数的结果页。

**不适用：**不可比指标或单位不同的量不能挤进一条共同数轴。

## 换材料必须重新决定

增加指标时确定主指标与附列；保持同尺度和行对应，标签长时扩首列，列数过多时拆任务。

先列本页必须保留的证据、条件、单位和边界，再确定视觉锚点、区域比例、对齐轴与颜色职责。案例的坐标、字号和配色是这份材料的选择，不是默认阈值。至少写出一个本次保留原则和一个因新材料改变的地方；不是强行凑不同。

不能用换色、换标题、微移文字框冒充重新设计。也不能为了使新稿更清爽而删除误差、对照或不利结果。正样本不是固定整页模板。
