# 从段落到共享比较

这是原创教学数值，不是真实研究。观看左、右两组相同信息：左侧是分段叙述，右侧的 comparison 按指标共享行。右侧得到更多面积，题签/底色服务于读数，而非做两张同权卡片。

重用的是比较关系：方法变为三种就增加 items 和每项指标的 values；没有误差或耗时数据就不补造。单位不一致时不能放在同一指标行。extent:content 只收紧实测文字高度，不删条件、不缩字号。标题必须随真实数据重写。

输入 request.json 经普通 init/plan/build/render 工具生成；input.json 是编译结果，仅用于重建。不是真实模型端到端测试。
