# 主证据与支撑底栏

原十二页版面实验第 10 页。配色方向：深紫 / 薄荷青。它是助手编排的构造数据案例，非 DSH 模型端到端实测；用户认可了这批样张的总体方向，不代表本次新报告已经获批。

## 先看画面，再学决策

打开同目录 `preview.png`（实际独立 PPTX 渲染），不要只读这段文字。阅读次序：先看大幅证据，再看底栏条件与原始读数。

**核心决策：**主图成为视觉锚点，支撑信息集中但不缩成不可读脚注；暗色背景与数据高亮分工。

**适用：**投影对比条件适宜，主结果适合大图且支撑信息较少。

**不适用：**必须原样保留的多幅白底图或密集表格可能更适合浅色；不为风格牺牲对比度。

## 换材料必须重新决定

源图是白底时允许保留白色图面；不反色科研图；增加限制时重排底栏或改浅色页，而非藏到notes。

先列本页必须保留的证据、条件、单位和边界，再确定视觉锚点、区域比例、对齐轴与颜色职责。案例的坐标、字号和配色是这份材料的选择，不是默认阈值。至少写出一个本次保留原则和一个因新材料改变的地方；不是强行凑不同。

不能用换色、换标题、微移文字框冒充重新设计。也不能为了使新稿更清爽而删除误差、对照或不利结果。正样本不是固定整页模板。
