# 共享尺度与原始读数

原十二页版面实验第 1 页。配色方向：墨绿 / 暖白。它是助手编排的构造数据案例，非 DSH 模型端到端实测；用户认可了这批样张的总体方向，不代表本次新报告已经获批。

## 先看画面，再学决策

打开同目录 `preview.png`（实际独立 PPTX 渲染），不要只读这段文字。阅读次序：先读汇总区间，再核对站点读数。

**核心决策：**区间图与精确表格各自成组，按同一比较任务并列；不要把解释拆成不相干的三个卡片。

**适用：**需要同屏读趋势与精确值，且比较对象有限。

**不适用：**大量比较对象或需逐站解释时，考虑分面、共享行或拆页。

## 换材料必须重新决定

比较对象增加时延展行，标签变长时调列宽；图表共用色义，不能照抄固定高度。

先列本页必须保留的证据、条件、单位和边界，再确定视觉锚点、区域比例、对齐轴与颜色职责。案例的坐标、字号和配色是这份材料的选择，不是默认阈值。至少写出一个本次保留原则和一个因新材料改变的地方；不是强行凑不同。

不能用换色、换标题、微移文字框冒充重新设计。也不能为了使新稿更清爽而删除误差、对照或不利结果。正样本不是固定整页模板。

## 实现与边界

`input.json` 是 `renderProject` 的直接绘图测试输入，不是已经通过研究/用户批准/交付流程的 `project.json`。没有真实论文 claim，不得拷贝为当前报告的科学记录；生产工程仍用 `academic_ppt_record` 的完整契约登记真实内容。

图形和表格样式由原生文本、点、线与色块组成，可编辑；不是带 Excel 数据表的 chart 对象。示例 `projection` 仅描述样张观看条件，不能用于调低用户工程的既定门槛。这里没有用户模板图片、Logo 或字体二进制。
