# 多图证据：让图与图对话

这两张曲线由确定性公式构造，只作原生布局示例，不对应真实研究。标题、共同对象身份与下方读图路径将两组证据连起来；两面板不必等宽，面积根据主次与原图比例决定。

迁移时用真实asset和面板替换，不运行脚本冒充新成果。不为配色重画未知数据。若原论文两图色义不同，应保留各自图例并解释；不能照搬共享图例。长图适合上下排，大量类别应扩大相关面板或分连续页。

不要把一个图形摘要缩在角落，然后用四段文字概括四篇文章。先决定哪些原图支持主张、哪些承担验证或反例，再组织邻接和对照。没有科学关联的两张图不应强行并列。

本页为助手编排并实际渲染的教材，不是DSH真实模型的自主输出或用户已认可的样张。
