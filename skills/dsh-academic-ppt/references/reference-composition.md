# 把参考中的组织能力落实到当前页面

这是正文编排指导，不是模板轮播表。用户提供的参考优先；下面的机制可以迁移，具体科学内容不可以。

## 1. 题名、命题与页眉分工
章节名承担导航，题名回答本页的问题。结果页可以是限定条件下的发现；方法页可以是准确的机制名称。不把“研究前沿/四篇论文/方法演进”重复放在每个最大字号位置。封面用 compose-opening：一个题名、少量身份信息、可选真实图；不用正文树重新拼一个冗长卡片墙。titleLines只允许语义断行，拼合后仍是原题名。

## 2. 方法不是三根高柱
先画关系，再安排文字。完整回路应回答：谁选择什么，谁执行，什么返回。把假设、参数类型、验证证据分在紧邻的第二层，不混入主节点长段落。flow自动按最复杂节点测量高度；留出的空间用于真实的参数解释或验证对照，而非继续把节点拉长。两到五个简短节点适合横向；窄区或较多节点纵向；复杂非相邻网络用已有显式drawings，不捏造因果边。

节点标题、角色说明、条件采用不同字级。标题可用结构色，状态与反馈线采用克制的次色。组内间距小于组间距；色面表达层级，不要求固定数量。拿方法参考看主分支、输入/输出和验证支线，而不是只模仿蓝色横条。

## 3. 计数同时展示读数与尺度
同一指标下的方法按列、指标按行。用comparison保留准确读数与单位，确有共同数量尺度时加scale。对于29/39这类计数，完整分母就近显示；条长基于同一0–39尺度。不能用截断范围把1和4的差异夸大为整体优势；不同单位的指标不共用轴。不因有条带就丢掉原图：涉及年度分布、离群点或阈值过程时，原图仍承担那些问题。

数据有限就围绕已知比较做紧凑页面，不为凑“信息密度”补解释。统计区间、共同达标年数、跨环境泛化都不能从边际计数里推定。短注释只解释这张表不能回答的关键问题。

## 4. 同页两层就近关联
主体是证据或机制；第二层是它需要的条件/读法。不固定“读数/判断/边界”三个侧栏。主图及图注作为整体对齐；辅助区以自身内容收紧。纵向split默认自然高度，只有确有需要才指定weight。程序返回allocated-payload-cavity时核对实际画面：它不是必须填满的命令，可收紧整体、扩大真实证据或保留有目的的留白。

## 5. 审稿动作
先将实际渲染与选定的参考正文同尺寸并置：视觉重心、主辅比例、题签层级、组内关系是否成立？再以单页检查孤行、日期/数字拆断、错误反馈方向、图注脱离。警告仅定位风险，不是审美得分。任何科学缺项和用户否定不能由“检查通过”抵消。

本指南的示例是合成教学材料。当前源数据的图注/版本/阈值仍须独立核对；生成PNG不等于read_image，present不等于用户批准。所有协作收据与暂停节点沿用rc6。
