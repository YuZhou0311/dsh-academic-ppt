# 证据记录、语义边界与原图

## 1. 建立可追溯链

论文登记为 `paper`，结论登记为 `claim`，原图登记为 `asset`，页面通过稳定 ID 引用。标题、卡片、图注与备注必须忠实于同一证据，不能只在 ID 列表放来源后任意扩写。

重要数字回答六问：衡量什么、分母是什么、与谁比较、何种设置、怎样汇总、什么不确定性。未报告或未核实的字段如实写明，不能补成已知。

## 2. 区分三种陈述

| `kind` | 表达 | `verified` 的实际含义 |
| --- | --- | --- |
| `reported` | 作者在具体设置中报告什么 | 已对照原文核查措辞和数值 |
| `inference` | 现有结果支持何种有限解释 | 已核查依据与边界，不代表推断获新实验验证 |
| `proposal` | 通过何种实验检验何种假设 | 已核查启发它的文献缺口，不代表假设已成立 |

三类均保留真实的支撑或启发论文 `paperId`。`locator` 写页码、章节、图表号或补充材料位置；`context` 写版本、验证范围与限制。“全文”不适合作为所有具体数字的定位。

`metrics` 分别记录标签、原始值、单位、基线、分母与汇总方法。最佳值、平均值、中位数、单例或估读值必须明确。比例由计算工具换算并保留原始计数，不将模型心算当成独立核验。

`verified: true` 是执行者对已经完成核查的记录，不是校验器授予的事实证明。工具可以发现缺字段、断引用和部分风险，不能替代原文判断。

## 3. 最容易改变结论的语义检查

| 观察材料 | 不能声称 | 必须保留 |
| --- | --- | --- |
| 两项指标各 29/39 达标 | 29/39 同时达标 | 分别统计；联合结论需要联合数据 |
| 多年天气模型轨迹 | 多年田间验证 | 仿真环境、年份和模型假设 |
| 24 株反复得到 1248 张图 | 1248 个独立生物样本 | 植物数与重复成像数分开 |
| 输出核查与另一组 LLM 评分 | 合并为同一准确率 | 任务、评价者、分母和尺度分开 |
| 四份报告各五项检查 | 20 个独立农艺试验成功 | 报告数、相关条目数和 pilot 范围 |
| 含收入和约束罚项的奖励 | 回报改善等于收入/产量改善 | 单位与目标函数组成 |
| 训练回报较早上升 | 学得更快且测试一定更好 | 训练曲线与留出评价分开 |
| 基线知道完整未来天气 | 与在线系统公平同信息比较 | 未来信息与 oracle 身份 |

本表是口径练习，计数不能直接成为新报告的研究事实。新任务必须回到自己引用的论文取证。

另查：两个中位数相减不是配对差值的中位数；最佳配置均值不是全配置均值；仿真人类反馈不是真实参与者；未报告统计显著性不能替作者补上。

## 4. 版本与冲突

固定实际稿件版本号、日期或 commit。正式题名与年份可来自出版页，但证据指向实际阅读稿。未取得最终出版社 PDF 时持续保留状态，不声称作者稿已与正式版核对。

正文、图注、表格或代码矛盾时记录双方位置，优先使用稳妥可核对结果；不能挑更好看的数字。综述转述别人的结果不是其原创实验，具体效果应追到原始研究。

## 5. 论文原图

科学图保留 `paperId`、图号/面板、图注、来源 URL、版本、许可和 `cropNote`，文件有稳定 ID 与哈希。图注告诉听众看哪里、观察到什么，以及判断所需边界。

渲染器接受已提供的 PNG/JPEG 字节或工作区文件，不自行下载 URL。PDF 渲染、下载和裁切使用宿主已有且获授权工具；新裁切文件也要登记来源和裁切说明。

科学图以 `contain` 保持比例，不为填满框截掉轴、单位、图例、统计标记或关键对照。拆面板保留面板身份，必要时配全图定位；放大不是重生成图内数据。

在实际页面尺寸查看图中文字。全图不清时拆页或用明确标注的局部，不能只因文件“高清”就认定可读。

论文原图允许为独立图片；标题、解释、图注与卡片使用原生对象。可编辑不要求将作者图拆成伪数据，也不允许整页压为一个图片对象。

## 6. 重绘与交付

只有取得可靠数值、单位、比较条件才重绘原生图表，通过 `sourceClaimId` 绑定证据。组件不支持必要误差线或特殊尺度时用原图或明确说明，不能静默省略后声称忠实重绘。

估读和曲线数字化数据须标记，不能伪装 source data 精确值。生图只能作非证据装饰或设计参考，不能承担结果图、数据图与精确机制图。

文章、原图、模板、字体和代码的许可分别保留；插件 MIT 不覆盖第三方资产。不能附整篇文章时给固定链接、阅读记录和获取说明，不用失败下载或伪 PDF 占位。
