# 学习模板，迁移设计语法

## 先确定参考约束的强度

默认由内容设计。没有参考时用 `design.mode:"content-led"`；用户提供参考、说“喜欢这个风格”或“借鉴布局”时通常用 `reference-guided`，只固定适合当前报告的字体、配色、对齐与层级。当前证据决定页序、卡片数量、图区比例和分组拓扑。仅用户明确说“沿用这套版式/逐页对应”时用 `template-faithful`，尊重其指定结构并披露不支持的效果。

mode是执行者与诊断的工作约定，不会自动生成布局或保证模板克隆。不要为消除布局提醒擅自切换到template-faithful。需要在内容与明确模板约束之间取舍时，先完成可支持部分，说明具体差异。

## 先确认模板的身份

用户的理想模板提供视觉方向。除非用户明确要求，其原研究主题、图表数据、机构、人员、成果、年份和汇报标题都不是本任务材料。原模板未获再分发授权时，不把它或其图片打包发布。

调用 academic_ppt_template({filePath,outputPath,render:true,fontDirectories}) 获得study、suggestedDesign、profile路径与真实页面/编号概览。字体目录只填已验证存在的路径。先查看实际PNG，必要时据实际字体纠正推断；结构推断的visualReview仍为not-performed。suggestedDesign默认带reference-guided，是可改的候选设计变量；按当前报告审定和适配后，作为record批次的design保存。无需复制所有候选值或逐页对应源模板。只导入components不会应用全稿风格。study是结构测量：实际画幅、显式字号与字体、颜色、标题和内容区域、图片/表格分布、代表页号、未解析项。它不会判断研究质量或替代实际看图。图片中的字和复杂继承尤其需要查看渲染。

查看缩略图的整体节奏，再打开封面、章节、方法、证据、密集表格中的代表页。根据真实内容选择，不必为了形式固定看五页。无法看图时标记未完成视觉学习，不能声称已经精确仿照。

## 保存一份简短的迁移决策

用本地 design-study.md 简短记录下表（通常十余行足够），后续只读需要的一项。无需把长篇模板分析塞进讲稿。

| 项目 | 记录内容 |
| --- | --- |
| 结构来源 | 模板文件hash、实际页号；不复制旧正文 |
| 约束强度 | design.mode；哪些来自用户明确要求，哪些只是可调整偏好 |
| 封面 | 主标题占比、对齐方式、署名层级、信息留白 |
| 页眉/页脚 | 标题的位置与高度、分隔线、页码/出处处理 |
| 字体层级 | 主标题、页标题、正文、图注的实际字号；替代字体 |
| 颜色 | 主色与强调色承担什么语义；哪些是装饰 |
| 研究关系 | 对照、机制、证据与注释、任务与成果如何对应 |
| 迁移选择 | 将哪些规则写入design.system/palette；具体页面采用何种composition研究关系，为什么适合当前内容 |
| 明确排除 | 机构/标志/人物/数据/原图/占位语/模板教学正文 |
| 未解决项 | 母版继承、字体、复杂背景、未看清图例等 |

多个参考最终提炼为一套主字体/标题/页脚体系；其中的科学关系只是候选，不要求任何参考成为整稿母版。不要一页一套皮肤。

## 从参考到当前页面

先写当前页论证，再说明借用哪个关系：

- 方法页借用输入、操作、输出的相邻关系，不沿用原领域节点或箭头标签。
- 结果页借用大证据图与紧邻解读，不沿用模板里的百分比和结论。
- 对照表借用行列的阅读顺序，用当前数据填真实条件；条件不齐就不做排名。
- 密集页借用紧凑对齐、统一标题、少量强调；模板原本字小不表示当前报告应继续缩小。
- 封面借用标题的视觉重心与正式身份层级，重新排当前长题目，不把正文布局放大后当封面。

学习结果应能用到另一学科，并且不依赖模板的原数据。若换研究主题后大部分正文仍能原样保留，内容很可能还停留在套话层面。

reference-guided验收看设计语言是否统一、当前证据是否清楚、是否有合理的独立构图；不把页面与模板长得不同作为失败。template-faithful才按用户明确指定的版式约束核对。两种模式都保留科研证据与可读性要求。

## 选择原生组件的边界

profile的components只含受支持背景形状，保留来源ID并排除旧文字。它们用于确有需要的局部边框或标签，不要求每页都放卡片。无法解析的母版、旋转、SmartArt、复杂填充和图片背景不能声称已原样复用。

用户要求严格沿用原文件且当前渲染器不支持时，说明具体缺失部分，完成可支持范围并提供真实差异；不要把新建的蓝白页称为无损模板导入。

## 模板目录的正确读法

academic_ppt_reference默认给中性区域、尺寸、数量和语义任务。选择一个templateId时先对照本页证据数量和比例。不要加载完整slide-records.json当写作起点，不复制其title/body/notes、示意图或假数据。显式请求includeExamples只表示查看版式示范。

质量检查会检测内置示例长段文字及模板图资产被误用。通过检测仍不证明内容原创或严谨；使用者仍需逐项对应当前原始材料。
