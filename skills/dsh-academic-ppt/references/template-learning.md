# 学习参考的证据组织

## 先确定参考用途

没有参考时使用content-led；用户给出喜欢的学术汇报、希望借鉴感觉时使用reference-guided；仅明确要求逐页沿用版式时使用template-faithful。mode记录工作约定，不会自动排版或保证模板克隆。用户提供的真实要求高于模式默认，不为消除提醒擅自切换模式。

参考学习应发生在绘制候选之前、中心问题和论证路线确定之后。重点研究原稿怎样容纳充分信息、区分主次、组合局部关系和推进问题，再决定当前材料怎样适配。不要把参考缩减为蓝白配色，也不要把坐标、卡数、横条比例或句式变成全稿固定槽位。

## 取得实际观察

参考为PPTX时，调用academic_ppt_template并选择真实渲染；fontDirectories只传实际存在的目录。按本次学习范围查看全稿概览，逐页记录职责和主要信息组合，再精看方法、对照、综合、密集页及相邻段落。不同正文类型都应进入观察，不能只看封面、目录或某一张漂亮页。结构推断、字号统计与suggestedDesign帮助定位，不替代看图；图片内部标签、继承字体和复杂母版尤其需要实看。

参考为PDF时查看实际页面并结合文本/字号提取；截图直接查看。不要把PDF或图片交给只处理PPTX的模板工具，不声称取得原母版或精确字体。仅有封面截图只能支持题名、元信息、配色和空间秩序的偏好，不能推断内页结构或证据密度。

核对缺失字体、替代字体、数学符号和异常换行。将渲染限制与参考本身的问题分开记录；必要时换可用渲染方式复核，不能学习缺字或错位，也不能在未打开原宿主时声称无损还原。

只提取可转移的设计依据。未获得再分发授权的用户原始PPT、截图、机构标志与提取媒体不随交付包发布。模板的论文、人物、数字、结论、背景图与旧身份不得成为新研究事实。

原文件缺失或视觉能力不足时，明确依据是用户文字、历史笔记还是实际页面，不能把记忆写成重新审阅。完成能支持的设计，保留需要实际对照的限制。

## 保存逐页观察与迁移笔记

用简短表格记录实际看过的每页：页号、页面职责、主要证据与辅助信息、主构图与局部关系、标题层级、它怎样接前后页。总览可先确定结构，密集页与关键段落再按可读尺寸核对。没有看过的页不列入观察范围。表格用于提炼原则，不保存待原样重用的坐标清单。

| 观察项 | 在参考中看什么 | 在当前材料中怎样使用 |
| --- | --- | --- |
| 主辅证据 | 第一眼看到什么，辅助图和文字放在哪里 | 选择当前最有判断价值的图/表/关系，按职责分配空间 |
| 信息充分性 | 哪些证据、方法、条件和解释共同支持本页问题 | 先恢复必要信息，再选载体，不把字多或图多当成目标 |
| 多层组合 | 主构图下怎样继续分组，局部是否混合比较、递进、主辅或包含 | 根据当前关系选择上下、跨栏、嵌套、局部穿插等，不固定为等宽并列 |
| 局部分组 | 边界、浅底、题签、对齐或空隙表达什么归属 | 围绕当前观测、模型、对照或解释设计，不能每块都套同款卡 |
| 图文对应 | 哪段解释紧邻哪个区域，图例与限定在哪里 | 将指标、条件、边界贴到对应图/表，避免远端找关系 |
| 标题与文字层级 | 章节定位、页级题名、局部题签、普通解释和图注怎样区分 | 用承托、对齐、字重和语义建立层级，不只模仿字号或扩大标题 |
| 颜色与线型 | 哪些颜色表达变量、处理、模块或状态 | 建立当前材料的稳定语义，保留原图数据颜色含义 |
| 封面与标题 | 题名断行、元信息与留白的关系，是否确有必要用图 | 文字主导地重新排当前题名和身份；有明确识别用途才加图 |
| 全稿节奏 | 目录、分节、转折怎样定位，不同任务怎样变化主载体 | 用本稿问题链确定页序，科学上需要的共同尺度保持一致 |

记录可取得的来源hash及实际看过的页号或截图名，选择有用原则及需要避免的做法。区分“稳定设计语言”与“随任务变化的结构”：同组证据可一致，方法、验证、综合与计划通常需要不同阅读关系。参考中的字过小、章节错号、旧项目名、科技纹理或巨型标识都不应照搬。引用笔记即可，不把长篇分析放入正式讲稿。

## 把原则落实到候选

为封面和最难证据/机制页各绘制两个真实方案，再将参考实图、当前来源图和候选并列检查：

- 参考的充实感来自哪些证据与关联信息；新页是否保留本次材料需要的职责，而非照搬原稿的块数。
- 主构图与局部分组是否表达实际关系，是否出现大空框、同款卡片或无归属的文字。
- 主图、辅助证据、条件与解释是否有主次，标题层级与中间解释层是否清楚。
- 多种关系是否获得合适的组合，而不是每页只换标题、颜色、圆角或图标。
- 封面是否通过题名、身份和留白独立成立，是否为了接近参考而复制装饰或添加无关图片。

选定候选后查看一段连续三页，确认标题、信息增量、转折与视觉节奏相接；短稿按实际页数处理。不能凭孤立页的整洁宣布全稿设计已成立。保留实际信息量，不能把困难页删成稀疏样板来通过比较。

相似的阅读体验可以由不同坐标与载体实现。反过来，颜色和字号相似也不能证明参考学习成功。用户明确需要template-faithful时，另按其指定结构核对并披露不支持的效果。

## 参考库与组件

suggestedDesign是待审定的变量，按当前图文适配后才记录，不整份照抄。配色不必原样继承，可从design契约的学术色板候选中选择与本稿匹配的方向。components可帮助理解局部归属，但不先选卡片库再挤入材料；原生drawings、card.appearance和自由区域可重新设计。框、浅底和题签有职责时保留，无职责时开放，不能把去模板化理解成去掉所有设计层次。

48页内置库按需查看结构，不加载整份示例记录作为新稿起点。其示例正文、图像和假数值不进入当前科学记录。参考页型只能是适配选项，不能反向决定删掉哪些真实证据。
