# 学习参考的证据组织

## 先确定参考用途

没有参考时使用content-led；用户给出喜欢的学术汇报、希望借鉴感觉时使用reference-guided；仅明确要求逐页沿用版式时使用template-faithful。mode记录工作约定，不会自动排版或保证模板克隆。用户提供的真实要求高于模式默认，不为消除提醒擅自切换模式。

参考学习应发生在绘制候选之前。先看原稿如何让证据充实而有秩序，再决定当前研究能沿用哪些原则。不要把参考缩减为蓝白配色，也不要把参考中的坐标、卡数和句式变成全稿固定槽位。

## 取得实际观察

调用academic_ppt_template并选择真实渲染；fontDirectories只传实际存在的目录。看全稿概览，再看封面、方法、结果及密集页等有代表性的实际页面。结构推断、字号统计与suggestedDesign帮助定位，不替代看图；图片内部标签、继承字体和复杂母版尤其需要实看。

只提取可转移的设计依据。未获得再分发授权的用户原始PPT、截图、机构标志与提取媒体不随交付包发布。模板的论文、人物、数字、结论、背景图与旧身份不得成为新研究事实。

原文件缺失或视觉能力不足时，明确依据是用户文字、历史笔记还是实际页面，不能把记忆写成重新审阅。完成能支持的设计，保留需要实际对照的限制。

## 保存简短迁移笔记

| 观察项 | 在参考中看什么 | 在当前材料中怎样使用 |
| --- | --- | --- |
| 主辅证据 | 第一眼看到什么，辅助图和文字放在哪里 | 选择当前最有判断价值的图/表/关系，按职责分配空间 |
| 信息密度 | 同页容纳多少独立信息，哪些通过图形/对照表达 | 保留关键数据、条件与读图解释，减少同义复述 |
| 局部分组 | 边界、浅底、题签、对齐或空隙表达什么归属 | 围绕当前观测、模型、对照或解释重新设计局部组 |
| 图文对应 | 哪段解释紧邻哪个区域，图例与限定在哪里 | 将指标、条件、边界贴到对应图/表，避免远端找关系 |
| 字体层级 | 题名、页标题、普通解释、图内标签、注释的实际区别 | 保留中间层，不将说明全缩成小字或全放大成口号 |
| 颜色与线型 | 哪些颜色表达变量、处理、模块或状态 | 建立当前材料的稳定语义，保留原图数据颜色含义 |
| 封面与标题 | 题名断行、对象视觉和身份的关系，标题如何归纳内容 | 重新排当前完整题名，按主题/方法/结果选择专业标题 |
| 全稿节奏 | 不同任务怎样变化主视觉、阅读方向和分组 | 当前页序按论证推进，科学上需要的共同尺度保持一致 |

记录来源hash及实际看过的页号，选择几项有用原则与一项需要避免的做法。引用笔记即可，不把长篇分析放入正式讲稿。没有看过的页不列入观察范围。

## 把原则落实到候选

为封面和最难证据/机制页各绘制两个真实方案，再将参考实图、当前来源图和候选并列检查：

- 参考的充实感是否来自真实图、对照和研究关系；新页是否保留了同类信息职责。
- 局部分组是否围住有联系的内容，是否出现大空框、同样小卡片或完全散落的文字。
- 主图、解释与条件是否有主次，字号是否保留中间层，重要限定是否可见。
- 不同科学关系是否形成不同构图，而不是每页只换标题和配色。

相似的阅读体验可以由不同坐标与载体实现。反过来，颜色和字号相似也不能证明参考学习成功。用户明确需要template-faithful时，另按其指定结构核对并披露不支持的效果。

## 参考库与组件

suggestedDesign是待审定的变量，按当前图文适配后才记录。components可作为局部边界参考；原生drawings、card.appearance和自由区域都能设计新的局部形式，无需依赖旧卡片目录。框、浅底和题签有科学分组职责时保留，不能为了“去模板化”全部删除。

48页内置库按需查看结构，不加载整份示例记录作为新稿起点。其示例正文、图像和假数值不进入当前科学记录。参考页型只能是适配选项，不能反向决定删掉哪些真实证据。
