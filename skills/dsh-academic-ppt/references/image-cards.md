# 把论文图组织进信息卡

图片嵌入式卡片将真实论文图、读图提示和必要条件组织为一个有边界的证据组。图仍是独立图片，题签、解释、读数、线与边界保持可编辑；它可以承担主要证据，不只是大图旁边的文字补丁。开放大图、原生表格与自由关系图同样可用，不要求整稿全部卡片化。

## 先看图，再选结构

先完成查证、取图与`asset.reading`，保留图号、面板身份、来源、轴、单位和图例。随后查询`academic_ppt_cards({"family":"figure","limit":12})`，读取适合的候选详情并查看实际预览。单纯运行目录查询不等于完成参考学习；按[card-design.md](card-design.md)保存观察、选择和内容适配依据。

| 预设ID | 图数 | 适合的图文关系 |
| --- | ---: | --- |
| `figure-caption` | 1 | 上方完整图，下方简短解释，适合横向结果图。 |
| `figure-observation` | 1 | 图左释右，适合一幅图与少量观察；只作为局部选择。 |
| `figure-reverse` | 1 | 释左图右，解释先建立读图条件；不是靠左右互换制造变化。 |
| `figure-pair` | 2 | 同尺度并图，共同条件与比较，不能把不可比实验排成优劣榜。 |
| `figure-stack` | 2 | 上下图列及逐图说明，适合共享时间轴、分层变量或逐项结果。 |
| `figure-sequence` | 3 | 三阶段图序，只用于真实先后过程或明示的阅读顺序。 |
| `figure-matrix` | 4 | 2×2证据窗，适合需要共同观察的多个条件；图内字必须仍可读。 |
| `figure-zoom` | 2 | 完整图加已核对局部，保留定位关系与共同解释。 |
| `figure-overview-details` | 3 | 上方总览、下方两个局部，适合空间图、结构与两个验证细节。 |
| `figure-margin-notes` | 1 | 中央图面与两侧短注，解释紧邻所指区域，不堆长段落。 |
| `figure-metrics` | 1 | 上方图面、下方成对读数；读数保留各自单位、基线和口径。 |
| `figure-conditions` | 1 | 条件带、完整图、边界说明共同出现，适合条件决定解释的结果。 |

图数是组件消费的资产数，不是研究需要的图片配额。一个原图可包含多个面板；多个资产也可能来自同一原图的总览和局部。不要重复同一图伪装成不同证据，不把四幅不可读小图硬塞入矩阵。

## v0.8.3 图像复刻参考的正确定位

先看[20 款可编辑局部组件](editorial-v083/index.html)中的双图、主图与局部、图证读数、四象限图阵等关系，再选择真实可用的 48 款预设或用原生组件重绘。每个 C 编号都是视觉参考 ID，**不能**在 `card.preset` 中直接填写 C01–C20；结构目录中的映射仅供判断起点。新图册的图像全部是合成占位，不是论文原始证据。生成的 PPTX 是四张卡同页的组件图册，不是可直接替换文字的整页学术汇报模板。

卡片应服从当前页面的中心判断和主图真实宽高。并排图可做局部对比、条件卡可嵌入一组图证，必要时用开放大图维持可读性；一张卡片的边界不能代替整页布局规划。

## 使用实际支持的字段

12种图片卡同样支持 `appearance.fill/stroke/strokeWidth/dash/shadow`，不再只能使用一种白底细框。可选真正透明的虚线范围或白底实线轻阴影，具体参数与职责见 [academic-visual-language.md](academic-visual-language.md)。它们只改变外部表达，原图保持独立图片、完整比例与原始色义；题签、图注和内部槽位仍按配方测量。不能为制造质感缩小科学图、裁掉坐标或给每一张图增加多层外框。

先查slide契约。`card.figureIds`列出已登记资产，顺序对应预设槽位，图数需匹配所选预设；卡内图不必重复放入`slide.figureIds`。独立于卡片展示的图仍使用`slide.figureIds`或绘图image。所有科学图的来源仍须列在本页`paperIds`，相关主张保持明确绑定。

`mediaHeight`可选，控制卡内图与图注槽的总高，合法范围120–520px。默认值仅是起点：按真实图比例、标签大小、卡片宽度和文本高度调整，不预设所有图片卡同高。卡片整体`box`和组合区域必须给完整标题、图片、图注和解释足够空间；溢出时重组而非隐藏字段或缩字。

图片默认contain，保持比例并完整显示。不要为了贴满圆角卡片而裁掉坐标、图例或数据区；卡片边界可以圆润，论文图仍完整矩形显示。局部放大使用另一个实际取得并核对的asset，登记`viewport`和`cropNote`等受支持来源记录，不把普通图片重复放大冒称新观测。已有裁图也要与完整原图对照，确认没有截断轴标签、留下相邻面板残片，或把必要图例当外边距裁掉。

标题命名该证据组，`body`说明需要看见的关系，`items`可承担对应观察、条件或读数。具体槽位以工具详情为准，不猜测每个预设都把条目放在同一位置。长图注在正文保留判断所需部分，完整来源和细节进入来源记录与讲稿。不能只显示“原图”“结果”之类占位标题。

## 把卡片关系扩展到整页

先写读者需要完成的判断，再组织卡片、开放文字和其他载体。以下是内容条件触发的组合，不能按页号机械轮换：

- 同一问题的两种方法：配对图卡共享比较条件，综合判断横跨两卡；相关原图尺度一致。
- 总体结果需要解释局部异常：总览与放大卡成为主要证据，边界作为短栏或底部说明。
- 方法流程与结果共同支持结论：方法区域串接真实步骤，每个关键节点只嵌入对应图或验证卡。
- 多来源综述：按可比问题组织图卡和条件矩阵，出处紧邻，明确不能直接比较的口径。
- 单幅图已足以表达：保留大图与少数就近注释，使用开放布局或单一图卡，不额外制造三张解释卡。

统一配色、线宽和字级，按图片关系变化局部结构。观察整稿时，要能区分配对比较、上下证据链、总览局部、图表联合和综合收束；把每页都变成“左边大图、右边三卡”或全部改成同样的上图下释，均没有完成逐页设计。

## 复核图卡的实际画面

在最终PPTX上检查：原图是否真正嵌入且匹配来源，标题与解释是否紧邻正确图，图内标签是否可读，裁切是否保留必要上下文，内外边界是否造成重复套框。多个图卡共同比较时核对坐标尺度和色义，图卡内部的留白按真实图面判断。

查看工具的图源实际使用与卡片诊断，再结合整稿概览检查是否只用了同一种图卡。样式数量没有最低配额，任务关系不同却结构始终相同应修复；同一实验的对应比较可保留一致设计。
