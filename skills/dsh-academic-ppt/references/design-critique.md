# 学术审稿与视觉复核

让审稿能拒绝一个看起来整齐却讲错科学的页面。自动检查负责来源连接、对象存在、几何和版本一致性；作者或实际具备图像能力的审阅者负责理解证据与画面。不存在一个能证明“去AI化”或学术专业性的自动总分。

## 按影响顺序检查

| 层次 | 具体问题 | 不通过时先做什么 |
| --- | --- | --- |
| 科学含义 | 数值/单位/样本/对照是否对？观察、推断、方案是否混写？标题是否过度外推？ | 回到来源核对，修正结论和必要条件 |
| 证据呈现 | 选中图是否上页？是否读得到支持判断的比较？是否缺误差或不利对照？ | 恢复证据、改变载体或重新分配图面 |
| 论证 | 为什么先讲这页？本页增加了什么？结尾回答什么？ | 调整顺序、删重复、补必要前提 |
| 阅读关系 | 比较是否共尺度？解释是否就近？箭头是否准确？ | 重排位置、关系和分组 |
| 投影可读性 | 图内标签/公式/注释够读吗？中文、上下标、换行正常吗？ | 放大、分面、改行宽或拆任务；不缩关键文字 |
| 风格与细节 | 字体、导航、数据色义是否一致？容器、装饰、阴影是否有作用？ | 删除无用包装，调整对齐、间距与视觉层级 |

科学错误不能用整齐的版式抵消，任何一页的严重问题不能被其他页的平均表现抵消。应区分通过、需修复、目前无法判断。后者意味着补来源/图像/能力，不能登记 passed。

## 查找常见模板化痕迹

逐项判断实际影响，不按词表自动处罚：

- 同一事实在标题、副题、大数字、旁注和结论带反复出现。
- 每页固定三个等大的块，第三条只是凑数；比较对象实际并不等权。
- 图被压成小附件，旁边文字却重复解释看不清的图。
- 技术页只剩概念框图，缺关键变量、条件、公式或数据处理。
- 负结果被包装成突破，限制被降到小字，方案被写成成果。
- 有效科学对象被通用图标、生成照片或装饰背景替代。
- 全稿每页都用同一个句式，或者所有标题都泛称“研究背景/创新价值”。

必要的列表、相同实验的共同布局、正常术语和合理边框可以保留。不能为了消除重复提示而随机换配色、镜像布局或把同一个实验的轴尺度改掉。

## 具体的复核动作

1. 先读故事板与来源，再只读全稿标题和转场，判断论证是否连贯。
2. 看全稿概览检查研究任务的推进与视觉重复。概览不用于证明小字可读。
3. 打开每页实际PPTX渲染图，以最终观看比例核对源图、标题、注释、字形与关系。
4. 连续查看困难页前后片段，检查前提、证据、解释是否衔接。
5. 每项问题写页号/对象、影响、修复动作。按优先级集中修复，重建和重渲染改变过的页面。
6. 最终核对当前PPTX、实际渲染与逐页review绑定同一版本；未看页不填已审查。

字体检查同时覆盖标题、正文、图注的字族和实际字重。`missingFonts=[]` 仍可能发生缺字或 Bold/Italic 字面回退：例如只提供宋体 Regular，渲染器可能合成粗体，笔形与真实 Bold 不同。为所用字重提供匹配字体，并在实际渲染中观察笔形、数字、希腊字母与上下标；字体清单通过不等于字形正确。

有意留白写明“哪块、为了什么、为何主证据已足够大且内容完整”。无用空腔则缩容器、放大有效图面或重组。新稿默认balanced允许这种判断；用户明确选择compact时保留相应约束，不通过改模式消除失败。

## 可用的评语

“第5页右图的两条曲线只靠红绿区分，图例在当前投影尺度无法读；给两线加不同标记并放大图例，再渲染核对。”

“第3页标题声称跨站点普适，来源仅提供一个地点的随机划分；改为该测试条件下的结果，并将跨站点验证列为未完成检验。”

“第4页为公式推导，主式、三个符号和成立条件均可读；右下留白用于稳定阅读，不添加装饰或第四个解释块。”

评语必须来自本次实际内容与画面。以上是表达形式示例，不能原样填入一份未查看的稿。

## 验证插件能力时区分层次

单元测试证明明确代码路径；教学样张证明该组内容的渲染与设计可行；独立Agent试作只覆盖该任务和模型；DSH实机创作需另外运行。不要把组件图册、手写样张或协议fixture称为通用模型效果评测。可复现实验任务见仓库 `evals/academic-cases.json`，先固定同一素材，再比较修改前后的实际稿与盲审结果。
