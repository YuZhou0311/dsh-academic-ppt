# 精简文字与安排语义换行

文字排版从内容编辑开始。依据[design-dialogue.md](design-dialogue.md)已确定的观看方式，先让论文图、表和关系承担可视表达，再用简练语言指出观察、条件与解释。增加字号要与行宽、图面和内容取舍一起完成，不能只把现有长段落放大。

## 留下会改变判断的文字

| 文字作用 | 处理方式 |
| --- | --- |
| 标题已经说过的结论，卡片又完整复述 | 保留一次准确表达，卡片改为指出读图位置或限定条件。 |
| 图上已有且听众能读出的变量与全部读数 | 保留必要图例和少数任务相关读数，正文解释它们意味着什么，不逐点再抄。 |
| “通过对…进行…能够实现…”等冗长句式 | 改为具体主语和动词，如“同化观测更新模型状态”；不能删去动作条件。 |
| 与本页判断无关的技术背景、长方法沿革 | 放入讲稿或附录；正文留下理解本页所需部分。 |
| 样本单位、比较基线、时间窗口、单位、负结果与限制 | 保留在相关主画面，允许重新分组和改写，不移成看不清的脚注。 |

每段只承担一个可识别职责，例如解释某一曲线变化或限定某一比较。题签可短，正文要有完整语义。术语第一次出现解释一次，后续沿用准确简称；不为了省字创造生僻缩写。现场讲述允许少字，答辩兼复读仍保留离开讲者后判断证据所需的条件。

先删除重复，再缩短句式，再调整图文组合，最后决定是否拆页。没有统一字数上限；同一句话反复出现在章节、标题、副题、卡片和结论带中，比单纯字数多更应优先处理。

## 把换行视为编辑决定

标题、卡片题签和关键读数逐项检查实际换行。用语义完整的短组安排`heading.lines`、`cover.titleLines`或受支持文字中的显式换行，保留原句顺序与含义。不要在不确定支持哪些字段时杜撰字号、行宽或“不换行”参数。

优先修正以下现象：

- 数值与单位、正负号与读数、变量名与下标被拆开，例如把`756 kg/ha`的单位单独丢到下一行。
- 中文行首只剩标点或行尾留下开括号；末行只有一两个字、孤立字母或一个连接词。
- 短标题被窄文本框拆成三四行，或长英文术语在单词中间折断。
- 相同职责的卡片因偶然换行而出现不同题签高度，破坏组内对齐。
- 左侧图很大，右侧却仍使用窄长栏承载段落，形成频繁换行。

修复顺序：删同义重复或改写短句，扩大有效行宽，调整同组区域比例，再作语义断行。字号通常保持或增大；不要为消除一行孤字将整页字号一律缩小。无法在当前结构保持可读时，换用上图下释、图中邻接注释、配对卡或跨栏说明。中文与英文混排、上下标和书目以最终渲染为准。

## 建立字号与行距的层级

在设计稿中记录标题、局部题签、普通解释、数据标签与来源五类职责，映射到当前契约支持的`system`、`projection`、`heading`和绘图字段。1280×720场景中1px约0.75pt，不能将像素数字直接当作PowerPoint点数。`projection`是检查下限，不会替文本自动变大。

用户要更清晰的现场汇报时，先选一张真实困难页比较两种合法字号，查看普通解释与图内标签能否同时读懂，再将选定职责推广全稿。卡片预设和自由绘图都应遵守该层级；必要条件仍是正文，不能标成`note`绕过下限。

行距、段距与内边距各自解决不同问题：行距让一段能顺读，段距分开语义组，内边距让内容离开边界。不要用空行、巨大内边距或拉高卡片制造“设计感”。在同一比较组保留一致字级与段落节奏，文字少的卡片可以收紧，不必强填到等长。

## 在实际PPTX中复核

查看全页和文本区域，不只看缩略图或测量值。先核对标题/题签行数与孤行，再核对普通解释、单位、图内标签和来源。软件给出的换行、溢出或孤行风险只是定位线索；没有提示也应看图。记录具体对象和修复，重建后复看受影响页。

把最终代表页返回给用户时，问具体取舍，例如“这版解释缩短并增大字号后，是否保留当前密度，还是需要更多方法细节？”这属于对前面密度选择的可见验证，不必对每张卡重新提问。

## 参考依据与适用范围

- [Harvard Catalyst：Slides](https://catalyst.harvard.edu/writing-communication-center/visualize-science/slides/)强调面向听众，以视觉证据、清楚标签和可读层级帮助理解。这里保留学术限定，不把少字理解为删掉比较条件。
- [Microsoft：有效演示文稿建议](https://support.microsoft.com/en-us/powerpoint/tips-for-creating-and-delivering-an-effective-presentation)建议减少冗长文字，并按观看距离选择字号。本插件按实际任务比较字号，不把网页中的通用点数当成所有角色统一门槛。
- [Anthropic公开PPTX技能](https://github.com/anthropics/skills/blob/main/skills/pptx/SKILL.md)的可借鉴做法是先查看全稿视觉概览、按内容选择不同布局，再检查真实输出；其工具和模板处理方式不直接替换本插件契约。

上述来源用于提炼原则，未复制模板、脚本或固定布局。具体中文换行与卡片安排由本稿内容和实际渲染决定。
