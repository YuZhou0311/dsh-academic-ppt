# 科学图表与方法页

先明确要比较、估计、定位或解释什么，再选图形。图面必须支持本页标题；装饰性相关不能替代证据相关。来源与资产的实际获取见 [figure-selection.md](figure-selection.md)。

## 按证据选择表达

| 判断任务 | 优先考虑 | 保留的信息与边界 |
| --- | --- | --- |
| 个体或配对变化 | 独立点、配对线、差值图 | 每个点的单位；同一对象配对；无原始数据不编造点 |
| 连续分布 | 原始点、箱线/分布、适合样本量的摘要 | 样本量、分组、离群规则；密度形状不夸大稀少数据 |
| 估计及不确定性 | 点区间、误差线、森林图 | 区间定义与计算单位；SD、SE、CI不能互换 |
| 时间过程 | 共同轴趋势、分面或残差 | 时间窗、采样间隔、观测/模拟身份及缺测 |
| 多方法比较 | 同尺度图与必要的精确表 | 相同测试划分、基线、指标和单位；不同比例不直接排序 |
| 空间或田间观察 | 真实地图/影像、地点索引、采样设计 | 比例尺、方向/坐标的必要说明、分辨率、时间、图例与真实来源 |
| 机制与算法 | 输入、状态、变换、输出和独立检验 | 箭头到底表示数据流、时间、因果还是假设；反馈与验证路径准确 |
| 数学/模型推导 | 假设、符号表、核心等式与必要中间步骤 | 参数/状态/观测区分，初边值条件、适用域、量纲 |
| 文献综合 | 条件矩阵、论点与来源对应、冲突证据 | 研究对象和设计的可比性，作者发现与汇报者推断分开 |

没有普遍最好的图形。类别计数可以用柱图；小样本连续数据的均值柱图可能掩盖分布与配对信息。有原始数据才展示其分布；只有汇总统计时忠实显示汇总及其限制。依据：Weissgerber 等，2015，[原文](https://journals.plos.org/plosbiology/article?id=10.1371/journal.pbio.1002128)。

## 不确定性与比较条件

明确 n 代表独立受试者、地块、站点、年份还是技术重复。不要把同一对象的多次测量当成额外独立研究单位。误差线旁或图注明确 SD / SE / CI 及其对应对象；没有检验或原文支持时不加显著性星号、不写“显著提升”。误差线相交与否不自动等于检验结论。依据：Cumming、Fidler、Vaux，2007，[原文](https://doi.org/10.1083/jcb.200611141)。

农业与模型任务尤其要保留训练/验证/测试的区别、随机划分与跨地点/跨年份划分、独立验证环境、管理和气象条件。效果来自哪些尺度就只在那些尺度上解释；不从模拟精度直接推导田间决策效果。

## 原图、重绘与局部放大

先实际看完整图及图注。对复杂多面板，可选择与问题有关的面板，并保留原面板编号和可定位出处；需要整体关系时先给总览，再放大关键局部。局部与原图用清楚的定位关系连接，不裁掉不利对照。

原图可作为独立图片，图旁标注保持可编辑。图层不等于所有元素都能编辑。取得准确原始数据时可用原生 chart/table/plot 重绘，记录数据与转换；只有图片时不凭像素猜小数或把图像生成结果当忠实重绘。

图注可以缩短措辞，但不能删去会改变解读的条件。引用靠近对应证据，完整书目进入讲稿/参考页；演讲者的解释不得伪装成原作者结论。

## 让听众读得懂

先说明坐标、点/线、分组与比较对象，再指出主要差异。正文解释靠近对应位置；重点标注不遮盖数据。图内标签的实际投影尺寸取决于嵌入后的缩放，图片分辨率高不代表字够大。看不清时分面、放大或有数据地重绘，不能把小图框撑大就视为完成。

变量颜色跨页保持一致，分类、连续量、中心偏差使用合适色标；关键区别另用文字/线型/形状，不能只靠红绿。色标不是页面主题色。[Wilke 色标原文](https://clauswilke.com/dataviz/color-basics.html)与[常见配色问题](https://clauswilke.com/dataviz/color-pitfalls.html)。

## 方法与理论页不必包装成图卡

公式、假设与推导本身可以是主视觉。给出本页真正需要的符号解释和成立条件；避免将每个变量做成卡片或给没有因果证据的概念画实线因果箭头。方法图中的每个箭头都应能用一句明确操作解释。

运行过程、外部验证、消融或测量路径分别标明。真实循环可以回连，纯并列条件不画成先后流程。不要把装饰性网络脑图、六边形和芯片图当作方法解释。

## 图页的交付核对

核对原图与页面的数值/方向/顺序、轴/单位/图例、n与误差、比较基线、可见条件、来源与许可。随后检查观众能否在讲述时间内完成必要读图。无法读图时标记未完成，不以“来源已引用”代替图面质量。
