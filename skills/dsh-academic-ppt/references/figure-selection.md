# 论文图的选择、裁切与版面适配

在选 `referenceTemplateId` 之前读本页。先确定听众需要从图里读出什么，再选图、裁切和分配空间。图像纵横比是一个输入，不能独立决定版式。

## 1. 给每张图分配明确职责

- **主证据**：听众必须能读出本页论点涉及的关系。保留并看清关键坐标、单位、图例、对照与不确定性。
- **局部证据**：从复合图提取直接支持当前问题的面板。保留面板身份和足以解释结果的上下文。
- **定位图**：只说明局部来自何处，不能计入“主要证据已可读”。没有实际定位必要时省去，将完整原图保留在资产与来源记录中。

不要因为原图来自高水平期刊就整张上页。把大竖图缩到一栏后，再用口头描述替代图内信息，会同时消耗空间和听众注意。优先选与本页科学问题有关的面板，其他任务放在相应页面。

## 2. 实际查看后记录读图条件

使用支持图像的宿主能力查看原图；OCR 和宽高元数据只能辅助。记录以下简短判断，并按当前 schema 写入已支持的资产字段：

1. 图中有哪些面板，当前页讨论哪一个关系。
2. 原始像素尺寸、有效内容区域及待用视窗。外部白边与作者有意保留的图间距分开判断。
3. 为正确解读必须保留的元素：轴、单位、颜色含义、样本/重复含义、比例尺、共同对照或面板编号。
4. 最小**必要**标签的字形高度；必须从原始像素或可靠的源文件测量。未知时保留未知，不根据图片总尺寸猜字大。
5. 是否需要并排比较；几张图的轴、颜色、条件是否可比。

文件中存在很多像素，不代表关键文字足够大。复合图里一个小坐标系只占原图一角时，应该以该坐标系和标签的实际尺寸评估。

将这些观察写进 `asset.reading`，或先传入 `academic_ppt_reference` 的 `figure.reading` 查询：

- `purpose` 取 `evidence` 或 `locator`；定位图只承担 `overview`。
- `contentType` 区分 `dense-multipanel`、`plot`、`diagram`、`photo`、`table`、`mixed` 和 `unknown`。
- `task` 区分 `overview`、`read-values`、`compare-panels` 和 `explain-process`。
- `panelCount` 说明当前展示的面板量；`minLabelPx` 记录原始像素中最小必要标签的实测高度；`requiredElements` 列出必须保留的科学元素。
- `verifiedBy` 取 `human`、`vision-model` 或 `unverified`。该字段是执行者的阅读声明，不会自动赋予模型视觉能力。没有测量就省去 `minLabelPx`，不能编一个值消除警告。

`academic_ppt_reference({figure:{width,height,viewport,reading}})` 使用原始图宽高、可选视窗和读图记录返回最多三个候选及具体问题。这里的表达是参数结构说明；实际调用使用有类型的数值与对象，不能把变量名当字符串提交。候选排序不证明图已读懂，也不是审美评分。

## 3. 先排除不可读的候选，再比较构图

对主图只比较 2–3 个有内容依据的候选：通常是“单面板主图 + 就近解释”“两张可比较面板”“拆成两页”。每个候选只写保留的证据、主要阅读顺序、标签可读性和一个缺点；不为追求创意枚举十几种风格。

| 图的内容与任务 | 优先处理 | 需要排除的情况 |
| --- | --- | --- |
| 密集竖向复合图，当前只讲一个结果 | 提取对应面板，以有效内容比例分配主空间 | 完整长图与放大图各占半页，左侧信息仍完全不可读 |
| 单一竖图，纵向结构本身重要 | 保留整列高度，另一列用对齐说明；必要时分段接续 | 按宽图槽位缩小，或为填满槽位拉伸 |
| 曲线或散点图，需要比较趋势/读数 | 主图优先保留轴、图例和误差，解释贴近对应观察 | 裁掉图例后只写“红线更高”，或用遮挡覆盖原图读数 |
| 两个面板需要共同对照 | 同尺度对齐，明确共同变量与不同条件 | 只因两图尺寸相近就并列；不同分母却使用相同“提升”标签 |
| 流程图，需要理解分支或反馈 | 保留拓扑；可依据原文重绘可编辑结构并标明身份 | 裁到箭头终点消失，或把分支改成线性流程 |
| 显微/田间照片 | 保留比例尺、处理身份和必要环境信息 | 用照片填空，图片与本页论点无关 |

没有参考页能同时保留必要元素和可读尺寸时，换主次比例或拆分任务；不要用空卡片凑够槽位。确需新构图时，使用受控自由区域：

- 选 `figure-focus` 或 `figure-split`，省去 `referenceTemplateId`；固定参考页的面板与自由图框不能混用。
- 为 `figureIds` 按相同顺序提供 `figureBoxes`，每个图框使用 `{x,y,w,h}`；为每张解释卡片提供明确 `box`。
- 先画出阅读顺序与共同对齐线，为标题、图注和页脚保留真实高度；图框要按有效面板比例分配，不能把整图拉伸到框内。
- 构建后检查缺失、重叠、可读性与实际 PPTX，必要时调比例或拆页。位置自由不取消证据、原图保全和局部修改范围检查。

自由区域是针对当前证据创建合适布局的手段，不能把自由排版当作随意摆放。用户仅授权改小卡片时，不切换为自由整页构图。

## 4. 用最终绘制尺寸检查缩放

对于保持比例的视窗，缩放倍率约为 `min(槽宽 / 视窗像素宽, 槽高 / 视窗像素高)`。必要标签的场景字形高度约为“原始标签像素高度 × 缩放倍率”。这只是几何估算，仍需实际渲染检查字形、对比和投影环境。

**教学计算**：一张 700 × 1,200 px 的长图含 10 px 高的关键标签，放入 320 × 400 px 的槽后，标签约为 3.3 场景 px，无法承担主证据。若只保留 600 × 300 px 的相关面板并放入 900 × 450 px 区域，标签约为 15 px；仍需逐项看清所讨论的标签，可进一步放大或在图外转录必要变量。以上数字是演示，不是任意图的实测值，也不是固定通过阈值。

1280 × 720 的场景采用 px，PPTX 以 1 px = 0.75 pt 换算。不要把槽位尺寸、源图像素、模型收到的缩略图尺寸和 PowerPoint 字号混为一谈。

当前预检将小于 12 场景 px 的必要标签投影高度标为错误，12–18 px 标为需复核，18 px 及以上仍只是估算。它们是本插件为尽早发现明显失配设定的经验值，不是学术汇报通用标准。测量值不可信、图像模糊或关键元素丢失时，数值达到阈值也不能通过。

## 5. 实施非破坏视窗

`asset.viewport={x,y,w,h}` 使用相对原图的 0–1 坐标，原始媒体完整保留。每个用途使用独立资产 ID，保留同一出处、图号和准确 `panel/cropNote`。视窗合法只能证明没有超出图像边界，不能证明保住了轴、图例或对照。

`asset.displayCaption` 放简洁的上页图注，例如“Fig. 3，任务 2，PLA 曲线”；`caption`、来源、版本、许可和裁切说明继续保存完整记录。不要把相同 DOI、作者串和许可证在一页重复三遍；具体归属仍应可追溯，不得误删许可证要求的署名。

用 `asset.treatment: "paper"` 为图像的实际边界提供浅框和轻阴影；`plain` 适合已有清楚边框或不需要分离的图。不要给远大于实际图像的空槽画重边框，也不要让阴影压到邻图的坐标和图注。

`asset.displayLegend` 接受按原图顺序登记的 `{label,color}` 数组（1–10 项，颜色为六位十六进制）。它将标签与短色线生成为独立原生对象，并从图框中预留一到两行空间；原图像素不变。不要将作者数据系列套用卡片语义色，也不要把未经核对的重命名当作原图标签。

转录轴名或图例时明确标记“据原图转录”，与原图逐项核对。转录用于阅读辅助，不能掩盖错误裁切；原图保留了必要语境，主结论涉及的趋势或差异也必须看清。

## 6. 对本次反馈的具体修复顺序

截图中的 PLA 页讨论的是生态型曲线分离。完整 Fig. 3 包含多个任务，不能与曲线面板平均分配主空间。先保留曲线面板及其坐标、单位、生态型图例和标准差说明，扩大为主证据；在旁边用清楚层级说明“观测单位”“图中观察”“统计解释边界”。完整 Fig. 3 仅在讲任务链时出现，或作为明确的定位图，不能再次充当可读证据。

若任务改为解释多智能体如何完成五个步骤，就以任务流程及各步输入输出为主，选择流程布局；不要仍然沿用结果曲线页。**同一原图可以支持不同汇报任务，每次选版都从当前要解释的关系开始。**
