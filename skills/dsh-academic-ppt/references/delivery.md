# 正式交付与真实复核

## 分清验证范围

| 范围 | 实际能验证 | 不能替代 |
| --- | --- | --- |
| 学术记录 | 来源、引用链、口径、要求是否齐全 | 全文阅读和科学判断 |
| 叙事与导航检查 | 声明的章节引用、目录映射、次序及缺项 | 论证真的连贯、转折有依据、结尾回答了问题 |
| 内容与几何检查 | 载体是否消费、尺寸、边界、字号估计、空间风险 | 关键语义真的正确、最终字体与审美 |
| PPTX生成 | 文件与原生对象存在 | 正常放映、好看或完整可读 |
| 实际渲染 | 当前PPTX生成真实PNG/PDF和字体报告 | 人或视觉模型逐页查看 |
| 逐页审查 | 具名执行者实际看过的当前页面及观察 | 其他版本、未看页或独立科学验证 |
| 跨稿结构比较 | 指定工程中的主体结构近似 | 像素审美、原创率或抄袭判定 |

## 顺序

先check修复阻断项，再build。小样可用draft并保留原brief；最终稿使用review。render后先看整稿概览，再按可读尺寸查看所有页面，包括封面、书目与补充页。HTML只作辅助，不能冒充PPTX的实际显示。

代表页用于提前发现设计和执行问题，必须包括真实信息量的困难页。确定方向时查看连续三页的任务与视觉节奏，再扩展整稿；短稿按实际页数处理。全稿检查覆盖新的全部内容。同轮问题集中修复后重建，额外渲染针对具体问题。

先只读目录、章节问题、页标题、transition与结尾，核对问题如何逐步得到回答；再在整稿概览中检查导航可见性和节奏。较长报告不能只在JSON里有路线而画面缺少定位；短稿也不必为达到固定数量插入空章节页。声明中的坏引用需修复，章节回看和空间提醒结合实际论证与画面判断。

## 每页检查什么

打开当前逐页设计稿，与实际页面逐项对应：实际可见内容和来源、语义关系、表达载体、层级与阅读路径。必要内容应能找到对应对象；完整设计稿不能在生成后补写成对现状的解释。若设计本身需要改变，同步更新相关段落并保留原因，再核对新输出。

1. 页面与讲稿支持同一主题或判断；来源报告、推断、未实施方案清楚区分，样本单位、分母、对照、信息条件和单位完整。
2. 逐项回查本页必要信息：主证据、辅助比较、条件、方法和解释是否按实际需要可见，缺项是否影响判断。定量结果没有退化为几个大数字；原图分布、时空结构和不确定性没有无理由删去。不用字数或图片配额替代充分性判断。
3. 入口、主次和阅读路径清楚，比较、包含、先后或解释归属能从画面读出。入口可是一组共同组织的表图或方法区域，primaryPanelId不要求唯一大图。查看实际距离、尺度、连接和边界，而不仅是visualPlan的文字。
4. 章节、页题、题签、普通解释、数据/轴与来源有各自字级；按先前确定的阅读场景检查最终缩放后的实际字形。主要读数、条件和边界不能降为note。28/24/18px的默认值不代表所有角色应统一大小，也不能在失败后调低projection清除提示。
5. 流程输入、预测、反馈、分支和返回对象正确。端点不误接，交叉不暗示汇合，标签靠近对应线，路径修改后标签同步。
6. 裁切保留必要轴、单位、图例、尺度与面板身份；重建的轴名、刻度、图例与原图位置和含义一致。数据点不被遮挡或篡改。
7. 章节定位、页级题名与局部题签的职责和视觉层级清楚，标题具体、断行合理，封面使用完整题名和真实身份。标题承托与正文区域相协调，没有靠过大标题挤掉证据。自定heading继承chrome时检查实际重叠，省略重复题签时保留必要定位。
8. 需要的卡片描边与题签实际可见，题签/正文结构适合内容；开放旁注有归属，必要嵌套表达包含关系。组内风格一致，不靠换色、换圆角或轮换stacked/banded/side-label冒充新构图。颜色职责清楚，关键身份不只靠颜色辨认。
9. 连续看相邻页面，确认本页接住什么、补了哪些信息、下一页为何出现，结尾回应开场并保留边界。不同任务没有机械重复同一骨架；同一实验的共同尺度、相关面板和必要复用仍保留。

有参考时，回到[template-learning.md](template-learning.md)的具体差距记录，确认本轮修复是否出现在实际页面。材料种类与丰富度不同如实说明；可改的标题、层级、标注、邻接和组合问题继续修复。仅颜色或字号接近不代表参考学习完成。

代码提醒只定位风险。contentLayers、readingOrder或其他声明存在，不证明信息足够或关系已经落实。自绘表格或关系有时未被自动识别，须结合页面和来源核对并保留解释；不能删提示、添加无关图或画空框刷过检查。

封面、目录和分节页允许服务层级与定位的留白，其空间提醒通过实际画面复核；不要为消除提醒增加装饰图或冗余文字。正文仍检查证据覆盖、可读性和compact空间要求。留白政策不豁免缺字、重叠、错位或不可读导航。

缺失字体列表为空不证明所有字符可用。实际检查数学上下标、希腊字母、负号与单位。出现方框时选择有相应字形的字体或准确的原生字符定位方式；必要时保留独立公式源资产，不能删符号。

## 记录与修订

用当前pptxSha256登记review，reviewedSlides仅列实际确认的页，observations逐页写contentCheck、legibilityCheck与issue。描述本页具体观察，不能复制一套“检查通过”。有未解决问题记needs-fix，模型不能冒充human。

修改后重新构建，旧哈希的批准不转移。确认最终整稿实际页面与当前产物对应；若借助未变化页面的字节一致核对，明确先前实际看过的版本、变化页和比较范围，不把它写成新的人工查看。接口接受审查也不证明声明真实，执行者需保留可复核依据。

修复次序是科学错误/缺项、载体与关系、比例和阅读层级、细节。只对剩余具体问题继续返工，不以降低要求、缩小关键文字、改verified或删科学限定掩盖。

readyForDelivery只是当前记录、构建、渲染与具名审查的汇总，不能称为学术论坛通用验收、科学真实性认证或模型稳定效果。

## 交付

提供当前可编辑PPTX、对应讲稿、实际渲染PDF/页面和可恢复工程，保留必要来源、许可与资产。说明影响使用的字体、编辑范围或未完成验证。论文原图是独立图片，不声称其内部点与文字全部可编辑。

正式画面与讲稿不放构建日志、版本验收术语或制作报告。验证细节另存。只有实际打开PowerPoint/WPS、实际运行用户宿主或真人排练后，才能声称完成相应验证；记录重建不算新模型创作。
