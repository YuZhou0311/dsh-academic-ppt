# 正式交付与真实复核

## 分清验证范围

| 范围 | 实际能验证 | 不能替代 |
| --- | --- | --- |
| 学术记录 | 来源、引用链、口径、要求是否齐全 | 全文阅读和科学判断 |
| 内容与几何检查 | 载体是否消费、尺寸、边界、字号估计、空间风险 | 关键语义真的正确、最终字体与审美 |
| PPTX生成 | 文件与原生对象存在 | 正常放映、好看或完整可读 |
| 实际渲染 | 当前PPTX生成真实PNG/PDF和字体报告 | 人或视觉模型逐页查看 |
| 逐页审查 | 具名执行者实际看过的当前页面及观察 | 其他版本、未看页或独立科学验证 |
| 跨稿结构比较 | 指定工程中的主体结构近似 | 像素审美、原创率或抄袭判定 |

## 顺序

先check修复阻断项，再build。小样可用draft并保留原brief；最终稿使用review。render后先看整稿概览，再按可读尺寸查看所有页面，包括封面、书目与补充页。HTML只作辅助，不能冒充PPTX的实际显示。

代表页用于提前发现规则问题；全稿检查覆盖新的全部内容。额外渲染针对明确失败，不能为每个词反复重建，也不能为了减少轮数保留实际问题。

## 每页检查什么

1. 页面与讲稿支持同一主题或判断；来源报告、推断、未实施方案清楚区分，样本单位、分母、对照、信息条件和单位完整。
2. 主证据确实在画面中，图、表、方法关系与解释对应。定量结果没有退化为只有几个大数字；原图分布、时间/空间结构或不确定性没有被无理由删去。
3. 主辅关系、图旁解释与局部分组清楚；既没有等大碎卡铺满，也没有大标题、小注释与散落文字取代设计。参考可用时并列比较组织与阅读体验。
4. 普通解释保留中间字级；主要读数、基线、必要标签与结论边界能当场阅读，辅助注释才可较小。检查最终缩放后的字号与实际字形。
5. 流程输入、预测、反馈、分支和返回对象正确。端点不误接，交叉不暗示汇合，标签靠近对应线，路径修改后标签同步。
6. 裁切保留必要轴、单位、图例、尺度与面板身份；重建的轴名、刻度、图例与原图位置和含义一致。数据点不被遮挡或篡改。
7. 标题具体、专业、断行合理，封面有完整题名和真实身份。无用重复角标、题签与横线回收，主证据没有被嵌套边距挤小。
8. 页序推进与视觉语言协调。不同任务的页面没有只换标题或颜色复用同一骨架；科学上必要的共同尺度对照保留。

代码提醒只定位风险。自绘表格或关系有时未被自动识别，须结合实际页面和来源核对，保留解释；不能删提示、添加无关图或画空框刷过检查。有图片也不证明科学证据已经完整。

缺失字体列表为空不证明所有字符可用。实际检查数学上下标、希腊字母、负号与单位。出现方框时选择有相应字形的字体或准确的原生字符定位方式；必要时保留独立公式源资产，不能删符号。

## 记录与修订

用当前pptxSha256登记review，reviewedSlides仅列实际确认的页，observations逐页写contentCheck、legibilityCheck与issue。描述本页具体观察，不能复制一套“检查通过”。有未解决问题记needs-fix，模型不能冒充human。

修改后重新构建，旧哈希的批准不转移。确认最终整稿实际页面与当前产物对应；若借助未变化页面的字节一致核对，明确先前实际看过的版本、变化页和比较范围，不把它写成新的人工查看。接口接受审查也不证明声明真实，执行者需保留可复核依据。

修复次序是科学错误/缺项、载体与关系、比例和阅读层级、细节。只对剩余具体问题继续返工，不以降低要求、缩小关键文字、改verified或删科学限定掩盖。

readyForDelivery只是当前记录、构建、渲染与具名审查的汇总，不能称为学术论坛通用验收、科学真实性认证或模型稳定效果。

## 交付

提供当前可编辑PPTX、对应讲稿、实际渲染PDF/页面和可恢复工程，保留必要来源、许可与资产。说明影响使用的字体、编辑范围或未完成验证。论文原图是独立图片，不声称其内部点与文字全部可编辑。

正式画面与讲稿不放构建日志、版本验收术语或制作报告。验证细节另存。只有实际打开PowerPoint/WPS、实际运行用户宿主或真人排练后，才能声称完成相应验证；记录重建不算新模型创作。
