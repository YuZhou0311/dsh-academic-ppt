# 验收、讲稿与可复用交付

## 1. 分别报告五种结论

| 检查 | 核查 | 不能额外声称 |
| --- | --- | --- |
| 科学 | 题名、版本、定位、数值、单位、分母与限制 | schema 通过即全文读完或结论正确 |
| 论证 | 页任务、标题与证据、共同比较层面、可证伪方案 | 图文足够即逻辑清楚 |
| 视觉 | 当前预览/渲染的截字、遮挡、图例、密度、重复 | HTML/SVG 通过即 Office 渲染正确 |
| 文件 | 可读取、页序、文字/形状、图片、备注、字体环境 | 导出成功即图内全部元素可编辑 |
| 范围 | 目标 diff、锁定对象/备注保持、正确基线 | 保留通过即用户审美认可 |

调用 `academic_ppt_check` 后读取问题与实际范围，修复实质错误再构建检查。虚构来源、关键口径错误、丢图、严重遮挡和错误版本优先处理，不能用总分抵消。

`mode: review` 构建会检查证据门槛；`draft` 供材料不齐的草稿，不是绕过全文/IF 要求交付最终版的方法。

## 2. 查看当前产物

先看最长题名、最密原图、最密图注、最矮卡片与复杂单位页，再看全页序。连续缩略图识别主次和重复，全尺寸查文字与科学读图；最终成品另查字体和换行差异。

视觉复核逐页回答：第一眼看到什么，沿什么顺序读，哪张图支持当前标题，哪处需要放大才懂。检查下列具体问题，不能只登记“美观、清楚、通过”：

- 主证据的关键轴、单位、图例、误差和对照可读；定位图没有冒充主证据。
- 标题、区域标题、正文与引用有清楚层级；必要条件未被缩进微小 kicker 或脚注。
- 颜色与卡片形式表达内容身份及并列、步骤、嵌套或限制关系；同一比较保持一致编码。
- 轻阴影和边框贴合实际图片边界，未造成空槽、遮挡或与原图图例冲突。
- 空疏区域经过内容判断：放大证据、补必要解释或合并薄页；密集区域保留可读正文，未靠缩小所有字解决。

若“放大原图可以读”但“当前 PPTX 上无法读”，本页仍需修改。可读性估算只辅助选型，实际看图者还须核对裁切语义。检查项的实现与失败修复见 [figure-selection.md](figure-selection.md) 和 [visual-decision.md](visual-decision.md)。

`academic_ppt_render` 使用默认安装包含的可选官方 LibreOffice Kit；使用 `--omit=optional` 安装则只保留普通生成，缺引擎记录 unavailable。默认用系统字体；缺字体时可传 `fontDirectories` 指向 1–4 个工作区内的有许可字体目录。自产 HTML/SVG 不代替 PPTX 渲染，未检查后者就明确范围。

`academic_ppt_review` 绑定当前 expectedRevision 与 pptxSha256；选真实 reviewer，列实际 reviewedSlides，准确选择 html-preview 或 pptx-render，记录 passed 或 needs-fix 及具体 notes。模型无视觉能力时不能冒充 vision-model 审查完成。

修订后的产物重新审查；旧通过记录不覆盖新版本。登记支持图像的能力声明不能替代实际查看动作。

## 3. 讲稿与当前页序一致

按当前 slides 的标题、证据、备注与 seconds 写讲稿，确保修正过的数字和边界同步。不能从旧稿复制被更正口径。

解释看图哪里、它支持什么、为何接下一页；不逐字读英文题名和文献条目。核心方法与结果保留时间，章节与参考文献快速过。

10–15 分钟可提供约 13 分钟主稿、压缩替换与扩展段。秒数和字数是计划估计，用真实排练校准；未朗读不能宣称精确控时。

Q&A 准备证据类型、样本/分母、基线公平、仿真迁移、假设可证伪性。答案只用已核对材料，不补未做实验。

## 4. 编辑与重建边界

标题、解释、框线、卡片、必要流程和有可靠数据的图表是原生对象；论文图为独立图像。说明可编辑范围，不称图内所有标注与数据均已原生化。

PPTX 可在兼容软件中编辑，JSON 是程序重建来源；Office 修改不会回写 JSON。构建使用新输出目录，保留外部手改成品，不称往返同步。

列出依赖、输入、输出和实测环境。渲染器、字体、模板原件或许可材料缺失分别说明，不能将当前成功写成任意电脑无依赖一键复现。

## 5. 提供用户需要的资产

交付能回答：主稿在哪、如何改、每篇读到什么版本、每张图来自哪里、检查的是哪一版。按用户要求提供：

- 当前可编辑 PPTX 与阅读预览。
- 当前项目 JSON、讲稿/备注、必要重建说明。
- 完整书目、实际阅读版本、获取链接。
- 实际用图、图号/来源/版本/裁切、模板组件映射。
- 检查结果与范围、产物和资产哈希。

只附取得且可提供的文章，其他给固定链接与状态。论文、图、字体、模板与代码分别保留许可；含第三方资产的包不统一套插件 MIT。

打包只保留一份明确主稿，旧版在历史目录注明用途。排除失败下载、缓存、凭据、私有环境配置和重复大文件；检查解包、路径与完整性，不只确认 ZIP 存在。

## 6. 最后回答具体且诚实

先给成品或安装入口，再概括主线、设计、编辑范围与实查内容。全文/IF 条件、视觉或渲染未完成时指出缺项和影响。

数量与哈希来自本次工程，不沿用旧案例成功记录。未实际执行的 DeepSeek 效果评测、PowerPoint/WPS 操作、投影和用户审美验收均不写成完成。
