# 按科学任务选择页面

reference目录提供48种可选结构参考，不构成固定课件或学术内容库。新稿先用composition自主构图；只有当前任务确实适合固定槽位时，通过academic_ppt_reference按category查询：paper / method / experiment / results / figure / synthesis / limitations / plan。它不是必经步骤，不能从示例正文起稿。

论文导读只在需要解释单篇身份时使用，不强制每篇做一页。机制页表达有意义的节点关系；实验页突出分组、采样、对照与指标；结果页让证据可读并解释关键条件；综合页体现机制/证据的比较；局限页指出具体外推风险；方案页给可证伪设计。

选择后将referenceTemplateId和layout对应写入slide。panelTitles按实际科学内容命名，不能继承模板自带的评语。默认返回中性结构，完整示范仅在includeExamples:true时提供，严禁把其正文/图片/数字复制到新研究。

数量、比例或读图任务与固定页型不合时，优先使用composition；只有确需绝对图框时才用受控figureBoxes，也可拆页。不要删除关键对照和限定去满足布局槽位。图像选择与可读性看figure-selection，模板风格迁移看template-learning。
