# 代表页决策与局部修复

代表页选择封面、最难证据页、机制或综合页。分别列出主任务、必要内容、限制和最多两个可行构图，选择能保留科学信息且阅读顺序明确的一种。记录简短依据，不为每页写长篇自评。

先看真实输出的视觉重心与顺序，再看标题、图例、轴、对照、正文和引用。空疏页补必要分析或合并；拥挤页先去重复、调比例或拆论证，不能缩小全部文字。

一次固定主色、字体层级、标题和图注规则，后续复用。变化应来自科学关系：对比、步骤、证据与解释、验证范围。不要通过换阴影、边框、圆角制造形式多样性。

修复清单记录slideId / objectId / 问题 / 修改 / 当前hash。只改失败对象相关区域；card-style不改文字与外框，改内容或图框用slide-content。重复失败先核查字段和布局容量，不反复盲试。

全部问题解决后停止。美观是对最终图像的判断，不能由“0 errors”、自设分数、模板数量或字符数量代替。
