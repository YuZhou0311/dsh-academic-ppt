# 从证据到构图

## 先写可检查的设计简报

先按[storytelling.md](storytelling.md)确定中心问题、章节问题与跨节过渡，再明确每页的任务、必要信息与信息间关系。先在可修改的逐页大纲中分配证据和时间，再绘制布局；不要先完成短句摘要或固定双栏，再找图片填空。来源图的比例、内部面板、标签与不确定性参与设计。

为整稿在design.direction记录简短视觉方向：材料约束、证据组织、学术色板选择、层级与重复任务的处理。该记录是设计依据，不是原创性证明。页面主色和数据变量色分别确定职责，不把品牌式大色面或功能宣传卡片作为默认。字段以contract(topic:design)为准。

| 信息关系 | 可采用的组织方式 | 必须核对 |
| --- | --- | --- |
| 比较 | 共尺度多图、对照矩阵、配对标记、同列指标表 | 单位、条件、基线与信息预算能否对齐 |
| 过程与验证 | 输入/操作/输出及分支，在对应步骤邻接证据或判定 | 先后、依赖和返回对象是否有来源，验证针对哪一步 |
| 层级与范围 | 主辅区、嵌套组、整体与局部视窗、尺度映射 | 包含范围是否准确，局部放大是否保留语境 |
| 证据与解释 | 主图加局部标注、图表加条件组、上部发现下部推导 | 每段解释是否对应具体观察，关键条件能否就近找到 |
| 时间与任务 | 阶段线、任务×时间矩阵、进度证据与下一节点 | 日期、持续时间和状态是否真实，位置是否被误读为数据 |
| 综合与取舍 | 多源证据、判断与边界逐项对应，问题与修正相接 | 是否跨条件过推，缺失和反证是否分开，方案是否未实施 |

这些是设计问题，不是固定模板。当前资料只能支持准确文本时可以使用文本，但不要把已存在的分布、时空图、原生表格和方法结构压成几句总结。

## 先盘点本页需要哪些信息

为本页问题列出必要的信息及来源，再决定其显示方式：用于判断的主证据，支持比较的辅助数据或反例，理解方法所需的关系，影响解释的条件，以及本页带来的认识。只保留当前任务需要的项目；没有来源的信息写成缺项，不为了完成这份清单补造。

把每项对应到原图、表格、数值图、关系图、公式或准确文字，并明确它对本页判断的作用。核心条件、读数和主要解释进入画面，补充推导可进入讲稿。遗漏关键证据时优先补回载体，不能用更大的标题或数字补偿。信息充分与字多不同，不设统一字数、图片或分块配额。

一个核心问题可以需要多个相关信息组。按关系选择上下分层、大小主辅、内部嵌套、跨栏区域、局部穿插、流程与证据邻接或连续比较；多区域不是等宽并列栏的同义词。单个完整图/表足够时可以保持完整，不强行切块。确定证据面积、邻接和顺序后，才决定哪里需要题签、线、浅底、框或开放文字。

## 比较真实候选

新做整稿时，封面与信息最复杂的证据/机制页各做两个实质不同的候选。封面以真实题名、范围与元信息设计，无需图片；比较题名承托、主副题与信息分组的关系，仅把相同文字左对齐或居中不算实质变化。困难页保留实际证据量、必要条件和解释。比较的是不同的阅读路径与信息组合，例如完整图加局部解释与共尺度多图加指标表、整体流程与分阶段验证；不能删掉一半信息使某个候选显得整洁。是否用图由内容决定，不为形成第二方案添加装饰。

通过academic_ppt_study保存实际候选与预览：优先使用candidatesPath指向工作区中小于1MiB的UTF-8 JSON候选数组，元素包含id、label和完整slide；outputDir使用尚不存在的新目录。候选工具不改原工程，也不登记正式视觉批准。需要时可产生给外部图像模型的视觉参考提示词。没有生图服务仍应完成原生候选。科学图、公式、箭头关系和数据值不交给图像模型编造。

按信息保全、科学关系、投影可读性、标题层级、主辅组织和参考体验比较，记录具体弃选理由。字体、颜色、圆角或图标变化不算独立构图。选定后先延展成含相邻关系的连续三页片段，查看信息有没有推进、标题是否相接、骨架是否机械重复，再完成全稿。短稿按实际页数处理。只有确实影响用户目标的偏好才请求选择，常规设计由作者完成。

## 落实阅读层级

组合页用visualPlan记录主关系、primaryPanelId、readingOrder与rationale，字段以contract为准。readingOrder覆盖本页实际区域一次；位置、大小、对齐与颜色必须支持这个顺序，记录不会自动移动内容。原生封面、章节和参考页无需机械填写面板计划。

需要说明信息层时，使用可选contentLayers，每项为`{role,panelIds,summary}`。role取evidence / explanation / conditions / method / synthesis，panelIds指向本页真实composition区域，summary说明这些区域承载什么。一个信息层可关联多个区域；这些角色不是五个必填槽，也不代表五个框。层记录不生成图文，不能代替核对实际信息。

依次处理：

1. 为主要证据分配可读面积，保留轴、单位、图例和研究对象。
2. 把局部条件、解释与边界放在对应证据附近，减少重复标题与跨栏寻找。
3. 让章节定位、页级题名、局部题签各司其职，用承托、对齐、字重和少量语义色建立层级；只有真正辅助信息使用注释级。
4. 按归属决定题签、细边、浅底或开放注释。若确需卡片，再设计题签与内容的相对位置；同一比较组保持一致，不把任何一种组件变成全稿默认。
5. 检查空区是否服务分组、比较或图本身；空间不足先重新组织或拆任务，不能删除会改变判断的限定。

composition.rows适合流式行列，composition.regions适合跨行或不规则证据区域；drawings适合自绘关系与局部组件。选择最能保留当前材料的结构，不为展示接口复杂度增加元素。

## 整稿与跨稿

检查目录、章节定位、过渡与结尾是否构成可读路线，再连续看相邻页：上一页留下什么问题，本页补了哪些信息，下一页为何出现。检查不同任务是否反复沿用相同主载体、区域比例与阅读路径。共同尺度、相同实验阶段的系列页可以同构；明确其比较目的。只改颜色、标题、对象ID、圆角或比例小数不会改变骨架。

提供了先前工程时调用portfolio，再并列看实际概览与相关单页。没有工程不扫描其他任务文件。自动结构比较只是提示，未检出重复不证明优秀原创性。具体工作见[originality.md](originality.md)。

## 修复顺序

科学错误和缺项优先，其次是载体与关系，再是主次比例、图文邻接、阅读层级，最后处理线宽与间距。稀疏页先找被删掉的图表或必要解释；拥挤页先去同义重复、调整布局或拆分。装饰不能填补科学内容。

按页面和对象记录具体问题。修改后查看当前PPTX；只针对仍存在的失败继续返工，避免为追求变化而破坏已清楚的科学比较。
