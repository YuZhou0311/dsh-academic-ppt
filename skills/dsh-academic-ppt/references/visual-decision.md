# 从论证到构图

## 先写页面设计简报

先完成 `argument` 与来源关联，再回答四个可以外显检查的问题：听众应理解什么；什么证据承担这个任务；信息之间是什么关系；先看哪里再看哪里。无需输出完整思维过程，保留简短决策即可。

把正文关系映射为合适的载体，比例由内容和可读性决定：

| 信息关系 | 优先表达 | 适配时检查 |
| --- | --- | --- |
| comparison | 共享条件的并排图、同尺度小图或对照矩阵 | 比较单位、基线、时间与实验条件能否对齐；不齐处是否可见 |
| sequence | 分阶段的流程与输入输出 | 先后是否真实，是否有分支、反馈或停止条件 |
| mechanism | 作用关系、假设路径与对应验证 | 关联与因果是否区分；边有没有证据或明确假说身份 |
| hierarchy | 层级节点、嵌套概念或变量分解 | 上下级含义是否一致；分组是否互斥/穷尽需按研究说明 |
| evidence-explanation | 主图或科学图，紧邻解释与短边界栏 | 第一眼是否看到证据；解释是否比原图更醒目 |
| matrix | 原生表格、证据与问题的交叉对照 | 只有真实可比较维度进入同一列，未知值保留未知 |
| synthesis | 已有证据、可支持判断、缺失验证逐项对应 | 归纳有无跨条件过推，提案是否标明待检验 |
| definition | 定义、核心示例与适用边界 | 不为制造结论把定义写成实证发现 |

这是一组关系词，不是八张固定模板。组合页允许多种关系并存，选择主关系记录。载体不足时使用准确文本即可，不强制图表或虚构数据。

## 保存可审阅的选择

组合正文页使用 `visualPlan`；精确字段以 `contract(topic:"slide")` 为准。例如，下列片段必须对应本页真实存在的 `evidence` 和 `boundary` 面板：

```json
{
  "visualPlan": {
    "relationship": "evidence-explanation",
    "primaryPanelId": "evidence",
    "readingOrder": ["evidence", "boundary"],
    "rationale": "给区间图保留可读宽度；边界紧邻图中跨零结果，避免只突出点估计。",
    "alternatives": [{
      "structure": "上下排列分布图与边界说明",
      "tradeoff": "本页只需一幅区间图，上下结构会压缩长组名与横轴。"
    }]
  }
}
```

该片段只演示字段，引用的图及统计含义必须在当前来源中成立。`rationale`说明当前内容为什么适合该结构，不能每页复制“清晰、美观、有层次”。`primaryPanelId`指定希望成为视觉焦点的真实面板；工具只检查其存在，不自动分配更大面积。`readingOrder`覆盖所有面板一次，也不改变其实际位置；通过大小、邻近、对齐与标注实现该顺序，再看图确认。

封面、章节和参考文献页不需要这个面板计划。已有旧稿兼容缺省。正文计划只进入工程与恢复上下文，不把设计说明写进投影画面或讲稿。

## 只在关键决策上比较候选

对最难证据页、机制或综合页，提出两个有实质差异的构图。例如大图加旁注与共享坐标的小图矩阵、流程加验证栏与按实验阶段对齐的分区。先比较科学关系表达、完整性、可读性与全稿一致性，再确定一个；不是只比较两种颜色。

把选定结构落实为composition，未选方案可保存到最多两条 `alternatives`。简单页无需机械提出多个方案，常规任务也不必请求用户挑选风格。若用户已指定结构，按其约束设计。

## 用层次组织充盈

1. 确定一个主证据或主关系，给它足够空间，图中文字和对照条件必须可读。
2. 将必要解释放在对应证据附近。可用短旁注、条件条、对齐表格、相邻机制节点；不用每条文字都包一张卡。
3. 用字体层级、有限强调色、对齐和组间空隙区分主次。面板surface表达分组，不能把装饰框堆在证据上。
4. 将来源和重要边界放在读者能够发现的位置。影响结论的限制不得只藏在讲稿。

相同任务的并列图可以等大，主证据与辅助说明一般不应等权。不要设置固定卡片数、固定图文比例、最低填充率或“每页必须不同”。保持共同尺度或连续实验的同构页可在 `repetitionReason` 解释原因；该说明不是审美合格证。

## 渲染后作具体修复

先看全稿概览：研究推进是否清楚、连续页是否只有标题变化、设计语言是否统一。再看单页：焦点、顺序、图例、轴、正文、限定和出处是否完整，短旁注是否被拉成长空框。

修复顺序：科学错位或缺项；载体与关系不匹配；图文比例和空间分配；可读性；细节样式。空疏页补必要分析或合并，拥挤页去重复或拆解论证，不缩小全部文字。

按slideId / objectId记录具体问题与修改。card-style仅改允许的卡片样式；composition和visualPlan的变化用slide-content。修改后重新构建并查看当前PPTX。自动提醒只定位风险，不产生原创率、审美分或“模型已独立思考”的证明。解决具体问题后停止装饰性返工。
