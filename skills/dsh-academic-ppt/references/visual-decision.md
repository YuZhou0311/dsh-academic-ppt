# 从证据到构图

## 先写可检查的设计简报

每页先明确听众要判断什么、必须看到哪些证据、信息之间是什么关系、哪些条件改变解释，再决定阅读顺序。来源图的比例、面板结构、标签与不确定性在这一步参与设计；不要先写固定双栏文字再找图填进去。

为整稿在design.direction记录简短视觉方向：材料约束、证据组织、层级与重复任务的处理。该记录是设计依据，不是原创性证明。字段以contract(topic:design)为准。

| 信息关系 | 可用载体 | 必须核对 |
| --- | --- | --- |
| 比较 | 同尺度并排图、对照矩阵、配对标记 | 单位、条件、基线与信息预算能否对齐 |
| 过程 | 输入、操作、输出、分支与反馈 | 先后和返回对象是否来自真实方法 |
| 机制 | 实体/变量关系及对应验证 | 因果、关联、假设与已验证关系是否区分 |
| 层级 | 概念分解、嵌套范围、尺度映射 | 上下级含义与包含范围是否准确 |
| 证据与解释 | 主图、就近标注、必要边界 | 解释是否对应具体观察，图是否仍是主要载体 |
| 综合 | 证据、可支持判断、待补验证逐项对应 | 是否跨条件过推，方案是否标明未实施 |

这些是设计问题，不是固定模板。当前资料只能支持准确文本时可以使用文本，但不要把已存在的分布、时空图、原生表格和方法结构压成几句总结。

## 盘点信息怎样出现在画面

为主张、重要方法步骤和关键条件指定载体：原图、表格、数值图、关系图、公式或解释。记录对应页及来源。遗漏关键证据时优先补回载体，不能以大标题或大数字代替分布、对照和不确定性。

一个页面可以有一个主关系和若干辅助关系。相同条件的比较对象可等大，主证据与辅助解释按阅读任务分配空间。图旁短注可以开放对齐，独立条件组可以浅底或题签，复杂解释可围住；边界的形式由归属决定，不强制每段套框。

## 比较真实候选

新做整稿时，封面与最难证据/机制页各做两个实质不同的候选。候选必须含当前真实图、标题、条件和解释，能生成SVG/PPTX查看。可比较：完整图加侧注与相关面板组合；按数据路径组织的方法图与按状态更新组织的反馈图；题名与研究对象并置与题名融入研究关系的封面。

通过academic_ppt_study保存实际候选与预览：优先使用candidatesPath指向工作区中小于1MiB的UTF-8 JSON候选数组，元素包含id、label和完整slide；outputDir使用尚不存在的新目录。候选工具不改原工程，也不登记正式视觉批准。需要时可产生给外部图像模型的视觉参考提示词。没有生图服务仍应完成原生候选。科学图、公式、箭头关系和数据值不交给图像模型编造。

按信息保全、科学关系、投影可读性、主辅组织、参考体验比较，记录一个具体取舍。字体、颜色或图标变化不算独立构图。只有确实影响用户目标的偏好才请求选择，常规设计由作者完成。

## 落实阅读层级

组合页用visualPlan记录主关系、primaryPanelId、readingOrder与rationale，字段以contract为准。readingOrder覆盖本页所有区域一次；实际位置、大小、对齐与颜色必须支持这个顺序，记录不会自动移动内容。原生封面、章节和参考页无需机械填写面板计划。

依次处理：

1. 为主要证据分配可读面积，保留轴、单位、图例和研究对象。
2. 把局部条件、解释与边界放在对应证据附近，减少重复标题与跨栏寻找。
3. 用必要的中间字号、粗细、对齐和少量语义色建立层级；只有真正辅助信息使用注释级。
4. 选择有职责的浅底、细线、题签或开放分组；不要整页变成等大卡片，也不要全页只剩散落的大小字。
5. 检查空区是否服务分组、比较或图本身；空间不足先重新组织或拆任务，不能删除会改变判断的限定。

composition.rows适合流式行列，composition.regions适合跨行或不规则证据区域；drawings适合自绘关系与局部组件。选择最能保留当前材料的结构，不为展示接口复杂度增加元素。

## 整稿与跨稿

检查不同研究任务是否反复沿用相同主载体、位置关系和页序。共同尺度、相同实验阶段的系列页可以同构；明确其比较目的。只改颜色、标题、对象ID或比例小数不会改变骨架。

提供了先前工程时调用portfolio，再并列看实际概览与相关单页。没有工程不扫描其他任务文件。自动结构比较只是提示，未检出重复不证明优秀原创性。具体工作见[originality.md](originality.md)。

## 修复顺序

科学错误和缺项优先，其次是载体与关系，再是主次比例、图文邻接、阅读层级，最后处理线宽与间距。稀疏页先找被删掉的图表或必要解释；拥挤页先去同义重复、调整布局或拆分。装饰不能填补科学内容。

按页面和对象记录具体问题。修改后查看当前PPTX；只针对仍存在的失败继续返工，避免为追求变化而破坏已清楚的科学比较。
