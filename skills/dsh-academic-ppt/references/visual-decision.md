# 把审美判断转成可执行的页面决策

在初次选版、视觉返工或模型倾向重复卡片时读本页。设计目标是让听众迅速看出研究对象、证据和解释的主次与关系；用用户认可的学术模板约束形式，不用“高级、丰富、简洁”三个形容词代替设计决策。

## 1. 一页只做一份短设计摘要

构建前记下：本页任务、主证据、必要限定、读图顺序、字号层级、语义颜色与形式、为何选择当前构图。控制为可核查的短记录，不保存长篇内部推理，也不把制作说明放进汇报正文。

先看难例：最密论文图、最长题名、方法闭环、结果与限制混合页。对难例生成 2–3 个有意义候选并选择一个；普通页沿用已建立的视觉语言。每次只改变能够解释的设计变量。

## 2. 字号、字重与局部强调共同分工

在 1280 × 720 场景中，当前默认主标题为 40 px（30 pt），卡片小标题为 26 px（19.5 pt），正文为 24 px（18 pt），引用通常为 16–18 px（12–13.5 pt）。这些是起点，不是投影一定可读的证明；实际模板、长英文词、图内标签和观看距离仍须检查。

- **主标题**：指出本页对象、方法或有条件的结果。保留最大稳定字级和足够字重，避免标题与下方所有小标题同等突出。
- **区域标题**：用短而具体的名词区分“实验单位”“模型输入”“主要观察”“外推条件”。颜色承接该区域的语义，不再加一行微小类别说明。
- **正文**：承担完整解释。对决定理解的变量、分母、条件或比较对象做局部强调，其余保持深色正文。
- **引用**：允许较小字，集中表达出处。会改变结论的限制必须保留正文尺度，不能作为脚注藏起来。

默认省去标题上方的微小 `kicker`。必要的“仿真研究”“尚未实施”等身份信息，放入标题、可见副题或正文限定；删装饰标签时先检查是否会丢失科学身份。重复章节名、页型名和英文栏目不值得占据每页顶部。

用 `card.emphasis` 指定最多 4 个正文中的精确片段；渲染器保留原生富文本。不要在正文直接塞 Markdown 星号，不强调每句话，也不靠增大单个数字掩盖单位和分母。

```json
{
  "id": "unit",
  "kind": "setting",
  "title": "独立生物学单位",
  "body": "24 株植物是重复测量主体。1,248 幅图像是观测总量。",
  "claimIds": ["C3"],
  "emphasis": ["24 株植物", "重复测量", "观测总量"]
}
```

这是[随包论文示例](../../../examples/science-demo.mjs)中 C3 的卡片记录片段，需与对应论文、证据和页面共同登记。强调不改变原文口径；不能把“观测总量”换成“独立样本量”。

## 3. 颜色与形式必须表达同一种关系

优先使用 `card.kind` 和方法节点的 `kind`，让同类信息跨页一致。下面是默认语义，不要求一页同时出现全部颜色。

| 内容身份 | 颜色与形式方向 | 听众应能辨认的关系 |
| --- | --- | --- |
| `question` 研究问题 | 深色标题、开放文字或细线 | 接下来的证据要回答什么 |
| `method` 方法与操作 | 蓝色、题签或清楚连接线 | 输入怎样转为输出，谁调用谁 |
| `setting` 设置与共同条件 | 蓝灰、侧标或浅底 | 哪些条件共同适用于当前比较 |
| `result` 结果与观察 | 青绿、结果题签或数值区 | 原文实际报告的观察是什么 |
| `boundary` 局限与风险 | 赭红、侧标或边界题签 | 结论在哪里停止，何时可能失效 |
| `hypothesis` 待检验方案 | 紫色与虚线/明确“待检验”标题 | 哪些是未来检验，尚无实验结果 |

默认框型分别采用问题开放框、方法浅表头、设置侧标、结果轻纸面、边界题签和假说虚线。可以根据块间关系覆盖 `style`；不要为每张卡片单独发明 `accent`，只有实际模板或清楚的语义映射需要时才覆盖默认色。

颜色不能单独承载含义：同时保留明确标题、位置、边线或连接关系。作者报告、汇报者解释和提议仍由证据记录决定，换一种颜色不能改变其身份。原图中的数据颜色维持作者含义，解释层不要把同一颜色另用于相冲突的类别。

需要表达**并列**时保持共同对齐和相同标题级；需要表达**步骤**时给明确方向；需要表达**嵌套**时使用共同区域；需要表达**证据与限制**时靠近放置并区分形式。不要把这些关系全部画成互不相连的三张等宽卡片。

## 4. 用结构变化丰富质感

从原模板提炼题签、短侧标、细框、浅底、连接线与图像边界。卡片可混合开放文字、细框说明、嵌边短签和结果区，但先有语义依据。一个页面通常只需少量结构家族；同一对照应保持一致形式，不能为了多样性改成难比较的不同形状。

选择性使用轻阴影，主要帮助原图与白底分离。阴影方向、柔和程度和间距跨页一致；结果仍靠文字与图形证明。不要在每个框后加阴影，不使用发光、厚重投影、玻璃效果或巨大纯色色面去填空。

优先缩短无功能的标题区与模块内留白，把释放的空间给图、正文和必要限定。让区域标题靠近所属内容，统一对齐基线。不要把每段短句拉开成相互孤立的小岛。

## 5. 六种常见失败与修复

| 看见的失败 | 具体修复 |
| --- | --- |
| 大竖图缩得看不清 | 回到[图片选版](figure-selection.md)，选相关面板，扩大主证据；定位图不承担读数 |
| 标题和正文缺少层级 | 固定主标题、小标题、正文和引用字级，再突出决定理解的少数词 |
| 顶部和图下全是小字 | 合并重复元信息，省去装饰 kicker，把重要条件升级为正文 |
| 相同卡片和蓝色色块反复出现 | 给块标明身份，再用语义色、形状和相邻关系；保留无框文字区 |
| 页面松散、看着空 | 放大有效证据，补理解所需设置与解释，合并薄页，收紧无功能间距 |
| 为了紧凑把所有内容填满 | 去重复、分主次、调整主图比例或拆任务，保留可读正文与科学限定 |

“空”与“挤”都需依据有效信息判断。没有通用留白百分比，也不以卡片数量、色块面积或字体种类多少计算审美分数。

## 6. 看过当前 PPTX 再下判断

先在缩略图中辨认主次和连续页节奏，再在实际输出尺寸看标题、正文、原图标签、误差含义和密集区域。把页面缩到常见阅读视野再看一次：若需要不停放大才能读清正文，先修布局；不能把“我在原图里读到了”当作“听众能从 PPT 上读到”。

每次视觉复核回答四个问题：第一眼看到什么；沿什么顺序读；哪条证据支持标题；哪一处必须放大才懂。修改后重新看当前 PPTX，不复用旧预览。缩略图用于层级检查，不能代替原尺寸字形与科学读图检查。

用户只要求小卡片时遵循 [revision.md](revision.md)：锁住已认可页型、外框、原图、文本、数值和备注。提出整页问题可以单独记录，不能借修样式改变原本授权范围。
