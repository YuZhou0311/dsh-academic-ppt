## 七项验收标准

| 维度 | 可提交使用的要求 | 有具体依据时认定的问题 |
| --- | --- | --- |
| 1. 封面报告身份 | 一眼可识别具体研究主题、报告性质或场合，以及已提供的汇报人、单位、时间等身份信息。主标题居主位，项目归属、机构及其他元数据从属。未知信息不得编造。 | 标题仅剩笼统领域、与任务不符；重要身份信息被装饰压过或挤出画面；保留未经说明的占位词、错年份、错误机构。单纯采取不同封面构图不构成问题。 |
| 2. 全稿层级与节奏 | 概览可辨识报告的研究问题、证据展开、解释和综合收束。相同层级的标题、正文、注释保持一致。页内主要论点有明确视觉入口；章节标题与本页具体主题能够区分。证据页、路线页、综合页允许不同密度和构图。 | 连续页面看不出主题推进；每页都只有同一泛化章名而无法识别本页内容；同层级标题反复变换视觉权重；装饰、过多同级醒目句争夺主位，妨碍识别主要论点。无章节过渡页、留白较多或构图重复本身不判失败。 |
| 3. 证据与解释关系 | 重要主张能对应到可识别的实验、数据、文献证据或明确标注的假说。读者能回答“看哪个结果、比较什么、支持什么结论”。图注和邻近文字补充实验对象、条件、对照、单位或结论所必需的范围。图像与当前科学对象、机制或流程相关。 | 图只是拼贴，无法知道哪个面板支持哪句话；用概念插图代替已声称取得的实验结果；标题推断明显超出图示；图像与文字中的研究对象不对应而被当作证据；数据与结论的对应关系依赖讲者补出不可见的信息。原始科学真实性无法从画面判断时列为待核实，不臆断为造假。 |
| 4. 复杂关系沿画面可读 | 路线、机制、比较或依赖关系选择合适图形。可从明确起点沿连接追踪到结果，关键步骤、分支、输入输出和反馈有意义且能区分。箭头终点与目标绑定，交叉处不产生多义。综合页能说明不同研究部分如何共同回答问题。 | 箭头穿过文字或重要图形；线条终止在空白、边框或错误对象；并列事项被误画成因果链；关键分支条件缺失；多个链条在画面内混接，无法追踪主路径。不能仅凭框数、箭头数或“看起来复杂”下判断。 |
| 5. 正文与图内字可读性 | 在整页适配显示时，标题、主叙述、关键数值、坐标轴、单位、对照组及图例可辨认；颜色对比足以区分文字与背景。中文、上下标、希腊字母、单位和公式正常呈现。源图中的非关键细字可保留，但不得让结论依赖不可读部分。 | 为了塞内容使主叙述明显小于同稿正文；关键标签只能局部放大才能辨识；截图压缩模糊；图例、单位或刻度无法阅读；缺字、乱码、异常断行破坏术语。用实渲染判断，不在未取得字体信息时捏造字号。 |
| 6. 内容密度与讲解负担 | 一页有清楚的主要任务。高密度页通过分组、顺序、图注或局部强调使读者可逐段理解。证据主体拥有足够面积，结论与条件得到保留。留白服务结构与阅读。 | 多组独立论点堆在一页且缺少阅读次序；结论、图、表、说明互相挤压，无法定位要点；正文被压缩为密集小字；用大块空泛概念替代应有证据。高密度、低密度、三栏或满版都不单独决定优劣。 |
| 7. 遮挡与误导风险 | 文字、图表、图注、页眉和结论区域保持必要间距。关键信息不被覆盖或裁切。颜色、面积、位置和连接方式不制造错误的比较或因果含义。裁图保留理解证据所需的标尺、条件与对照。 | 标题换行后撞入正文；说明框覆盖证据或表格数据；关键数字、符号、轴端或图例被截断；比例被拉伸而改变图示含义；不同实验条件被拼接为可直接比较；颜色编码前后矛盾。轻微不齐只有产生实际阅读后果时才升级。 |

## 成品评审的判定方式

1. 先看全稿概览确认结构与节奏，再逐页查看原尺寸画面。对疑似小字、遮挡或路线歧义定位具体区域，不靠缩略图直接判不合格。
2. 每项问题必须包含“页码与区域、可观察的现象、对报告理解的影响、最小修正方向”。不使用“没有高级感”“不像专家做的”等无法检验的评价。
3. 严重度分为：**阻断提交**（关键信息缺失、核心证据不可读或被遮挡、关系表达产生实质误导）；**提交前必须修正**（显著影响主要页面的阅读与论证，但修改范围明确）；**可优化**（不妨碍准确理解的局部形式问题）；**待核实**（需要源数据或任务材料才能判断，不能仅据画面定性）。
4. 正式可提交要求不存在阻断提交项和提交前必须修正项。可优化项不自动导致不合格；待核实项须明确其与结论的关系，不把未经证实的疑点当作既定缺陷。
5. 不设对象数量、图文比例、卡片数量、满版程度等机械及格线。评审以该页科学任务完成情况与实际可读性为准，也不要求不同研究主题使用同一种图形。

本标准在接触候选成品前固定；后续各轮结果另见 [独立制作与审查](INDEPENDENT_REVIEW_V05.md)，不回改标准迁就产物。
