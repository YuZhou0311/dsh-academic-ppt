### 独立审查发现并修复的两项问题

1. **间接证据来源绕过门槛。** 原复现的推断经多级 dependsOn 依赖只读摘要、无分析/IF/书目条目的第二来源，检查曾为 0 错误且正式构建成功。修复后同一输入出现 7 项明确错误，构建 blocked；新增多级前提回归。
2. **模板组件来源页号错误。** 原来按 XML 文件名推算页号，与放映顺序可能不同。现在研究和组件提取共用放映顺序，sourceSlide 为实际页号，sourcePart 留原部件。回归使用第一放映页 slide205.xml、第二页 slide7.xml，核对组件、节点、不支持对象和 profile 导入。
