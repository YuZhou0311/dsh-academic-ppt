# 0.9.0 设计依据

检查日期：2026-10-27。以下是源代码与真实材料的定性观察，不是对开源项目审美效果的排名或未经重跑的性能比较。

## 从真实失败反推约束

一次由用户提供的失败输出中，正式构建仍有23个错误和49个警告；实际逐页审查记录为 `needs-fix`，但草稿仍被当作成果交付。两幅承担读数任务的论文图实际高度约127px，分别只占整页面积1.73%与2.03%。主要裁切已经被原校验器发现。

这说明需要同时解决执行闭环、图像真实尺寸和计划兑现。0.9.0 引入独立交付操作，保留静态错误、实际渲染、逐页检查和科学来源之间的区别。它不通过修改门槛或增加装饰来掩盖缺陷。一个失败样本不足以证明0.8.3相对0.8.2存在统计性的普遍退化。

另一个可观察问题是恢复过程中删除绘图和计划，导致机制、比较关系退化为等权文字块。新故事板将主要证据和必须可见的条件放入独立记录，并在实际导出画面中核对。

## 从优秀学术模板抽象的设计语法

对本次授权参考的七套模板、148页进行结构读取和实际渲染总览，随后细读60张正文页，包括15张独立大图与45张可读分组页。另重新查看原48卡的30页原生图册与20款局部组件。整页关系与局部质感需要共同设计：同尺度结果、多面板、总览与局部决定内容组织，框线、题签、纸面层次和组内外间距让这种组织可以被看懂。

逐页观察再与PPTX对象属性交叉核对，区分了真正无填充的2.25pt虚线范围、白底1pt细实线加外阴影、没有可见边线的白纸面阴影，以及独立深蓝题签覆盖上边框等情况。部分模板的40%黑色近距阴影与另一些模板8%蓝色大范围柔影不同，不能概括成同一种“加阴影”，更不能把原参数整稿套用。虚线在原页中常承担方法或子图的共同范围，不自动表示未验证。

初次研究样稿虽然完成证据与交付检查，用户仍明确指出卡片细节缺失、浅色块偏多、配色不够正式。这一反馈说明流程合格不能当作视觉验收。修订增加具体组件细读、稳重配色理由、外框paint能力与四页原创细节图册，并在同一科研内容上重做真实正文。

小字、密集论文拼图、3D饼图、每页强制结论条和过多章节页未作为通用要求继承。模板的信息密度不自动成为投影可读性的保证。分析环境使用替代中文字体，观察可支持拓扑和信息组织判断，不能声称像素级还原原始PowerPoint。

新的32种语法与四页框线/纸面/题签示例由本项目独立绘制。没有分发用户商业模板、截屏、Logo、字体、原图、旧内容或特色整页复刻。它们提供研究关系、适用条件、槽位、容量和视觉处理起点，允许按真实来源调整比例或自主构图。组件指南见[学术卡片视觉语言](../skills/dsh-academic-ppt/references/academic-visual-language.md)。

## 学术与交互的边界

故事感来自问题逐步得到回答、出现可信冲突和边界后引出下一步，不来自戏剧化夸大。`reported`、`inference`、`proposal` 继续分开记录，推断须有前提与替代解释。

交互集中在故事线、可见样张、最终使用。一次方向选择可以落实多个样式字段，明确委托后自主完成；样张确认以实际内容为依据。最终使用节点用于审阅科学取舍和讲述准备，不成为普通修复的第二次授权。

软件检查发现可计算问题，实际看图发现画面问题，学术阅读判断结论。任何单一层都不能代替其余两层。
