# 从两份真实学术模板提炼布局规则

本次修订依据用户提供的两份蓝色学术汇报 PPTX：重点项目结题答辩模板 20 页、重点研发计划模板 19 页。2026-10-20 实际读取其原生对象，渲染并查看全部 39 页，再放大检查代表性图文页。以下是对这些具体文件的观察与本插件的设计选择，不是从论文推导的通用密度标准。

源文件包含其原有研究内容、人物照片、标识和第三方图片。公开模板包提供新制作的可编辑参考页与示范资产，未将源 PPTX 或其研究材料整体放入仓库。模板风格研究、原生组件读取和新页型重建是三件不同的事。

## 1. 保留什么

两份模板的主体是白色页面、深蓝结构、近黑正文、淡蓝或浅灰区域，红色用于限定词、重要结果或风险。大量正文页把研究目标、图像、解释、流程和结论放在同一视野内。空间紧凑来自有目的的区域组合，不能简单归结为“字多”或“框多”。

| 参考页面 | 观察到的组合 | 新模板应继承的表达原则 |
| --- | --- | --- |
| 结题答辩第 3 页 | 问题横条、现状与方案图、底部需求 | 背景直接连到研究问题，避免独占一页的泛泛口号 |
| 结题答辩第 5 页 | 上方两组题签图文，下方通栏流程 | 用不同高度的区域表示并列任务与共同执行链 |
| 结题答辩第 6 页 | 多阶段流程、分层输入和输出 | 流程框高度服务节点内容，不拉成长空柱 |
| 结题答辩第 7–8 页 | 框内细分模块、短题签、箭头 | 卡片可以是研究结构的一部分，不能取代结构本身 |
| 结题答辩第 10 页 | 三项机制图文与一列实验证据 | 多项方法归纳旁保留具体证据，不让文字吞掉图 |
| 结题答辩第 11 页 | 左侧图文交错，右侧竖向证据图 | 依据原图纵横比与阅读次序分配空间 |
| 结题答辩第 12 页 | 关键发现、三项对应证据及解读 | 多图具有不同证据职责，避免重复说明 |
| 重点研发第 3–5 页 | 短标签、背景图、进展分区 | 层级由题签、边线和位置共同表达 |
| 重点研发第 7–8 页 | 目标说明、任务分解、图与流程结合 | 学科或模块之间的关系必须可见 |
| 重点研发第 10–12 页 | 目标横条、图组、局部解释与结论 | 图上的关键位置配就近解释；每块内容都有读图作用 |
| 重点研发第 18 页 | 带侧签的风险分区 | 同维度风险保持一致结构，局部差异由内容表达 |

封面、目录、证书展示和结束页不作为正文信息量的标尺。字体替换导致的源文件换行也不属于需要继承的设计。我们借鉴有效结构，而不机械照搬每一页。

## 2. 把用户此前的反馈转成动作

| 反馈 | 生成时的动作 | 审查时看什么 |
| --- | --- | --- |
| 论文完整题名没有上页 | 单篇导读展示完整英文题名、作者、年份、期刊和版本 | 题名是否完整且有足够高度，未被中文总结代替 |
| 读得浅、信息量少 | 先建立方法接口、实验单位、对照、结果和局限记录 | 听众能否复述研究如何完成、证据支持到哪里 |
| 没用好论文原图 | 根据图的方向、面板和图例选择页型 | 原图有效面积、轴字、单位、样本与裁切上下文 |
| 一大堆表格 | 表格用于同维度严格对照，其余用流程或图文关系 | 表格是否比图和分区更能解释当前问题 |
| 模板只剩配色 | 提取标题区、区域比例、边框、题签与对齐关系 | 是否出现可识别的参考结构，而非通用卡片页面 |
| 小卡片单调 | 对必要的局部解释区选择淡蓝表头、嵌边短签、侧签或开放线框 | 样式与语义是否对应，相邻页是否机械重复 |
| 只要求改小卡片却重做整页 | 记录认可基线，以 slideId/cardId 限定样式修改 | 文字、数字、图、卡片外框、其他对象和讲稿是否保留 |
| 品牌化、留白过多 | 缩短无功能标题区，取消装饰大色块，把主证据放大 | 空白是否用于分组和阅读，而不是掩盖缺少解释 |
| 为密度而堆数据很累 | 确定一个研究任务，去掉重复解释，必要时拆页 | 主图、解释、限定三者能否按顺序读懂 |

“主张—证据—边界”约束的是论证，不要求每页画成三张卡片。多样性也不是每页随机换皮：同一比较任务保持一致结构通常更好。

## 3. 选版的实际顺序

1. 写出本页要回答的问题，及听众看完能得到的发现。
2. 列出不可删的证据：主要图、必要对照、关键数值与口径。图不够清楚时先取得更好的原文件，或选择有上下文的局部视窗。
3. 按证据形态选择参考页。宽图、竖图、双面板、执行闭环、实验因子、统计结果与研究方案需要不同布局。
4. 放入证据后补充最少但充分的解释。题签用具体名词；正文解释变量、关系和适用条件，不重复标题。
5. 全尺寸检查可读性，再看连续缩略图检查节奏。空疏页优先补研究解释或放大主证据；拥挤页优先去重复、简化装饰、拆分任务。
6. 仅当研究结构稳定后修饰小卡片。采用哪种边框由内容和相邻区域决定，不以数量或随机轮换来追求变化。

## 4. 落到插件中的内容

- `references/templates/` 提供 48 个内容专属参考页、8 个分类 PPTX、一个完整 PPTX、可浏览目录、结构清单和逐页输入记录。
- `academic_ppt_reference` 返回可安装位置中的具体资源与区域要求。`referenceTemplateId` 参与实际生成，不是只写在说明里的标签。
- 原生学术面板、嵌边题签、侧签与平面解释块可以组合；旧版小卡片样式保留供已认可工程的局部修改。
- 论文图片保持独立媒体。`viewport` 定义展示窗口，保留原始图片 bytes，并要求说明裁切位置与上下文。
- 原生表格保留行列内容和来源记录。数字比较要求共同口径；占位样例明确标记为合成教学数据。

## 5. 验收边界

39 页源模板的阅读证明本次设计参考有具体对象，不自动证明新模板的美感或可读性。生成后的模板页和论文示例还要实际渲染、逐页查看并修复。视觉验收的范围、字体环境与未覆盖软件写入版本验证文档。
