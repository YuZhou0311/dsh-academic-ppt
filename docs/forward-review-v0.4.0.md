## 1. 材料疲劳研究进展

任务为约 8 页、10 分钟的课题组进展汇报。输入为本轮新建协议和 48 件独立试件 CSV，持续标明**教学模拟，不是真实实验、用户研究、机构或项目成果**。没有外部论文、篇数或 IF 门槛，也未要求必须证明工艺有效。可公开的输入、计算和实际成品见 [materials-v04](../examples/materials-v04/README.md)。

A 常规、B 常规、B 改性、C 改性四组各 12 件，A/B 为 200 MPa、C 为 180 MPa；共同停止点 500000 循环，C 有两件 runout。执行者完整读取协议和 CSV，形成以下判断：

- 主要描述性比较限制在同批次同应力的 B 组，避免混合条件后直接归因于工艺。
- B 组均值差 25622.25 循环（+8.44%），中位数相对差 +2.36%；组内重抽样 100000 次、seed 20261020，均值差的探索性 95% 百分位区间为 −8274.49 至 61628.68 循环，跨零。
- 全体合并的 +41.52% 只称观察时长均值相对差，指出批次、应力与右删失混杂；不把 runout 当失效，不删除它们。
- 没有从寿命终点编造组织、断口或残余应力机制。未提供随机分配记录不等于已证实未随机。
- 下一步提出同一新批次的随机工艺分配、共同应力和停止点、预设限制平均寿命差及工程上有意义的差异，明确尚未实施。

主线程从原 CSV 独立重算组别、终点、均值和中位数，与报告一致。便携脚本保留 bootstrap 和 Welch 敏感性区间。区间只在所述采样模型下有解释，不能消除未测混杂或建立因果效应。

## 2. 理论/机器学习论文精读

任务为 8 页、10 分钟的研究生组会，仅依据 Angelopoulos 与 Bates 的 [A Gentle Introduction to Conformal Prediction and Distribution-Free Uncertainty Quantification](https://arxiv.org/abs/2107.07511)，提供 v6 的 51 页 PDF。PDF 题页日期 2022-12-08，条目修订日期 2022-12-07，在完整书目中分别注明。

执行者读取全文提取并查看原图，另请独立科学审查者核对核心推导。报告围绕：

1. 固定模型与分数后，秩论证为何给出有限样本边际保证；第 k 小分数及 k=n+1 的无穷阈值边界。
2. 边际覆盖、给定输入的条件覆盖、固定校准集后的覆盖率是不同概率对象。
3. CQR 分数与区间如何由不等式推出；阈值可以为负，区间并非总加宽。
4. i.i.d. 连续分数下校准集引起的 Beta 覆盖波动，校准量与验证量需要分开报告。
5. 天气案例的 500 点窗口是覆盖评估窗口，不能当成正文未给出数值的校准窗口 K；经验曲线不是任意漂移下的形式保证。
6. 分别检查覆盖有效性、集合实用性、群体可靠性和漂移证据；后续公平比较方案标为待验证。

Figure 2、6、10、11、15 均有看图记录，正文与比较表为原生对象。科学复核指出部分原文代码/公式易被盲抄的记法问题，执行者按正文及附录核对；没有运行作者 notebook 或声称复现数值优势。
