## 1. 材料、工具与页型

材料主题为“强化学习农业管理研究结构演示”。全部书目、作者、期刊、研究设置和数据都明确标为合成教学占位；真实论文数量为零，没有声称运行策略训练、作物仿真或田间试验。

## 6. 字形、视窗与视觉判断边界

**字形。** `missingFonts: []` 表示所检查字体可用，不能证明字体覆盖每一个字符。原始 `ₜ` 在相同字体输入下仍缺字，因此保留 `needs-fix`。正式参考记录 T08 已独立核对为 `s_t / a_t / r_t` 的可见写法；本审查没有据此擅自改写原测试输入中的符号。

**视窗。** S04的正向示例使用同一1200×1400完整PNG，B面板视窗为 `{x:0,y:0.5,w:1,h:0.5}`。实际查看确认B的轴、单位、图例和合成身份仍在；PPTX仅应用 `srcRect t=50000`，完整原媒体保留。负向探针故意采用几何合法、却移除坐标/部分图例的视窗，仍能构建。归一化几何检查不能理解科学坐标语义，必须实际看图。

**文字高度。** S04的两块短正文曾触发高度估计警告；在所看渲染中内容可见。这个局部观察不证明任意字体、字数或投影环境都能容纳同样内容。

**结果身份。** 三份PPTX均是教学fixture。人工构造的数字不证明算法有效、农业结论成立或文献已经精读。当前审查不覆盖真实论文事实、IF/全文条件、全部48页视觉效果、用户原始模板对应程度、投影可读性、用户审美认可及DeepSeek/DSH端到端输出。
