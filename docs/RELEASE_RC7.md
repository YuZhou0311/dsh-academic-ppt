# 0.10.0-rc.7 — 参考导向的内容高度与比较构图

本地候选，基于已交付rc.6源码。没有发布Release，没有调用真实DeepSeek模型。旧工程不静默迁移；rc6真实协作、逐页图片收据和预览等待保留。

## 模型可见信息修复
RC6的authoring契约虽然在结构化value中包含instructions和visualLanguages，但formatToolResult未输出这些字段。RC7在实际模型可见文本中呈现这些说明，同时呈现新开场schema和教材PNG/请求路径，且位于长正文schema之前。新增测试验证最终文本和官方Host返回的text content，不能只断言JSON中有字段。没有本轮session，不能据此断言这是最新输出所有问题的原因。

## 可执行变更
- 新的compact flow布局：按文字测量节点高度；auto在宽区横向、窄区纵向；反馈分配独立通道，不推断未知边。
- 纵向split的短文字、比较、表、flow默认自然高度；明确weight仍表示有意伸展；真实图像仍为弹性载体。
- 同一plan增加compose-opening，使用已有原生封面引擎：完整题名单处出现，题名断行必须保持原文字。
- comparison可选显式scale：保留原数值、单位、完整范围；只接受有限纯数字，越界或语义不明时报错；负值从零位置向负方向绘制。
- text可选准确短语emphasis；ISO日期作为完整排版单元；不自动改写科学内容。
- 具体构图观察：章标题占主标题、主张藏在副题、内容与分配区的空腔、重复题名。只报告风险，不打审美分，不强迫补满空间。

## 本轮输入和限制
用户最新pilot-draft.pptx的提取文字可用，但原始二进制未能在本轮容器中取得；文件工具回报的复制路径与容器实际不一致。因此没有对这份新附件声称完成真实渲染、逐页像素判断或字体检查。先前两份参考原稿与获认可的十二页样张仍可访问，已查看代表正文的真实渲染。

本轮本地回放根据新附件的文字重组方法与计数，并包含单题名开场。它不是新附件的原样重现；没有原图的页不会用旧图冒充。原稿科学结论尚未独立核验。方法页把绝对约束承诺改为待核验范围，是公开标注的编辑提案；没有增加效果数值。

## 验证解释
单元和回归检查验证几何、数据保留、字段、权限与状态，不证明审美。实际Host检查使用官方工具/图片附件，但模型适配器禁止网络、present界面为受控端点；不等于真实DeepSeek、桌面或WPS效果。安装检查使用隔离已安装依赖，不是假称全新联网安装。最终本轮测试数与日志以随交付的审计报告为准。

## 数据与版权
不将用户参考原稿、科研原图、会话、模型凭据或字体二进制打入插件。教学示例与实际研究数据分开。本轮只保留本插件已有的获许可资源及新增原创代码/文字示例。
