## 模板与生图流程

使用仓库原生参考PPTX完成了 `prepare → template解析/实际渲染 → 查看代表页 → 回填review → prepare`。该文件1页，提取32个原生形状与9个候选组件，当前解析未报告不支持对象。已审阅分支继续参考设计，没有再次提取动作。此结果不代表任意复杂母版、动画或旧`.ppt`都能完整转换。

本轮通过宿主已有的生图工具实际生成一组6款内容化卡片参考，使用作物模型与农业决策的示例主题，随后查看结果。该图用于比例、题签和分组探索，不作为研究证据，也没有替代库中的原生文字和形状。36款组件不是36张生成图片。

插件本身只返回准备计划和提示词，实际提问、上传接收、生图调用和看图由宿主执行。未在用户DSH账户内运行付费云模型对照，没有新增任意endpoint调用或密钥读取。
