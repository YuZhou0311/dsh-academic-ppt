# rc.4 正文构图入口与验证边界

## 修改依据

用户认可过同内容多种构图的十二页实验，但 DSH 后续五页样张仍把不同任务放入左图右注。此前好样张由助手逐项编排 drawings/composition；仅修改 SKILL 与增加程序审稿门槛没有证明这种设计工作能迁移到普通 Agent 执行路径。

本版主要改变制作接口，而不是再添加“认真设计”的形容词。用户 PDF 的方法页只显示流程细条，而原文件内嵌的完整图片包含完整 Step 4；多图页两种情景的图证和数字没有共享行。本轮只依据上传文件及其内嵌完整图像做版面修复，不重新核验论文事实。原稿、源图片、数字化回放工程不进入公共插件。

## 实现

新增 `academic_ppt_contract(topic:authoring)` 与现有 `academic_ppt_plan` 的 `compose-page` 动作，保留19工具。split/group/text/figure/table/flow组成内容树，模型填写研究对象、关系、主次、比例、颜色职责；代码计算正文区、共享行列、内边距、文字测量、原图等比放置和反馈布线。

正常注册工具 init 默认 content-tree；正文没有显式 composition 在构建时（包括草稿）被阻断，不能通过改回 legacy 消除要求。旧工程不迁移；底层 SDK 直接调用保持兼容。复杂公式/任意拓扑/原生 chart 仍可通过已有 drawings/composition 制作，不要求六个节点类型包办所有内容。

编译器不搜索、推断研究结果、猜裁切、填 verified/confirmed 或审美分数。溢出返回具体节点、尺寸和所需高度，拒绝缩字/裁内容；原图只引用已登记真实资产。成功保存输入与几何报告的修订文件，整页替换需要 changeNote，随后复用原有修订、撤销、产物及审稿失效机制。

模型可见摘要返回递归 schema 的被引用定义，不能只返回不可解析的 $ref；plan 输出实际节点尺寸与图像可用面积，而不仅是 saved=true。

保留 rc.3 的图片接收记录、自动展示预览、自然语言反馈、图源清单和先困难页再扩稿。新 compose-page 入口执行相同的样张扩稿检查。

## 正常工具路径回放

三个失败正文任务使用 `buildAcademicTools` 中注册的 init/record/contract/plan/build/render 执行；没有直接调用 renderProject 或修改最终 PPTX 对象。初稿与修改稿保留全部请求。实际看图修复了单位上标缺字，以及简化方法图中可能使人误以为智能体直接输出资源方案的连接；多图页改成同情景图证与读数共享行。

共享行读数表的证据绑定追踪到实际绘制的每个文本单元格；未显示、错列、重复或不存在的单元格不会被计为表格。表格自身来源必须支持定量口径，不能借用同页其他定量主张过关。

这些页面是助手选择内容树后由新工具编译，不是实际 DeepSeek 模型自主输入。输出为 draft 候选：来源仅是用户 PDF，不伪装原论文全文阅读；转述数字尚未独立复核，科学与协作条件未全部满足。保留质量报告的错误/警告，不降低门槛把它包装成正式科研交付。表格由原生形状和文本组成，不冒称 PowerPoint 表格；科学原图仍为图片，不冒称可编辑曲线。

## 测试与可复现说明

完整测试统计、Host检查、包检查以及最终文件哈希在随包审计记录中单独提供。官方 Host 脚本使用官方原生服务与真实渲染/read_image；present/ask UI端点是受控测试，不是用户桌面检查；无模型HTTP请求。依赖复用了隔离运行时，因此不是用户机器上的全新联网安装。

新增检查覆盖：内容树与尺寸、溢出与来源错误、不可变输入/修订/失败回滚、默认Agent路由、禁止降级、递归契约可见性、新入口扩稿限制。历史低层渲染夹具显式声明 legacy 来继续检查旧路径；新增默认路径另有测试，未删除旧兼容测试。

当前能力边界：flow 的快捷自动布线限单行最多5节点；table 最多12行/8列；单页现有协议最多4个不同源资产；超出范围用显式 composition 或拆页。编译器没有实际图像理解，语义裁切完整性须模型实看。不能从程序测试通过推断审美稳定达标。

没有读取模型密钥、改变模型/思考档位、覆盖用户原稿、上传用户源图到仓库、合并分支或发布Release。
