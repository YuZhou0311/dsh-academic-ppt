新增回归专门验证以下风险：

- 新建工程使用自定义设计但省略 mode 时，仍默认 `content-led`，且不会修改调用方的输入对象。
- 更新 design 省略 mode 时，保持已经选择的模式；读取缺 mode 的旧工程保持原文件字节，不自动迁移。
- `visualPlan` 进入工程和聚焦 context，不泄漏到投影文本、PPTX 备注或独立讲稿。
- 无效主面板或阅读顺序会阻止 review 构建；缺计划或需解释的重复只是提醒。
- 内容修改使旧构建和审查失效；后续构建保留已有导出文件。
- 省略 surface/align 与显式 inherit/stretch 保持既有场景；plain 仅移除面板装饰，不删除标题、证据或说明。
- align:start 与绝对卡片或机制节点坐标冲突时报告明确错误，不把绝对内容挤出一个缩短的容器。

## 独立代码复核及修正

另一执行者检查了契约、模式保存、阶段提示和几何实现，并用最小调用复验。复核发现并修正了四处问题：

1. 短面板最初只检查 `card.box`；现也检查该面板实际消费的 `node.box`，保留绝对几何并阻止带冲突的正式构建。
2. 旧固定页型的重复提醒曾建议填写该页不支持的 `visualPlan`；现改为人工确认或按证据重排，组合页才建议登记重复理由。
3. 自定义 design 省略 mode 需要继承明确默认值，而更新设计时需要保留已有模式；新工程、更新和旧工程分别验证。
4. 模板工具的“不逐页映射”指引需限定于 `content-led/reference-guided`，避免与用户选择 `template-faithful` 冲突；已用真实模板工具返回验证。

上述问题均已复验通过。代码复核不等同于最终 PPTX 画面验收。

## 实际制作试用

本次另设一项单例制作试用：独立上下文执行者只获得插件、原始教学模拟协议与 8 行 CSV，任务是完成包含封面和参考页的 7 页中文组会汇报，预算 8 分钟。参考模板可用，但没有提供指定页面构图、结论大纲或现成成稿。

数据刻意保留两个不同情境：A 站是开发/调参站点，B 站未用于调参；每站四个配对时间块，不是四个独立站点。材料明确不提供显著性检验、置信区间、因果识别或已完成的新站点试验。检查重点是模型能否正确区分证据、推断和验证方案，并按信息关系分配版面。

试用执行者未继承本次聊天和诊断；试用期间仍有兼容性修正，因此它不是冻结版本的盲测或严格 A/B 实验。

**实际结果**：完成 7 页可编辑 PPTX 与 480 秒预算的完整讲稿。工程为 `reference-guided`，5 个正文页均自行组织 composition / visualPlan，未使用 referenceTemplateId；3 个关键页保存构图取舍。具体画面包括双路径方法图、完整配对表与差值分布、均值图与旁注、证据矩阵和后续判定表。实际采用 plain / rule，不把未使用的新外观也算成模型试用覆盖。

最终 r9 的 PPTX SHA-256 为 `aad6a1ddb7ad527145fe65e6d3da571bc4077e13ced260e1e7a58f4c165736b7`。作者通过可选 LibreOffice WASM 引擎实际渲染了 7 页，提供运行字体后缺失字体列表为空；作者逐页查看并登记当前哈希的审查，最终工具检查为 0 错误、0 提醒、readyForDelivery=true。该状态仍只是插件的过程汇总。

主线程另行查看了同一 r9 的概览、全部单页和讲稿，对照原始协议与 CSV 核对：8 行输入保留；A 平均差为 −0.65、B 为 +0.15 个百分点；没有把块数当独立站点数；B3 反例保留；开发站点和外部站点角色区分；未来区间方案标明未实施，没有伪造当前显著性。未发现需修正的阻断问题。原生对象解析为 7 页、7 页备注、168 个 shape、4 个表格、1 个 chart、0 个图片对象。

制作过程中，静态检查暴露了表格与方案页拥挤，作者保留原始数据和判定分支，删除重复条带与措辞；实际全稿检查又发现“外部优势能否重复”预设了未获得的优势，作者改为先在新站点检验是否降低误差，并重新渲染复查。首次渲染还遇到环境没有 `/tmp` 的问题，通过提供真实的工作区 TMPDIR 解决；未知图像能力曾使审查登记被拒绝，作者在实际看过图片后登记真实入口并重建。没有为通过这些检查修改插件校验器。

因此不声称一次通过；8 分钟为预算，未经真人排练。实际原稿、截图、模拟输入与著述记录见[单例试用样例](../examples/content-led-v06/README.md)，整理未改变 PPTX 或预览字节，独立讲稿仅规范化末尾空行。
