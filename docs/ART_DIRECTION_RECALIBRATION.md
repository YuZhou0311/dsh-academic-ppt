# 审美校准补丁：从“通过检查”到“对照参考逐页设计”

基线：`5b39e33d9639f17a13f19d8c8d81389d8dd425d4`，`0.10.0-rc.1`。

## 修正的判断

用户提供两份蓝色科研项目汇报后，旧版六类样张不应再被视为达到其审美目标的成功案例。旧版提升了证据组织和可编辑性，但将学术表达过度收敛为素净、开放、轻量；用户需要的是强层级、紧凑分区、复杂关系图与真实图证深度整合。

这不是“更喜欢蓝色”的偏好差异，也不能通过加几个配色 preset 解决。新的主 SKILL 把证据与美术指导作为两个独立必要维度，让参考拆解、整页构图与实际精修在生成前及生成中发生。

## 本次文件

- `skills/dsh-academic-ppt/SKILL.md`：重写创作顺序；用户参考优先于风格默认；保留原有证据、协作与交付约束。
- `references/art-direction.md`：参考分析、设计系统、单页构图合约、同内容候选与审美否定后的处理。
- `references/reference-grammar.md`：两份用户参考稿的正文语法拆解及不应继承的内容问题；不附原稿和素材。
- `references/page-polish.md`：整页、证据组、微排版三级精修，含实际修订的好/坏示例。
- `scripts/inspect-pptx-reference.py`：Python标准库原生对象审计，递归处理组变换，输出几何和显式字体信息。它不是渲染器，不猜测继承的字体或缺失变换。
- `scripts/check-art-direction.mjs`：参考图/当前PPTX/渲染/逐页审查/前后修订的一致性检查，不计算审美分数。
- `test/art-direction.test.mjs`、`test/test_reference_inspect.py`：新功能专项测试。
- `evals/art-direction/README.md`：同内容、同预算、盲评与人工修订量的评测方案。

## 参考检查范围

上传A共20页，B共19页。实际查看A20页渲染概览；实际渲染并查看B的3、4、7、8、10、11、12、16、18页概览；放大检查A6、B10。原生结构详细审计各选7页。不能将“全部提取了文字”说成“全部放大精读”。

原生叶对象统计（不含母版）：A6共70个、0张图片；B7共49个、0张图片。对象数只是说明两页进行了大量原生关系组织，不是质量指标或目标配额。

## 校准样稿

本次会话另交付4页可编辑PPTX，未纳入公开补丁：

1. 同一组教学数据的结果页：强标题、共同尺度主图、原始差值表、解释边界。
2. 同一组教学数据的方法页：观测—站点配对—汇总共享行关系，替代三张独立等宽卡片。
3. 从参考B7整理三条改进路径及局限；只迁移信息组织，内容标为原稿表述。
4. 使用参考B10内嵌的两幅图重新组织图文；原图轴、单位与面板保留，定量结论标为待原文核验。

前两页仍是教学构造数据，后两页仍含未核验的原稿表述；不存在新增真实研究结果。样稿由助手通过Python编排并经LibreOffice实际渲染，不是本插件运行时或真实DSH模型端到端生成结果。没有据此声称达到了用户审美目标。

首轮到修订轮发生了实际修改：消除主题继承导致的全局阴影；扩大四字标签避免断词；重构方法页为共享结构；降低整段红字的强调强度。四页修订后重新渲染并逐页查看；结构溢出检查通过。用户审美认可仍为pending。

## 验证与边界

本轮本地新增测试：Node 18项通过，Python 9项通过；两份实际上传PPTX的选页结构审计成功；四页校准稿实际渲染并完成修订前后比较。审查旁路工具检查的是文件/记录一致性，不证明观察真实性或审美品质。

本次没有在本地运行原仓库全量回归，没有测试PowerPoint/WPS实机，也没有做真实DSH模型端到端对照；因此不使用上轮551项通过来为本轮审美背书。本补丁尚未把旁路审查接入宿主 `academic_ppt_deliver` 的运行时硬拦截；现阶段由SKILL引导执行。

这是基于现有候选版的源码/指导补丁，不是独立可安装的完整TGZ。没有修改package版本、发布Release或合并主分支。真实项目试用后仍应根据具体难页继续校准。

## 本地复现

```bash
node --test test/art-direction.test.mjs
python test/test_reference_inspect.py
python scripts/inspect-pptx-reference.py reference.pptx --out local-study --pages 3,6,10 --include-text
node scripts/check-art-direction.mjs review.json --mode candidate
```

检查脚本无新增npm依赖；结构审计需要Python3.10+标准库。图片和原稿保持在用户项目目录，不能无授权写入公共仓库或发布包。字体仅按名称引用，不分发二进制。
