# rc.5 安装与定向试作

这是完整本地候选 `dsh-academic-ppt-0.10.0-rc.5.tgz`，不是补丁、不是 npm 发布，也未同步远程仓库。不要安装旧链接代替。19个工具不变。

在实际使用的 DSH profile 中停用/更新旧插件，用新 TGZ 的真实本地路径安装、启用，完全退出并重启 DSH，再新建会话。桌面用应用内插件管理或桌面自带 CLI；服务器 Web Host 的路径必须指向服务器文件。不要用独立 npm CLI 修改桌面 profile。详细宿主安装路径见 [安装说明](INSTALL.md)。

版本为 `0.10.0-rc.5`，工具返回 `guidanceRevision:visual-craft-rc5`；`contract(authoring)` 有 visualLanguages、headingStyle、comparison、statement 和 extent:content。当前设计案例应为8项。仅复制SKILL不会注册工具。

**这次必须新建工程、复用旧材料。** 旧工程及其显式字体/chrome/system设计不自动改写，新版尊重它们；继续旧工程可能仍保留旧稀疏配置。普通Agent初始化的新工程默认内容构图和structured视觉语言，用户明确模板或legacy不被覆盖。无需更换模型或提供密钥。

## 直接试作

```text
/dsh-academic-ppt
核对插件为0.10.0-rc.5。复用已有论文、原图和笔记，新建工程，不覆盖旧报告。
按当前视觉工艺指导，只重做结果、方法、多图证据3页；参考我认可的科研正文完成度，由你自行选择配色和构图，不复用被否定的旧稀疏设计，也不复制教学内容。
保存首稿和修订稿，逐页查看实际渲染再修改。展示可编辑PPTX、PDF和PNG文件链接后结束，等我自然语言评价，不扩稿、不弹视觉确认框。
```

看实际画面：标题/题签/正文是否分级，色面是否形成主次，图注是否贴图，比较数字是否共享行，方法关系是否展开。不要仅看它是否复述新名词。新字体要有真实本地字形与字重；包里不含字体二进制。能力不足或图片工具失败时记录具体问题，不伪填已看图/用户认可。
