# dsh-academic-ppt v0.8.1

面向论文精读、文献综述、研究进展、开题与答辩的学术汇报插件。主动核对来源、取得并阅读论文图，用真实图表和研究插图组织页面，交付可编辑 PowerPoint。

发布日期：2026-10-26。插件版本 `0.8.1`，工程格式 `schemaVersion: 1`。

## 本版修复

- **将查证与取图放到制作前面。** 明确从题名/DOI、出版页或作者稿，继续取得全文、图片与图注，再建立资产并排版。只得到搜索摘要或网页文字，不等于已经下载 PDF、读过全文或看过图片。
- **以论文图与研究插图组织正文。** 先安排结果图、方法图、空间图或准确数据图，再配置解释、条件和辅助卡片。论文原图可以作为独立图片保留，可编辑交付不要求把图改成文字。
- **默认检查图源是否真正入稿。** 新学术工程使用 `source-led` 策略，记录来源核对与候选图。选中图须关联同一文献的实际资产并出现在相关正文；仅登记资产、定位缩图、装饰图和未核对图片不能抵扣原图要求。
- **补齐定性综述和定量结果检查。** 所有正文页均纳入视觉载体统计。文字卡片和关系箭头不能代替定量数据图；来源主导的定量证据页缺少实际数据载体时阻止正式构建。
- **检查文字负担与零散留白。** 报告正文原图覆盖、连续文字页、过小源图、文字负担及零散低占幅。先补回遗漏证据、重组图文和压缩空卡片，不通过装饰、拉高容器或放大文字填空。
- **保留合理的学科差异。** 不规定每页一图，也不设置所有报告相同的图片数量。核心论文确实没有适用图时，记录具体盘点依据与科学替代表达；只有数据集、报告或研究方案的稿件不强求不存在的论文原图。

36 款原生信息卡、模板上传参考、学术配色、章节导航、局部修改与恢复继续可用。卡片和可选生图参考承担辅助设计，真实论文图与实测数据具有独立来源身份。

## 安装与兼容

| 项目 | 配置 |
| --- | --- |
| DSH Host | `>=0.2.1-rc.2 <0.3.0-0` |
| Node.js | 22.x（≥ 22.19.0），或 24.0.0 及以上 |
| DSH 端 | 官方 Desktop / Web 共用安装包 |
| 注册内容 | 1 个学术汇报技能、16 个工具 |
| 安装包 | `dsh-academic-ppt-0.8.1.tgz` |

从本发布页下载安装包，按[安装与升级说明](https://github.com/YuZhou0311/dsh-academic-ppt/blob/v0.8.1/docs/INSTALL.md)更新正在使用的 profile，然后开启新会话并重新加载技能。桌面端使用应用内插件管理或桌面自带命令；网页端安装到实际运行 Web Host 的环境。

新工程自动启用来源主导流程。已有工程继续可读，缺少新策略的旧工程会提示补充来源与选图记录；继续制作图文报告时由 Agent 按当前任务补齐，不能通过删除或降低策略绕过缺图检查。

五个文件由同一标签对应的提交生成。源码打包采用明确的公开目录清单，工作区临时内容与未跟踪文件不进入发布资产。本项目未发布到公共 npm registry。

## 验证范围

回归覆盖来源主导流程的正式构建阻断与草稿保留、图号/来源绑定、选图实际使用、非论文来源、旧工程兼容，以及原生导出、局部修改和发布打包。DSH `0.2.1-rc.2` / `0.2.1-rc.3` 的真实 Host 集成继续由 CI 执行，详见[兼容记录](https://github.com/YuZhou0311/dsh-academic-ppt/blob/v0.8.1/docs/DSH_COMPATIBILITY.md)。

检索、下载、PDF处理、看图与可选生图由当前 DSH 宿主的实际能力执行。插件检查可审查记录和实际导出对象，不把 `verified` 字段当作联网验真的证明；缺少权限、全文或看图能力时须保留具体缺口。最终科学解释、实际图像可读性和模型端到端表现仍须复核。
