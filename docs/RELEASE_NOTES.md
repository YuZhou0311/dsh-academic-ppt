# v0.2.0 · 按研究内容选版的学术参考库

上一版默认页面过于空疏，卡片和配色偏向展示设计，无法充分表达论文方法与实验证据。本版实际重新读取两份用户学术模板，共 39 页，据其紧凑图文、细边框题签和研究任务组织方式改良插件。

## 具体改变

- 增加 **48 个可编辑学术参考页**，8 类各 6 页，同时提供全集 PPTX、8 个分类 PPTX、HTML 画廊、结构索引与逐页输入记录。
- 新增 `academic_ppt_reference` 工具。模型按研究任务逐步选型，`referenceTemplateId` 直接决定生成版式；缺失所选页型要求的证据会明确报告。
- 重做白底、近黑正文与深蓝结构的默认设计。增加细框淡蓝表头、嵌边短题签、侧边标签，与开放解释区配合使用；保留旧卡片样式支持既有工程的局部修改。
- 添加原生表格及其来源检查，允许严格同维度对照。表格页为参考库的一部分，图、流程和方法关系仍按内容选用。
- 添加论文图的原生局部展示窗口。PPTX 保留完整原始媒体，展示范围有独立记录，支持全图定位与面板放大。
- 将真实论文示例扩展为 14 页，详细解释实验单位、工具执行、原图证据、两套独立评价和失败边界；逐页讲稿同步生成。
- 把用户反馈落实为密度双向审查：信息不足时补必要研究解释或合并薄页；拥挤时去重复或拆任务，不为填模板堆数字。

模板资源中的教学数据清楚标记为合成示例。真实论文示例使用原文与明确来源；用户完整源模板及其原有研究内容不重新分发。

## 更新后如何使用

在新会话中加载学术技能，先按内容查看一类模板：

```json
{"category":"figure"}
```

再读取一页的要求与可编辑参考：

```json
{"templateId":"figure-detail-window"}
```

将结果中的 `referenceTemplateId` 与 `layout` 写入页面，使用真实证据填入相应角色。不要把示例数字作为论文发现。只改小卡片时保留已认可页型和原图，继续使用按 ID 限制的 `card-style` 操作。

## 安装

下载本版安装包，或克隆固定标签：

```sh
git clone --branch v0.2.0 https://github.com/YuZhou0311/dsh-academic-ppt.git
cd dsh-academic-ppt
npm ci --ignore-scripts
```

将完整插件路径安装到已初始化的 DSH profile：

```sh
dsh plugin --profile desktop add "file:/absolute/path/to/dsh-academic-ppt"
```

安装或更新后重启 DSH。源码的锁文件和 overrides 只约束本源码根目录，目标 profile 的实际依赖由其宿主管理。详见 [安装说明](INSTALL.md)。

## 兼容性与验证范围

工具数从 10 增至 11；项目记录增加可选字段，原有 ID、旧卡片样式、修订和撤销机制继续保留。旧成品不会被覆盖。渲染器版本更新后，需重新构建并查看实际 PPTX，旧版本的视觉审查不能自动继承。

具体确定性测试、实际 PPTX 渲染、字体与逐页观察记录见 [VALIDATION.md](VALIDATION.md)。论文记录门槛不自动证明科学结论；本版也不宣称已经完成真实 DeepSeek 端到端效果实验或 PowerPoint/WPS GUI 全平台验证。
