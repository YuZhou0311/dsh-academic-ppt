# v0.6.0 · 自主构图、可编辑卡片层次与空间检查

本版针对实际农业遥感报告中解释区裸文字、正文大空洞和页面同质化的问题，连同提示词、工具契约、原生渲染与交付检查一起改造。设计仍由当前宿主模型完成；插件提供可组合能力和可解释约束，不承诺自动获得原创性或通用审美分。

## 设计与渲染

- 新工程默认 `content-led`、`density:compact` 与可见卡片轮廓。`card.appearance` / `design.cardDefaults` 支持轮廓、浅底、实色、开放表面，以及圆角、内边距、强调边和轻阴影。卡片文字、边框与图标均为可编辑原生对象。
- 十种语义图标由线条、矩形、椭圆构造，避免 emoji 缺字；图标帮助辨认问题、方法、证据与限制，不构成科学证据。
- `cover.variant:custom` 允许作者独立安排标题、副题、场合、身份和媒体区域，改变比例、主次与位置。完整题名、缺失区域、相撞、越界和高度不足接受检查。`split/editorial` 仍是可选起点，不是强制模板。
- `design.chrome / slide.chrome` 可逐页改变或删除重复标题线、角标、品牌、章节、页码和页脚；删除元素会回收正文区域。来源记录和备注不随可见页脚隐藏而删除。
- 结尾可用 `closing` 的 statement/evidence 结构，也可直接用 composition 组织核心判断、证据支点与讨论问题。
- 卡片的最小尺寸测量与实际绘制共用实现，完整指标、单位、图标与内边距参与测量；放不下时明确报错，不静默裁字或缩小字号。
- 独立作者的真实小样暴露并修复封面语境图忽略裁切的问题；封面与结尾均按 `asset.viewport` 保留可见比例，经过裁切 XML 和实际 PPTX 双重验证。
- 自由图框的边界检查跟随删除页眉后实际回收的正文区域，避免旧的固定 y 坐标误拒绝合法大图；越过标题、底部和侧边仍会被阻断。

## 空间与全稿检查

- `check` 和导出的 `quality.json` 新增 `designDiagnostics`：逐页记录实际内容区域、内容覆盖估计与最大连续空区的坐标/比例。
- compact 正文与结尾的最大单块连续空区达到正文区域四分之一、封面达到可视区域一半时，阻止 review 构建。章节过渡页与参考页使用不同规则；参考页只提醒合并。阈值属于工程规则，不能代替真实渲染判断。
- 背景、卡框、图标和正文装饰不计为科学内容，放大空框不能消除错误。论文原图、科学图、数据表内部留白不会被误作待填空洞。
- 检查连续页和全稿非相邻页面的近似同构。颜色、边框、微小权重差和空卡不算结构创新；有意义的共同尺度对照允许保持一致。
- 主技能重写为内容与素材共同构图、可见语义分组、少量代表页验证、逐页审稿和全稿节奏复核，清除旧指令中对卡片和留白的相互抵消。

## 兼容与使用边界

包版本 `0.6.0`，渲染器版本 `7`，schemaVersion 仍为 `1`。旧序列化项目没有新增字段时保留原设计路径；旧导出与视觉审查需重新构建和复审。design 更新省略 mode/density/cardDefaults/chrome 时保留已有设置，不能以 compact 降级消除空间错误。

默认离线 demo 现使用新上下文制作者完成的 [materials-v06](../examples/materials-v06/README.md)：保留其 compact 设计、可见卡片与完整分析记录。公开记录重建后的 9 张实际 PNG 和逐页讲稿与作者成稿逐字节一致；重建不是新增模型试用，新的 PPTX 不继承旧视觉审查。可用 `--example materials-v05` 选择历史示例，其开放内层卡片与 balanced 设置仅用于兼容核对，不作为新版自主设计验收。没有升级依赖，也没有新增收费模型调用。

设计依据见[内容驱动设计](CONTENT_LED_DESIGN.md)与[参考机制取舍](DESIGN_REFERENCES.md)，软件测试和独立制稿范围见[本版验证记录](VALIDATION_V06.md)。下面保留 v0.5 历史发布说明。

本轮两个新上下文任务均完成实际渲染与独立逐页复核：材料教学模拟 9 页/555 秒、农业遥感同化 14 页/795 秒。前者公开可编辑成品及重建输入；后者使用四篇原论文，公开[逐页审稿与边界](AGRI_REVIEW_V06.md)。材料保留 2 项提醒，农业保留 7 项提醒；不称作零警告、一次成功或目标 DeepSeek 模型的稳定效果评测。

# v0.5.0 · 正式模板设计与内容驱动的学术构图

用户反馈 v0.4 的视觉结果与两份理想模板仍有明显差距。这一版继续重做模板如何影响最终PPTX，以及模型如何将证据、机制和判断组织成正式汇报。根因与实现见 [AUDIT_V05.md](AUDIT_V05.md)。

## 主要改变

- template 返回可直接写入 design 的 suggestedDesign：模板中的页眉、封面、字体比例、色带与分区经结构推断进入实际渲染。推断附来源页与适配说明，执行者看图后审定，不依赖文件名或学科特例。
- 新增 framed / project 封面与正式章节体系。完整题名可语义换行，真实场合、署名、机构与日期分层；旧模板的研究内容和机构标志不移植。
- 新增 academic 组合页，用加权行与证据面板组织图、表、机制、原生统计图和紧邻解释。条件、主证据、分析与结论有明确关系；每个载体恰好使用一次。
- 新增可编辑的独立观测分布图与显式区间图，支持同页多图。独立样本不连线；图形输入保留来源与单位，置信区间由有记录的计算提供。
- diagram.rows 安排阶段，edges 明确步骤、分支、汇合、反馈和无向关联。独立映射保持可辨认的连线；密度和穿节点问题明确报告。
- 面板按真实文字、图注、表格、图形与行标签测量空间。支持表格列宽比例与行高亮；不自动缩小字号、不隐藏未消费内容。
- 模板可一次研究并实际渲染，成品和模板均返回编号概览。CLI 新增单命令 --help / --schema，contract 明确只查询七类记录。
- record 新增 slideOrder，支持小样完成后在同一事务中补页并重排；顺序必须包含全部页面恰好一次，旧构建与审查不被当作新页序的验收。
- SKILL 和参考改为先确定研究关系、实际学习并应用主模板、完成难页小样、检查当前PPTX和模板差距。旧48页参考库保留作补充。
- 根据独立试用修复流程图标签遮挡与原生图表类别静默省略；标签空间由组合与绘制共同测量，原生类别轴保留完整标签。可选valueDecimals只控制显示，内嵌工作簿保留原值。
- 将关键原生数学字符和密集表格纳入难页小样；明确图像输入能力的合法登记契约。研究方案增加结果分支与反例检查，避免把反向证据和信息不足混为一谈。

- 发布审查补齐两处既有门槛：嵌入资产保留解析来源，重渲染后旧PPTX画面审查失效；CLI帮助与条件性必填字段一致。

# v0.4.0 · 研究论证、模板学习与正式交付

本版根据一次真实 DSH 失败会话、19 页产物和两份共 39 页参考模板重做流程；问题与改动证据见 [AUDIT_V04.md](AUDIT_V04.md)。

## 主要改变

- 新学术工程增加来源 analysis、claim reasoning、推断/方案 dependsOn 与正文 argument。覆盖理论、定性、实验、数据集和项目材料，取消默认固定篇数与强制逐篇导读。
- SKILL 按任务定问题、读证据、形成推导、学习设计语法、先验难页、完整渲染的顺序执行；分别说明综述、精读、进展、开题、答辩。没有为特定农业论文写固定答案。
- 模板工具返回内容隔离的 study；参考工具默认只提供中性布局与空骨架。有题签的参考页需要当前研究的 panelTitles，长段教学原文与模板示例图不能充当研究证据。
- 独立 formal/minimal 封面，45 pt 原生大标题与真实身份；正文默认平面表达。全局参考编号保持跨页一致，正文页脚不再塞完整 DOI 与内部来源 ID。
- 改进混合字符宽度估计、长标题顺排与短表位置；已知文字/指标/表格溢出和语义区域碰撞在导出前阻断 review，不靠截字或自动缩小字体消除错误。
- 修复 slide-content 已保存后返回 undefined 导致 DSH lossless JSON 失败的问题；统一严格 JSON 返回值，给误传工程目录提供准确提示。可用 removeFields 明确删除可选布局字段。
- 新增 academic_ppt_contract，record 使用工作区 recordsPath 批次。12 个工具注册定义 12,860 字节，较 v0.3 的 42,293 字节减少 69.6%；完整执行校验保持。
- 已登记的全文、篇数、IF 与逐篇导读要求不能静默降低；最终验收逐页记录 observations，未解决 issue 不能 passed，旧版本画面不能充作新版本审查。
- 独立审查修复多级推导的间接来源漏检，以及非连续 XML 部件下模板组件来源页码不一致；默认 demo 改为有可复算输入的 v0.4 材料教学示例，保留历史成品的版本身份。

## 兼容与升级

包版本为 0.4.0，渲染器版本为 4，工程 schemaVersion 保持 1。旧记录可读取、修改和构建，但只有补充真实学术记录并完成当前版本渲染/审查才可能达到新交付条件。CLI/core 内联 record 保留；DSH 注册入口改为 recordsPath。详见 [INSTALL.md](INSTALL.md)。

## 验证与边界

完整确定性回归、实际渲染、独立理论论文精读与材料研究试用结果见 [VALIDATION_V04.md](VALIDATION_V04.md)。不能将字段完整、模板密度或程序测试通过当成研究正确、审美优秀或真实 DeepSeek 稳定成功的证明。本轮未在用户的 DeepSeek 账户中运行付费对照，69.6% 是工具定义字节变化，不是人民币节省比例。

# v0.3.0 · 图片适配与学术视觉层级（历史）

这轮更新针对实际示例中六类问题：密集竖图不可读、文字缺少层级、小字碎片、卡片关系不清、图文松散，以及模型审美指导过于抽象。完整方法见 [VISUAL_DESIGN_V03.md](VISUAL_DESIGN_V03.md)。

## 已实现

- 新增图片阅读记录、关键标签投影估算、实际槽位建议和最多三个候选。完整长图不再默认作为一栏主证据；不会自动猜测科学裁切范围。
- `figureBoxes` 支持为不适合现成页型的证据配置明确比例；图框与卡片边界、对应数量和重叠继续检查。
- 40/26/24 场景 px 的默认标题、区域标题与正文层级，`card.emphasis` 生成可编辑富文本；方法/设置/结果/边界/假说有明确颜色身份与不同关系形式。
- `displayCaption` 简化上页出处，完整 provenance 进入备注；`displayLegend` 转录作者图例为原生色线和 22 px 标签，原图媒体与数据颜色不变。
- 图片细框贴合真实图像，浅阴影只用于有分组价值的对象；短表后的相关解释跟随实际内容高度，指标总块增加越界预警。
- 更新 48 页、8 类参考全集及分类包、实际 PPTX 预览、画廊和逐页记录。T28 改为独立的主/补证据面板，T29 用密集竖图中的一个独立面板；教学数据明确标为合成。
- 重做 14 页真实论文示例：作者独立 PLA 曲线、Summary 统计分组、相关系数段落分别采用合适图文比例，保持论文题名、数字、评价分母与 670 秒讲稿。
- 新增图片选择与视觉决策参考，强化 DeepSeek 的候选比较、难例先行、局部修订和真实画面检查。模型能力按当前宿主核对，不以名称推断视觉输入。

## 使用与兼容性

下载本版 `.tgz` 安装包，或按 [安装说明](INSTALL.md) 克隆固定 `v0.3.0` 标签；尚未发布 npm。仍为 11 个独立的 `academic_ppt_*` 工具，与原 dsh-ppt 共存。

项目新增可选字段，已认可版本的小卡片仍按原范围修改。渲染器修订为 3，旧 PPTX 不覆盖，旧版的视觉审查不自动继承。升级后重新构建和检查实际成品。

## 验证与限制

当时完整测试、48 页参考包、14 页科学示例和独立 CLI 制作演练见 [VALIDATION_V03.md](VALIDATION_V03.md)。工程检查不会证明科研事实或审美；本版未完成真实 DeepSeek/DSH GUI 的端到端效果实验，也未完成 PowerPoint/WPS 全平台编辑测试。

# v0.2.0 · 按研究内容选版的学术参考库

上一版默认页面过于空疏，卡片和配色偏向展示设计，无法充分表达论文方法与实验证据。本版实际重新读取两份用户学术模板，共 39 页，据其紧凑图文、细边框题签和研究任务组织方式改良插件。

## 具体改变

- 增加 **48 个可编辑学术参考页**，8 类各 6 页，同时提供全集 PPTX、8 个分类 PPTX、HTML 画廊、结构索引与逐页输入记录。
- 新增 `academic_ppt_reference` 工具。模型按研究任务逐步选型，`referenceTemplateId` 直接决定生成版式；缺失所选页型要求的证据会明确报告。
- 重做白底、近黑正文与深蓝结构的默认设计。增加细框淡蓝表头、嵌边短题签、侧边标签，与开放解释区配合使用；保留旧卡片样式支持既有工程的局部修改。
- 添加原生表格及其来源检查，允许严格同维度对照。表格页为参考库的一部分，图、流程和方法关系仍按内容选用。
- 添加论文图的原生局部展示窗口。PPTX 保留完整原始媒体，展示范围有独立记录，支持全图定位与面板放大。
- 将真实论文示例扩展为 14 页，详细解释实验单位、工具执行、原图证据、两套独立评价和失败边界；逐页讲稿同步生成。
- 把用户反馈落实为密度双向审查：信息不足时补必要研究解释或合并薄页；拥挤时去重复或拆任务，不为填模板堆数字。

模板资源中的教学数据清楚标记为合成示例。真实论文示例使用原文与明确来源；用户完整源模板及其原有研究内容不重新分发。

## 更新后如何使用

在新会话中加载学术技能，先按内容查看一类模板：

```json
{"category":"figure"}
```

再读取一页的要求与可编辑参考：

```json
{"templateId":"figure-detail-window"}
```

将结果中的 `referenceTemplateId` 与 `layout` 写入页面，使用真实证据填入相应角色。不要把示例数字作为论文发现。只改小卡片时保留已认可页型和原图，继续使用按 ID 限制的 `card-style` 操作。

## 安装

下载本版安装包，或克隆固定标签：

```sh
git clone --branch v0.2.0 https://github.com/YuZhou0311/dsh-academic-ppt.git
cd dsh-academic-ppt
npm ci --ignore-scripts
```

将完整插件路径安装到已初始化的 DSH profile：

```sh
dsh plugin --profile desktop add "file:/absolute/path/to/dsh-academic-ppt"
```

安装或更新后重启 DSH。源码的锁文件和 overrides 只约束本源码根目录，目标 profile 的实际依赖由其宿主管理。详见 [安装说明](INSTALL.md)。

## 兼容性与验证范围

工具数从 10 增至 11；项目记录增加可选字段，原有 ID、旧卡片样式、修订和撤销机制继续保留。旧成品不会被覆盖。渲染器版本更新后，需重新构建并查看实际 PPTX，旧版本的视觉审查不能自动继承。

具体确定性测试、实际 PPTX 渲染、字体与逐页观察记录见 [VALIDATION.md](VALIDATION.md)。论文记录门槛不自动证明科学结论；本版也不宣称已经完成真实 DeepSeek 端到端效果实验或 PowerPoint/WPS GUI 全平台验证。
