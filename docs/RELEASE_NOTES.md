# dsh-academic-ppt v0.8.0

面向论文精读、文献综述、研究进展、开题与答辩的学术汇报插件。使用研究问题与证据组织叙事，按每页的信息关系设计标题、分栏、图表与卡片，交付可编辑的 PowerPoint 文件。

发布日期：2026-10-26。插件版本 `0.8.0`，渲染器版本 `14`，工程格式 `schemaVersion: 1`。

## 本版能力

- **完整学术叙事。** 贯穿问题、目录、分节、正文定位与结尾回应共同组织全稿；逐页记录论点、证据、解释条件和阅读顺序。
- **36 款可编辑信息卡。** 覆盖问题、方法、证据、指标、边界和进展六类用途，提供实际渲染的 SVG 预览与可查询内容契约。卡片与开放文字、原生表格、图表和关系线组合，支持按内容调整比例、尺寸、分区和颜色。
- **模板参考与自主设计。** 开始制作时询问一次是否上传模板 PPTX；有模板时提取设计语言并查看代表页面，无模板时继续内容驱动流程。学术配色可自主调整，只有用户明确指定时固定颜色；参考不作为整页照搬的指令。
- **内容化生图参考。** 宿主有可调用的生图工具时，先依据真实汇报内容准备分批提示词，由宿主调用、看图后重建为可编辑对象。无接口、调用失败或用户拒绝时回到原生卡片库。
- **可恢复与可检查的工程。** 保存来源、学术记录、逐页设计、讲稿与修订，支持限定范围的局部修改、撤销、真实 PPTX 渲染及逐页审查。
- **桌面端与网页端共用插件包。** 对齐官方 DSH 的 Host 插件接口，使用 `engines.dsh` 声明兼容范围；两端分别安装到实际运行的 profile。

## DSH 兼容与安装

| 项目 | v0.8.0 配置 |
| --- | --- |
| DSH Host | `>=0.2.1-rc.2 <0.3.0-0` |
| Node.js | 22.x（≥ 22.19.0），或 24.0.0 及以上 |
| 注册内容 | 1 个学术汇报技能、16 个 `academic_ppt_*` 工具 |
| 安装方式 | GitHub Release 的本地 `.tgz` 包，或源码目录 |
| 模型与生图 | 复用当前 DSH 宿主提供的能力，无须给本插件另存模型密钥 |

从本发布页下载 `dsh-academic-ppt-0.8.0.tgz`，按[桌面端与网页端安装说明](https://github.com/YuZhou0311/dsh-academic-ppt/blob/v0.8.0/docs/INSTALL.md)完成安装或更新，然后在新会话中加载 `dsh-academic-ppt` 技能。宿主版本、官方依据和实际验证范围见 [DSH 兼容说明](https://github.com/YuZhou0311/dsh-academic-ppt/blob/v0.8.0/docs/DSH_COMPATIBILITY.md)。本项目未发布到公共 npm registry。

## 验证与维护

发布流程执行完整测试、包结构与本地文档链接检查，再从标签对应提交生成五个发布文件。安装包与源码归档均记录摘要，发布清单绑定具体提交。工具注册和运行时调用的实测记录见 [DSH 兼容说明](https://github.com/YuZhou0311/dsh-academic-ppt/blob/v0.8.0/docs/DSH_COMPATIBILITY.md)；桌面窗口、浏览器 UI、模型端到端表现和 PowerPoint/WPS 的实际显示需分别验证。

维护者可在干净的 Git 源码检出中运行：

```sh
npm ci --ignore-scripts
npm test
npm run check
npm run release:build -- --tag v0.8.0
```

输出位于 `dist/v0.8.0/`。打包脚本要求 `package.json`、锁文件与标签版本一致，并拒绝未提交的受跟踪文件改动。源码 ZIP 可用于安装依赖与运行测试；重新生成绑定提交的发布包需要 Git 检出。

已有工程可以继续读取和修改。更新插件后，对需要交付的工程重新构建、实际渲染并复核当前成品。
