# dsh-academic-ppt v0.8.2

面向论文精读、文献综述、研究进展、组会、开题与答辩的 DSH 学术汇报插件。与你逐步确定汇报方向，主动核对来源、取得并阅读论文图，再将证据、解释与条件组织为可编辑 PowerPoint。

插件版本 `0.8.2`，工程格式 `schemaVersion: 1`。

## 设计协作

新建整稿按阶段讨论 **信息密度、故事线、配色、形态、语言、层次质感和封面**。每轮通常只问 1–3 个相关问题，提供有理由的推荐与 2–3 个选项；封面和代表正文通过实际候选确认。

用户已经表达的偏好继续沿用，明确委托的部分自主完成。待回答的建议不会自动变成“已确认”；研究、取图和暂定候选可继续，批量定稿依据真实选择或明确委托。局部改稿保留已有方向。

## 48 款卡片，包含 12 种图片嵌入式结构

图卡支持完整图与解释、同尺度并图、上下图列、三阶段图序、2×2 证据窗、总览与局部、图旁短注、读数和条件边界等关系。实际论文图通过已登记资产嵌入，图题、解释、读数和边界使用可编辑对象。

图片保持原比例，卡片不自动裁掉坐标或图例。总览与放大采用分别核对的资产；没有真实局部图时不能用重复图片伪装新证据。图卡与开放大图、跨栏比较、方法流程和表格按研究任务组合，不要求整稿卡片化，也不设置样式数量配额。

随包提供可筛选的 48 卡图册、单款 SVG 预览和 12 页图卡参考 PPTX；图册中的图片为原创结构示意，不含研究数据。README 另展示实际验收稿的封面与双图卡，后者按 CC BY 4.0 使用并注明论文来源及裁切。

## 参考学习落实到页面

Agent 需要查询目录、实际查看相关预览，并记录观察、选型以及针对当前内容的改造。用户模板用于学习层级、图文比例与分组方式；普通参考模式允许重新设计配色和结构。明确要求沿用模板时才进入忠实模板模式。

有可用生图工具时，按照已经讨论的方向优先生成内容相关的卡片设计参考，查看后用原生对象重建。没有模板或生图接口时，继续内置参考与内容驱动流程；设计参考不替代论文图和精确数据。

## 文字与整稿构图

- **科研内容的断行保护。** 对数值、百分比、单位、范围和上下标标识保留完整词组，无法放下时要求调整宽度或重排；不静默丢字或缩小字号。汉字短末行和不合适的标点换行进入提示，作者再结合实际画面修改。
- **先精简重复，再提高可读性。** 删除标题、卡片和页末判断的同义复述，保留样本、单位、基线与边界，再根据观看场景确定正文和标签字级。正文共同字号可在支持范围内提高到 40 px，实际阅读要求与字号分别检查。
- **构图同质化诊断。** 依据实际导出对象的相对位置，提示连续或占比过高的“左图右解释”等大骨架。预设名称、颜色和细微坐标变化不会直接被当作新的阅读关系。同尺度对照和忠实模板可以合理重复。

这些检查提供可审阅的排版信号，不能独立评价学术解释、原创性或审美。最终仍需查看当前 PPTX 的每一页及相邻段落。

## 研究与交付流程

查证来源、阅读全文、获取并阅读原图、建立问题路线、逐页设计、学习参考、比较真实候选、原生构建和实际渲染继续作为同一工作流执行。

新学术工程保留来源主导策略，追踪选定原图是否真正进入正文。原始论文图可作为独立图片使用，受支持的数据图、表格和科学关系保持原生可编辑；图标、文字卡和生成设计图不替代研究证据。

已有工程保持 `schemaVersion: 1`。缺少新协商字段的旧工程会得到提示，整稿重新设计时按当前任务补充真实记录；局部修改不要求虚构历史对话。交付包含可编辑 PPTX、讲稿、证据清单与可恢复工程；最终渲染需要可选引擎及实际使用的字体。
