# 农业模型组会：4 页、8 分钟故事板与困难页设计

## 1. 本次范围与结论边界

- **交付阶段：** 逐页故事板和结果页的可执行设计说明。暂不制作 PPTX，不生成实际样张，不对外写入。
- **场景：** 中文农业模型组会，现场短讲，共 4 页、480 秒；第 1 页直接进入研究问题，不单设封面、目录、分节页或致谢页。
- **材料身份：** 本轮任务提供的软件演练教学材料，**非真实实验**。所有页面均显示这一身份。
- **来源范围：** 只使用本轮教学材料；设计依据为指定的 `skills/dsh-academic-ppt/SKILL.md` 及按需参考。未读取项目 docs、其他 Agent 的工作或已有测试输出；未添加论文、作者、机构、地点名称、年份名称或参考文献。
- **设计决定：** 已获明确委托，采用原创设计，自主确定故事线、配色、构图并审查本次计划，无须再次询问。
- **完成范围：** 科学内容、数值、论证与设计规格的计划审查。尚未完成 PPTX 渲染、字体替换检查、投影可读性实测或真人排练，不将这些项目写成“已通过”。

### 中心问题与可支持的回答

**中心问题：方法 A 能否在新站点保持产量预测优势？**

**本材料的回答：** 随机划分中 A 的 RMSE 低于 B；在所给的三个整站留出结果中，A 的 RMSE 均高于 B。因此，**本次三个整站留出未保留 A 的优势**，材料不支持“A 已在新站点保持优势”。这个方向明确的观察不能弱化为“优势略有波动”，也不能外推为“A 在所有新站点都更差”。

A 的方法价值应落在可以核查的层面：它把过程约束接入气象、土壤到产量的预测链，构成一个可检验的方法思路；本材料还提供了随机划分下较低的 RMSE 观察。过程约束本身造成了多少收益、为何在整站留出中未获优势，均未得到因果或消融证据支持。

### 故事线

先辨认“120 条地块记录”和“新站点检验”回答的问题不同，再交代 A 相对 B 的已知方法差异，随后在同一结果页完整呈现有利与不利读数，最后给出受限结论及明确标为未实施的后续检验。

听众离场时应能区分三件事：**方法思路是什么；本次各评价条件下观察到什么；哪些推广与归因仍未得到支持。**

## 3. 全稿风格与阅读规则

### 风格选择

采用 **research-seminar** 方向，密度为 **balanced**。本稿的核心是同一方法在不同评价条件下的证据判断，适合开放图表、直接注释和轻量条件表。农业题材本身并不要求地图或田间照片；材料未给地点坐标与实拍，故视觉重点放在方法关系和精确读数。

- **画幅：** 16:9，规划尺寸 13.333 × 7.5 英寸；左右正文边距约 0.55 英寸，上沿与底部保留独立导航／来源带。
- **字体职责：** 拟用思源黑体／Noto Sans CJK SC；标题加粗，正文常规，数值采用清晰的等宽数字效果。这里只规定角色，不声称已核实环境字体或渲染效果。
- **字级：** 标题 32–34 pt；正文及主要标签 24 pt；图表标题、表头和数字 22 pt；必要条件 18–20 pt；仅出处可用 14–16 pt。会改变结论的限制不能塞入出处小字。
- **底色：** 暖白 `#FAFAF7`；主文字 `#22313B`；辅助文字 `#45545E`；细规则线 `#CBD2D3`。
- **A 的颜色：** 深青绿 `#126B68`，表示研究对象 A；不表示“获胜”。
- **B 的颜色：** 石板灰 `#66717A`，表示对照 B。
- **差值图：** 深色实心菱形 `#22313B`，只表示 ΔRMSE；以正负号和零线表意，不用红绿编码胜负。
- **导航：** 上沿小型“01 / 04”等页码与本页任务标签；右上固定“教学材料｜非真实实验”。无作者、机构、Logo。
- **表格：** 轻横线、无竖线；测试条件改变处用一条清楚的横向分界。数值按小数位对齐。
- **容器：** 主要内容开放排布，不套统一卡片，不用阴影、装饰插画或虚构网络图。
- **有意留白：** 方法图两条路径之间留空以辨认对照；结果页图表之间的空隙用于分清差值和绝对值；不填入无证据支撑的图标或大数字。

### 为什么选择“差值图＋原始表”

结果页需要看清两个任务：判断 A/B 的方向，以及核对所有原始 RMSE。差值图将四行的比较统一到零线，0.02 t/ha 的差异也不依赖两个相邻标记的微小间隔；右侧原始表保留完整数值，避免听众只看到加工后的指标。

绝对 RMSE 配对点图也可保留信息，但在从零开始的共同尺度上，0.88 与 0.90 的标记容易靠近。此次自主选用差值图作为主体、原始表作为核对入口。此为设计推演，未冒充已经渲染并比较过的视觉样张。

### 第 2 页｜A 将过程约束接入气象、土壤到产量的预测链

**角色：** mechanism；**关系：** 共享输入后的平行方法路径；**layoutFamily：** custom。

**听众问题：** A 的方法思路是什么？它和 B 的已知差别有哪些？哪些机制细节目前不能解释？

**本页任务与证据：** 用 C03 画出摘要所支持的信息流，以 I03 说明可以陈述的方法价值，不添加网络层、方程、约束项名称或训练细节。

**完整可见正文与流程标签：**

- 顶部身份：**教学材料｜非真实实验**
- 左侧共同输入：**气象数据＋土壤数据**
- 上方 A 路径：**方法 A：加入过程约束 → 产量预测**
- 下方 B 路径：**方法 B：无过程约束 → 产量预测**
- 两条路径下的共同条件：**输入相同；训练预算相同。**
- 邻近解释：**A 的可陈述方法价值：把过程约束纳入产量预测，形成可检验的方法思路。**
- 方法范围：**仅有方法摘要；过程约束具体形式、网络层数、超参数和额外消融未提供。**
- 图注：**依据摘要整理的流程示意；箭头表示信息流。**
- 来源：本轮任务教学材料，方法摘要。

**必须可见的条件：** 同输入、同训练预算；A 有约束、B 无约束；仅掌握摘要；没有消融证据。方法的“过程约束”不等于已经证实了生理真实性、可解释性或迁移收益。

**推理与边界：** 相同输入和训练预算是已知控制条件，但不足以断言 A 与 B 除约束外的全部实现完全相同。因此，A/B 差异不能自动解释为过程约束的因果效应。

**构图：** 共同输入放左，分出上下两条水平路径；A 使用青绿标签，B 使用灰色标签。每条路径只有一个方法摘要节点和产量输出，不画装饰性神经网络。共同条件横跨两条路径，方法信息缺项放在图下，字号 20–22 pt。保留路径间空白以识别平行对照。

**简要讲稿：**

> A 和 B 的输入都是气象与土壤数据，训练预算也相同。材料明确给出的区别是 A 在预测过程中加入过程约束，B 没有这项约束。所以 A 的方法价值可以具体描述为：尝试把过程约束纳入产量预测，而不是只给出一个模型名称。这里的图仅表达这条信息流。我们没有约束方程、网络层数、超参数，也没有同一实现下的去约束消融，因此不能把性能差异全部归因于约束，更不能提前宣布它提升了可解释性或跨站点能力。下一页就检查：这一方法思路在两个评价条件下分别得到了什么读数。

**承接：** “过程约束是方法动机；是否保持预测优势，需要由接下来的逐项比较回答。”

### 第 3 页｜随机划分中 A 的 RMSE 较低；三个整站留出中 A 均较高

**角色：** evidence；**关系：** 分组的同条件配对比较，差值图与原始值表横向对齐；**layoutFamily：** custom。**本页为最难页。**

**听众问题：** A 的优势在整站留出后是否仍存在？结论依据是哪些读数，强度到哪里为止？

**本页证据：** C01、C02、C04、C05、C06、I01、I02。全部八个原始 RMSE 必须上页；四个差值为确定性减法。

**完整可见内容：**

- 标题建议语义换行：
  - **随机划分中 A 的 RMSE 较低；**
  - **三个整站留出中 A 均较高**
- 顶部身份：**教学材料｜非真实实验**
- 共同条件：**A 与 B：输入、训练预算相同；RMSE 越低越好。**
- 主图题签：**差值：ΔRMSE = A − B（t/ha）**
- 主图方向：**左侧：A 误差较低；右侧：A 误差较高。**
- 四行标签：**随机划分／留出站点 1／留出站点 2／留出站点 3**
- 四个差值标签：**−0.09／+0.10／+0.05／+0.02**
- 右表题签：**原始 RMSE（t/ha）**
- 表格列：**A／B**；四行数值依次为 **0.62／0.71；1.10／1.00；1.20／1.15；0.90／0.88**。
- 下方三行条件：
  1. **随机测试：120 条地块记录，来自 3 站点、2 年；记录数 ≠ 独立站点数。**
  2. **整站留出：3 个站点；各站点测试记录数未提供；未做跨年度独立检验。**
  3. **无逐样本预测、无 SD/SE/CI 或 p 值；仅显示汇总读数，不作显著性判断。**
- 来源：本轮任务教学材料；差值由所给 RMSE 计算。

**必须可见的条件：** 上述全部条件与八个原始值均保留，不能为使图更简洁而把不利站点、独立单位或不确定性缺项移到讲稿。每个点代表对应测试的汇总差值，不是一个地块的误差或独立重复。

**推理与边界：** 负差值表示 A 的 RMSE 更低，正差值表示更高。随机行为负，三个留出站点均为正，因此“本次三个留出站点未保留优势”有直接数值支持。没有不确定性资料不妨碍描述读数方向，但阻止统计显著性及总体优势／劣势的推断。差值大小不能解释成逐地块产量误差的平均变化。

**简要讲稿：**

> 先看中间的差值，定义为 A 的 RMSE 减去 B。零线表示误差相同，左边有利于 A，右边表示 A 的误差更高；右侧保留了全部原始值，便于核对。随机划分这一行，A 是 0.62，B 是 0.71，差值为负 0.09，确实观察到 A 更低。然后看三个整站留出：站点 1 是 1.10 对 1.00，差值正 0.10；站点 2 是 1.20 对 1.15，正 0.05；站点 3 是 0.90 对 0.88，正 0.02。三个差值都在零线右侧。因此，在这份材料的三个留出站点中，A 没有保持随机测试中的优势。这不是“某个站点略有波动”，而是三个读数方向都不利于 A。不过，我们没有逐样本预测、区间或检验结果，不能说 B 显著优于 A，也不能推广到所有新站点。三个站点的 RMSE 也没有直接合成为一个总体 RMSE 的依据。

**承接：** “结果改变了可陈述的结论：A 的方法思路仍可检验，但当前不能用新站点优势来为它背书。”
