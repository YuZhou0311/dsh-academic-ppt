## 4. 独立使用与能力边界

除确定性测试外，本轮安排独立执行者只依据技能、原始论文记录与图片制作四页真实论文节选。它是当前制作环境中的 CLI 使用检查，不是 DeepSeek/DSH GUI 端到端模型评测；真实完成的范围与保留问题见 [独立使用检查](forward-review-v0.3.0.md)。输入中的版本日期和出版日期需要核对，未知标签高度仍需保留告警，不能为得到全绿伪造测量。

离线重建脚本默认模型视觉能力为 unknown；发布样例的画面检查不会自动注入复用者的项目。`asset.reading.verifiedBy`、阅读状态与审查条目都是执行者声明，代码不能独立证明语义、事实或审美。
