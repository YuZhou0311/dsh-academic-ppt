# rc.6：从页面信息到多层构图

研究与实现日期：2026-10-25。这个版本接续 rc.5，但不沿用其完整样稿已经解决审美问题的判断。用户对 rc.5 的反馈是：信息偏少，卡片和表达方式重复，标题层级弱，正文缺少逐页设计。通过回看实际输出与提供的完整参考，确认只增加描边、配色和章节字段不足以解决这些问题。

## 1. 本轮采用的设计原则

一个页面可以共同呈现研究条件、几组证据、方法说明、比较、解释和阶段结论。它需要明确的阅读方向与主次；“一页有中心问题”不意味着只能保留一个孤立信息点。区域数量、方向和尺寸取决于当前论证，不预设每页必须三块、必须左右并排，或每页必须采用不同外观。

学习参考时，要看到正文如何分层。大区域内部可以继续组织图、局部题签、条件和解释；上层可以是总分，内部可以同时有比较、流程、对应和汇总。标题带、留白、对齐、线条、浅底及空间邻近都可表达分组，不需要将所有信息塞进相同卡片。

学术内容的充分程度由是否保留完成论证所需的信息判断。放大一个数字、铺满色块或增加装饰不会增加证据。另一方面，把全部正文缩成脚注也不是高信息量设计。应先梳理内容，分配主辅空间，采用合适的图表或关系图，再通过实际投影尺寸检查阅读性。

### 从参考学习什么

- 同页的几类信息分别承担什么职责，如何由条件到证据再到解释。
- 主区域与辅助区域的面积、对齐、跨度和嵌套关系。
- 章节、本页题名与局部题签如何分层；来源、单位和不确定性放在哪里。
- 连续页面如何推进研究问题，何处保持共同比较尺度，何处换用更适合新任务的构图。

参考中的项目事实、机构标志、作者图像、占位数字和精确几何不进入新样稿。装饰过量、来源缺失或难以阅读的部分也不继承。附件只用于本次私有研究，仓库不再分发这些文件及其截图。

## 3. 四层提示与执行顺序

### 任务层：先给设计约束

明确汇报场合、听众、时长、源材料、必须回答的问题、学术正式程度以及是否有参考。把真实结果、汇报者推断和待实施方案分开。没有的身份、数字、实验或参考文献不补造。

### 整稿层：让章节承担论证任务

为开场问题、各节问题、证据顺序、局部结论和最终回应建立联系。目录用于呈现逻辑路线，正文保留定位与具体过渡。短稿可把路线与研究对象/条件同页组织，避免用空泛分节页拉长稿子。

### 页面层：先内容清单，再构图

每页先列出已有的证据、方法、条件、解释和综合判断，指出缺失材料。随后选择它们之间的关系，确定主区域、辅助区域、阅读顺序及局部题签。允许上宽下分、侧注与跨栏结论、主图周围的局部解释、多层流程、矩阵、嵌套区域等组合；这些只是关系的可能表达，不是需要轮流使用的版式菜单。

一份可操作的逐页任务应包含：本页在整稿中的作用、必须出现的信息、真实可用载体、信息之间的关系、标题层级、阅读顺序、配色职责与不能删改的条件。不同页面不必具有相同的信息层数量。

### 修订层：把意见落实到可见对象

“更好看”不足以定位问题。可用的修改描述包括：补回主视图缺失的比较条件；将机制说明与其证据放近；让两组图保持同尺度；把等权文字块改为主证据加局部解释；区分章节与本页判断；减少连续页面中没有必要的相同骨架。修改后重看实际 PPTX，不继承旧画面的审查结论。

## 4. 本轮接口与兼容路线

- `visualPlan.contentLayers` 可记录 `evidence / explanation / conditions / method / synthesis` 信息层，各层关联真实 `panelIds` 并给出简短说明。它保留设计依据，不自动创造或补足内容，也不要求每页填齐全部角色。
- `visualPlan.readingOrder` 容量与自由区域一致，最多12项。区域多不等于质量高，完整阅读路径仍需实际检查。
- `heading.inheritChrome: true` 允许自主题名保留选定的公共章节视觉层级。标题位置仍由作者给定；与章节带冲突时报告问题，不静默移动或缩字。未指定此字段的旧工程继续使用原有自定义标题路线。
- `card.appearance.layout` 提供 `stacked / banded / side-label` 三种内部组织：普通堆叠、表头带、侧题签。卡片依然可以是轮廓、浅底或开放表面；区域、图旁解释和独立卡片应各有职责。布局测量与绘制共用几何，完整文字参与容量检查。
- 结构提醒增加自由区域的近似骨架比较和等权文字块识别。换色、换字、微调坐标不视为新构图；真正的布局变化和有理由的共尺度比较应被区分。提醒只指出需查看的页面，不提供审美分或原创性认证。

字段均为可选；schemaVersion保持1。完整契约以插件 `contract` 返回结果为准。旧工程的显式风格保留，旧文件需重建才能使用新渲染功能。

## 5. 检查完整样稿的方法

先用实际绘制的候选比较最难的多证据页与方法或综合页，封面另行检查。随后连续查看至少三页，核对主次、信息层和阅读方向是否一直套同一种骨架。相同实验的共同尺度比较可保留重复，不能为追求变化破坏科学可比性。

最终需查看当前 PPTX 的每一页：标题层级是否清楚，必需条件是否在主视图中，图表与解释是否相邻，描边是否有分组意义，密集内容能否阅读，来源与结论边界是否完整。静态越界、字号和引用检查仍然保留；它们不能判断讲述是否充分或设计是否有说服力。

本轮已在工作区制作并验证10页完整样稿，暂未收入公开仓库；软件回归、渲染和内容核查的实测记录见 [本轮验证记录](VALIDATION_V07_RC6.md)。rc.5 的公开样稿与审查保留历史身份，用于理解本轮修订起点，不表示用户已认可其设计。
