# 0.10.0-rc.6 完整候选安装与试用

这是完整 DSH 插件 TGZ，不是上轮源码补丁。无需解压；不上传 ZIP 到插件管理器。未推送 GitHub 主分支或原 PR，未发布 Release 或 npm registry。使用此次交付的真实本地文件。

## 安装

在正在使用的 DSH 应用/同一 profile 的插件管理中，以新 TGZ 更新或重新安装 dsh-academic-ppt 并启用。输入本地路径时，使用 DSH 所在电脑上的绝对路径；服务器 Web Host 的路径指向服务器，不是浏览器所在电脑。

完全退出后重启应用，新建会话。核对插件 **0.10.0-rc.6**，工具返回 **guidanceRevision: collaborative-proof-rc6**，19 个工具、8 个设计案例。只复制 SKILL 不能注册完整工具。

桌面可使用应用内插件管理。使用桌面自带 CLI 时，先初始化并完全退出桌面，再执行 `dsh plugin --profile desktop add "file:/absolute/path/to/dsh-academic-ppt-0.10.0-rc.6.tgz"`，随后重启。不要用另外安装的 npm CLI 修改桌面 profile。官方来源（核对于2026-10-31）：https://github.com/deepseek-ai/deepseek-harness/blob/master/apps/desktop/README.md 。具体旧渠道说明保留于 INSTALL.md，勿从旧链接下载替代包。

建议新建输出工程，复用已有论文、原图和笔记；不会覆盖旧报告。旧工程中的显式设计参数继续保留，新建工程不会代入被否定的旧配置。无需换模型、交出密钥或重检整批论文。

## 应观察到的行为

先对齐内容与设计建议；真实正文样张发布后停止新增页，等待自然语言反馈；否定时修已有页，不把“继续修改”改记认可；认可样张不自动等于认可最终稿。

图片的 read_image 只供模型观察，present 才是向用户提交预览，二者都不是用户批准。若当前 Host 无法展示，须说明缺口，不要求盲批。重启后短期反馈收据不持久保存，需要一次简短复核，不得伪造历史确认。

若因含糊/混合反馈被保守拦截，可直接说明“认可这三页的设计方向，可以继续扩稿”或“第2页需修改，先不要扩稿”；无需修改工具记录绕过。该机制不是自然语言授权的完整解释器。
