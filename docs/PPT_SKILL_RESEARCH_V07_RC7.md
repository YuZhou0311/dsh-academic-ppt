# rc.7：把参考经验落实到逐页设计与实际画面

研究与修订日期：2026-10-25。

## 修订起点

用户再次指出 rc.6 成稿与所提供参考的差距。旧稿已有散点、区间、曲线、表格和流程，问题不能简单归结为“图形种类少”。对实际页面的复看显示，较多正文仍以大标题、大说明和单一主证据区组织信息，模块内部的条件、指标、方法和解释没有形成足够清楚的对应。

本轮将公开教程、其他 PPT Skill 的工作流与实际参考比较结合起来。采用可迁移的方法，独立编写本插件的指引；不导入第三方执行器，不运行其脚本，不复制受限提示词全文，也不把用户模板的事实或媒体用于示例研究。

## 从研究转成执行方法

### 1. 在绘图前完成逐页设计稿

先确定观看场景和本页任务，再写出本页实际需要显示的内容：研究对象、条件、证据、方法、解释、判断及来源。随后描述这些内容之间的顺序、对照、依赖、包含或约束关系，并决定用什么图、表、文字或原生关系表达。

逐页稿应足以直接指导建页，而不是“左边图、右边结论”一类空槽位。完成页面后，反查设计稿：应显示的数值是否在主要视图中，应该对应的图与统计量能否就近核对，限制是否跟着相关判断出现。若实际内容或关系改变，同时更新逐页稿。

### 2. 用有效内容与对应关系增加丰富度

丰富度来自不同任务之间的互补：图列与指标列相互对应，方法步骤邻接它的验证证据，条件在起作用的步骤附近，局部解释指向具体观察。一个大区域可以包含若干不同层次，也可以通过共同坐标、对齐或分组表达归属。

不把图表种类、面板数、字数或占幅当作配额。单一完整图足够时保留完整；材料有限时减少重复页面。没有提供的设备、机制、实验图和成果不通过生成图片补造。

### 3. 为中间层次保留空间

章节定位、页级题名、模块题签、正文、数据读数、图内标签和来源分别承担职责。用当前契约支持的字号范围明确设置本稿的层级；不把默认字号视作所有任务的唯一方案，也不把重要条件伪装成注释以绕过检查。

标题应适合页面任务：方法、条件和资料页可以用准确主题名称；有直接证据支持的结果页再使用判断式标题。层级清楚不要求每层都有独立色带，也不要求把标题统一缩小。

实际候选复核还发现，把最高层局部题签用于“每个点代表什么”等编码说明，会削弱证据阅读。结果区应在有依据时指出需要核对的局部特征，并让对应表列、曲线区段或读数获得有限强调；编码说明贴近图形保留。此项已补入设计指引，方法区不因此被强制写成结论。

### 4. 参考比较必须产生具体修订

选任务相近的参考正文，在同一观看尺度下比较。记录具体差距，如图表与指标对应不清、方法控制没有挂接、模块内部信息太平、关键条件只存在讲稿。把需要修复的差距落实到当前页面，重新看图。

同时分开记录素材约束：参考里的真实设备图、模型结果、成果证明等，当前材料没有时不能通过排版创造。参考本身的占位、拥挤和模糊图也不照搬。

## 本轮落实

- 重写技能主流程，新增[正向页面设计工作坊](../skills/dsh-academic-ppt/references/page-design-workshop.md)，连接具体材料、逐页稿、真实建页和实际核对。
- 修订设计、组合、标题、参考学习与交付指引，使逐页稿在制作前发挥作用；明确 `primaryPanelId` 可以指向一个组合阅读入口，不要求单一巨大主图。
- 将完整多面板图的无条件阻断改为 `figure-multipanel-review` 审阅提醒。保留实际标签小于12px的阻断与不足18px的建议，也保留未看图、缺少标签测量和定位图职责检查。
- 修改空区修复建议：先查遗漏的证据、条件、比较和解释，再重组或合并，最后根据可读性调整尺寸。compact 阈值与占幅算法未更改。
- 保持 schemaVersion 1、renderer 13 和既有数据结构；版本为 `0.7.0-rc.7`。本轮没有安装第三方 Skill 的执行环境或新增模型服务。

实际检查与制作范围见[本轮验证记录](VALIDATION_V07_RC7.md)。方法研究、软件回归和样稿观感是不同证据，不能相互替代。
