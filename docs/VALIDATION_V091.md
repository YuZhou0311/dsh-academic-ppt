# v0.9.1 验证记录

本记录对应 2026-10-27 的 v0.9.1 修复。原始来源、学术内容与用户批准仍需执行者真实核对；测试中的审查与回答明确标为软件状态模拟，不作为真实用户评价。

## 验证方法

- 新任务前向试跑：独立会话读取实际安装技能，使用“智能体与作物模型结合、15分钟组会、材料随后提供”的任务。实际创建的工程进入source阶段、requiresUserResponse=true，返回三种设计来源选项并等待回答；没有创建幻灯片或代填用户批准。
- 公开API与工具回归：验证开场来源、主题范围委托、layout讨论、待上传处理、真实样张顺序、逐页space/color检查、风险目标回应、最终双哈希确认和可恢复交付。
- 局部更新回归：验证保存最终反馈保留设计系统、已有决定和同一PPTX；密度决定跨局部更新保持；同批重复topic拒绝；历史模板路径不阻断无关反馈。
- 两版官方DSH AgentLoop注入：使用固定0.2.1-rc.2/rc.3的真实官方服务，只有provider回复使用脚本。检查技能目录、全文与新工作流文件读取、19个工具及结果、工作目录、访问策略和实际图片传输。不宣称真实DeepSeek模型完成了端到端学术报告。
- 真实渲染：使用LibreOffice WASM实际导出PNG/PDF，检查卡片高度、图槽比例、文字可读性、深/中/浅填色和图注；不把SVG预览当最终PPTX。

## 实际视觉检查

已实际查看两页卡片适配对照、深浅配色页面，以及重建的12页原创图卡参考。12页参考使用官方Noto字体，渲染报告无缺失字体；总览/局部图比例在看图后修复，重渲染确认只有相应页面像素改变。

留白反例保留用于诊断：显式高框的短卡实际空腔约328.58px，占框高69.9%，被定位为card-excess-whitespace；另一页即使收紧外框，整页仍有约42.86%连续空区，继续得到unused-region-review。没有把单个尺寸修复或工具成功当作整页审美通过。

## 发行验证

最终测试数量和发布提交由正式发布流水线记录。发行任务强制真实渲染与两版官方运行时回归，运行npm run check后，从同一已提交干净源码树生成五项附件，先上传草稿，再下载并逐文件/校验和核对，通过后公开为Latest。

当前可复查的测试入口包括 test/human-loop-v091.test.mjs、test/review-v091.test.mjs、test/card-fit.test.mjs、test/projection-quality.test.mjs 及原有完整回归。普通注册工具schema预算保持18KB以内，较大的设计契约只按需读取。

## 适用边界

机器验证不独立证明用户原话真实，也不保证任意模型每次都能完成优秀设计。复杂母版、付费字体或特定PowerPoint/WPS放映仍须在实际环境中检查。旧独立复杂card.style几何保持兼容，新适配主要覆盖当前preset、appearance与语义组合布局；旧样式仍受最终实际画面与整页留白审查。
