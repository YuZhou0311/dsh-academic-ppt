# v0.7.0 · 以论文证据组织页面，自主设计学术报告

**dsh-academic-ppt 0.7** 将论文材料、论证关系与页面设计连接起来：先盘点原文证据，再制作真实构图候选，完成可编辑报告并逐页复核。此次更新重点处理反复套用卡片模板、主证据不足、标题与封面缺少设计、主要视图小字，以及不同报告构图过度相似的问题。

本版将已完成重建与复核的 `0.7.0-rc.4` 实现整理为 **0.7.0** 正式版本，渲染器为 **11**，工程 `schemaVersion` 仍为 **1**。页面分析与设计由当前 DSH 会话模型完成，插件负责可编辑构建、证据记录与可解释检查。

[README](https://github.com/YuZhou0311/dsh-academic-ppt/blob/v0.7.0/README.md) · [安装与升级](https://github.com/YuZhou0311/dsh-academic-ppt/blob/v0.7.0/docs/INSTALL.md) · [设计与接口](https://github.com/YuZhou0311/dsh-academic-ppt/blob/v0.7.0/docs/RESEARCH_NATIVE_DESIGN.md) · [完整验证记录](https://github.com/YuZhou0311/dsh-academic-ppt/blob/v0.7.0/docs/VALIDATION_V07.md)

## 主要更新

### 1. 自由原生构图与独立的封面、标题设计

新增 `drawings` 和 `composition.regions`，支持自由安排原生文字、矩形、椭圆、折线、箭头与已登记的图片。区域可以隐藏标题、取消内边距和外框；主图、比较表、解释区与条件说明按研究关系分配位置，不要求先选模板编号。

`heading` 保存完整题名、自定断行、位置与字号，并按实际占用让出正文空间。封面可以独立安排题名、汇报身份和主题视觉，`chrome` 控制页眉、页脚、角标及标题线，避免每页复制同一套装饰。卡片仍可用于有明确边界的局部解释，其轮廓、表面、强调边和间距可由作者设计。

### 2. 实际候选与参考学习

新增 **`academic_ppt_study`**：接收 2–6 个作者真正绘制的候选，输出 SVG、PPTX、并列 HTML 和可选实际渲染，帮助比较封面或困难证据页。候选不会修改原工程，也不会自动获得正式审阅状态。

制作流程重新强调原文图表盘点、参考的主辅比例、局部分组、图文邻接、标题层级和全稿节奏。参考的组织方式用于当前证据；模板的页序、卡片数量和图文比例不自动成为新稿要求。没有生图模型时，仍可用原生文字与形状制作 SVG/PPTX 候选。

### 3. 主要视图的字号、条件与来源

新工程默认正文 **28 CSS px**、图标签 **24 CSS px**、注释 **18 CSS px**，对应 **21／18／13.5 pt**。检查使用最终缩放后的字级，不能靠缩小必要文字掩盖拥挤。

新增 `contentChecks`，核对主要视图中必须呈现的条件与数字，保留正负号、科学计数与单位大小写；讲稿、图注和引用不能替代必要正文。原生 drawing 的图片和数据标记纳入来源链，未消费的图、表、节点、drawing 或书目会被明确报告。来源中的事实、汇报者的推断和待验证方案继续区分记录。

### 4. 稿内与跨稿的结构比较

新增 **`academic_ppt_portfolio`**，只比较明确指定的 2–12 个不同工程，返回需要并列观察的页面。换色、换字或改变数据值不算新构图；有意义的同尺度科学比较可以保持结构一致。它检查作者记录的几何关系，**不提供原创性分数或自动审美结论**。

插件现有 **14 个工具**。详细契约按需读取，完整记录通过工作区文件提交，避免常驻接口反复携带大量嵌套字段。

## 下载与安装

需要 **Node `^22.19.0 || >=24.0.0`**。插件使用宿主已有模型，不另行调用付费模型或管理 DeepSeek 密钥；可与原 `dsh-ppt` 共存。**尚未发布 npm 公共 registry**。

本版安装包与校验清单：

- [dsh-academic-ppt-0.7.0.tgz](https://github.com/YuZhou0311/dsh-academic-ppt/releases/download/v0.7.0/dsh-academic-ppt-0.7.0.tgz)
- [SHA256SUMS.txt](https://github.com/YuZhou0311/dsh-academic-ppt/releases/download/v0.7.0/SHA256SUMS.txt)

下载并校验后，在已经初始化的 DSH profile 中使用本机真实绝对路径安装：

```sh
dsh plugin --profile desktop add "file:/absolute/path/to/dsh-academic-ppt-0.7.0.tgz"
```

网页版将 `desktop` 换成 `web`，安装或更新后重启对应 DSH。`file:` 安装副本不会因你修改源码就自动更新。

也可以从固定标签取得源码：

```sh
git clone --branch v0.7.0 --depth 1 https://github.com/YuZhou0311/dsh-academic-ppt.git
cd dsh-academic-ppt
npm ci --ignore-scripts
node bin/academic-ppt.mjs --help
```

源码可离线重建两份示例；每次使用新的输出目录：

```sh
node scripts/build-research-demo.mjs --author a --output ./research-demo-a
node scripts/build-research-demo.mjs --author b --output ./research-demo-b
```

普通 PPTX/HTML 构建不依赖 Office。实际 PPTX 图片/PDF 渲染使用可选 `@deepseek-ai/libreoffice-kit`，可通过 `--render --font-dir ./fonts` 为示例重建启用渲染并提供有许可的字体。字体不随包分发，缺少引擎或字体时不能将未验证结果写成通过。完整步骤见[安装说明](https://github.com/YuZhou0311/dsh-academic-ppt/blob/v0.7.0/docs/INSTALL.md)。

## 升级与已知限制

旧工程继续兼容，未提供新增字段时保留原有分支。升级后需要重新构建和实际渲染当前 PPTX，再登记逐页审阅；旧产物的通过状态不自动继承。

部分论文原图的次级刻度和标签仍低于目标字级，主要数字、单位与条件另用较大原生文字补充。本轮没有在用户 DeepSeek 收费端点、真实 DSH Desktop/Web GUI、PowerPoint/WPS GUI 或现场投影设备验收；840 秒是讲稿预算，没有真人计时排练。两位作者使用同一宿主模型，这不是十套报告的稳定性测试，也不是多模型盲测。

自动检查、测试通过与 `readyForDelivery` 只描述各自的过程和范围。学术关系、数字条件、原图处理和最终投影视觉仍需实际复核。三篇论文图件与提取文本按原文 **CC BY 4.0** 声明保留署名、出处和修改说明，来源材料不适用插件代码的 MIT 许可；详见[来源与许可](https://github.com/YuZhou0311/dsh-academic-ppt/blob/v0.7.0/examples/research-native-v07/sources/README.md)。
