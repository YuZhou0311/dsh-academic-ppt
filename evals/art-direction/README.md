# 审美校准的配对评测

目标不是验证“更满”，而是验证同一材料在用户认可的学术设计目标下是否更可用。

## 固定条件

旧版与补丁版使用同一模型/版本、上下文、来源、素材、报告场景、页数范围和总预算。参考稿相同；盲评时随机顺序并隐藏生成版本。保存每个任务全部输出，不能只挑最佳。

## 三类任务

A. 同一小型结果集：共同尺度区间图、站点原始数值、样本层级与外推限制。候选不得删除困难条件或引入新结果。
B. 原生技术路线：至少有真实来源支持的阶段、分支与验证关系。禁止以三张概念卡替代拓扑；不追求对象数量。
C. 多图科学页：来源图、面板身份、图注、条件和对应解释。不得裁掉轴/图例；原图太小须明确放大/拆页策略。

增加局部修改任务：用户指出右侧松散、图太小或强调过强，检查是否做了定位明确且不损失内容的修复，而不是换整套皮肤。

## 评价

科学错误和不可读证据优先单列。视觉方面记录：参考方向匹配、主次、证据组完整性、关系准确、微排版、色彩职责、有效信息密度。每个判断给页码和具体画面位置；不要用自动对象覆盖率或大模型自评总分代替。

记录人工修订分钟数、需要重构的页数、错误数量、生成与修订成本。小样本先呈现逐页胜负与分歧，不能宣传统计显著或对所有学科有效。

至少让用户/实际学科报告者参与校准。助手编排样页证明某种构图可制作，真实DSH独立生成与盲评才回答插件是否稳定学会了它。
