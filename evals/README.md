# 学术表达回归任务

[academic-cases.json](academic-cases.json) 提供8个固定任务。内联数字仅为软件演练，不是论文或真实实验。需要实际论文/模板/工程的case明确标为需要附件；未提供时不能记成已执行。

用同一宿主、模型版本、输入材料、时间预算和授权范围分别运行基线与候选。向作者Agent只提供prompt及必要原始材料，不提供must_preserve/must_not或预期结论。将产物匿名交给审阅者，再用这些字段核对科学忠实度。

分别保留完整输入、工具调用记录、PPTX、实际渲染、来源与审查。观察科学忠实度、论证连贯、读图能力、投影可读性、风格适配和修改范围；严重科学错误或缺失证据直接不通过，不能靠视觉平均分抵消。重复布局允许有科学理由。

记录每项结果为通过、需修复或无法判断，并给具体页号/对象与原因。没有生成PPTX的试验只报告计划能力；没有实际DSH创作的试验不称为DSH端到端验证。单次通过不能推论模型稳定性，重复任务应采用新会话且不泄露旧输出。
